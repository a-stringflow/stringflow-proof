\section{Dependency graph and status ledger}

The dependency graph is a directed acyclic graph whose nodes are
mathematical lemmas and Lean theorems.

\subsection{Main dependency chain}

\begin{enumerate}[leftmargin=*]
\item Finite base:
  \texttt{FinitePrefix.lean}.
\item Candidate and segment bridges:
  \texttt{UnifiedCoreBridge.lean}.
\item Unified core:
  \texttt{UnifiedCoreAudit.lean}.
\item Cycle bridge:
  \texttt{CycleBridge.lean}.
\item Final assembly:
  \texttt{DwdbDiv.lean}.
\end{enumerate}

In topological order, the individual statements are:
\begin{enumerate}[leftmargin=*]
\item explicit orbit values and first-big-step facts;
\item candidate parameterisation and terminal equations;
\item orbit segment equations and $d=1,d=2$ exclusions;
\item $d=3$ and $d\ge4$ family exclusions;
\item CRT candidate, terminal residue, and size conditions;
\item the unified-core final inequality (pending);
\item cycle-word extraction and the QB-8 split;
\item corrected-window projection and failure-window contradiction;
\item window-to-no-cycle bridge;
\item final divergence assembly.
\end{enumerate}

\begin{verbatim}

  imports S6AuditStage1

UnifiedCoreBridge.lean
  imports FinitePrefix, UnifiedCoreAudit

UnifiedCoreAudit.lean
  imports S6Audit, S6AuditStage1, LteMacro

  imports BlockAutomaton, FinalStatement, S6AuditStage1,
          PhOne, SurvExAudit, Td0Real

DwdbDiv.lean
  imports CycleBridge, UnifiedCoreAudit

FinalStatement.lean
  imports S6Audit, FBeta
\end{verbatim}

The import graph is read from the file headers; it is updated whenever
the Lean project re-imports.

\subsection{Verification commands}

The manual uses the same verification commands as the main paper:
\begin{verbatim}
lake build CycleBridge
lake build DwdbDiv
\end{verbatim}
For a status change, also re-run the axiom audit and check that
\texttt{UnifiedCoreAudit.lean} contains exactly one \texttt{sorry},
namely \texttt{unified\_core\_final\_no\_hge}.

  the unique Lean \texttt{sorry} in the unified-core audit;

status tables must be updated before the final theorem is promoted.
