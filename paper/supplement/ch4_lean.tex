\subsection{WordWindow.lean}

\texttt{WordWindow.lean} defines the string-flow vocabulary:
\begin{itemize}[leftmargin=*]
\item \texttt{StringFlow.Word.wordA}: the word molecule;
\item \texttt{StringFlow.Word.wordOrbit}: the word orbit;
\item \texttt{StringFlow.Word.wordValid}: word validity;
\item \texttt{StringFlow.wordWeight}: the prefix-weight function;
\item the exact word-orbit identity
  \begin{equation*}
    2^{\wordWeight(w)}\,\wordOrbit(w,x_0)
      =5^{\operatorname{len}(w)}\,x_0+\wordA(w),
  \end{equation*}
  recorded in the file's identity lemmas.
\end{itemize}
The file also hosts the elementary valuation facts
\texttt{n\_\allowbreak eq\_\allowbreak two\_\allowbreak pow\_\allowbreak
mul\_\allowbreak oddPart},

pow\_\allowbreak eq},

two}, and

\subsection{Reading order}

\begin{enumerate}[leftmargin=*]
\item \texttt{WordWindow.lean}: \texttt{wordA}, \texttt{wordOrbit},
  \texttt{wordValid};
\item \texttt{Pmi.lean}: PMI and PMI-B algebra;
\item \texttt{FinitePrefix.lean}: the explicit finite base;
\item \texttt{UnifiedCoreBridge.lean}: candidate parameterisation and
  segment exclusions;
\item \texttt{UnifiedCoreAudit.lean}: CRT, terminal residue, and the
  final pending statement;
\item \texttt{CycleBridge.lean}: corrected window and no-cycle bridge;
\item \texttt{DwdbDiv.lean}: final divergence assembly.
\end{enumerate}

\subsection{Acceptance criteria}

\begin{itemize}[leftmargin=*]
\item no \texttt{sorry} in any theorem consumed by the main chain;
\item no custom axiom; only \texttt{propext},
  \texttt{Classical.choice}, and \texttt{Quot.sound} appear;
\item no \texttt{native\_decide} in the main chain; the finite base is
  expanded by rewriting;
\item \texttt{unified\_core\_final\_no\_hge} is recorded as pending and
  is not cited as closed.
\end{itemize}
