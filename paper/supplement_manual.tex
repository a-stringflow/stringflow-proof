\begin{abstract}
This manual is the companion to the main paper.  It records the full
proof chain, the Lean theorem index, and the dependency ledger.  The
current compiled length is 102 pages; the target length is 100 to 150
pages, and the chapters are maintained incrementally.
\end{abstract}

\begin{itemize}[leftmargin=*]
\item mathematical statement;
\item Lean name and file;
\item status: \texttt{Math: proven}, \texttt{Lean: compiled}, or
  \texttt{Lean: pending};
\item list of dependencies.
\end{itemize}

\section{Cross-reference policy}

The manual cross-references the main paper by section and theorem
number.  It does not paste Lean files line by line; it lists definitions
and theorems, with file and line regions.
