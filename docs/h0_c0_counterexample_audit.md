# h=0 c0 反例逐条审计（2026-08-10）

状态：审计记录，不声明证明闭合。

## 1. 核心恒等式

固定 `E`、`k`，令

```text
c0=(k·2^E-47)/125,
r_j=c0+2^E·m0.
```

由 `125c0+47=k·2^E` 得精确恒等式：

```text
σ = (125r_j+47)/2^E = k+125·m0.
```

因此：

- `σ` 为奇数 当且仅当 `k+m0` 为奇数；
- `σ≡k (mod 125)`，所以 5-adic 剩余类自动由 `k` 决定；
- 保持 `c0` 的模 5 轨道长度 `L` 需要
  `r_j≡c0 (mod 5^(L+1))`，即 `m0≡0 (mod 5^(L+1))`；
- `σ` 尺寸条件等价于 `k+125m0<5^(j+3)`，
  跨块上界等价于 `k+125m0<3·5^(j+2)`。

## 2. E=8,k=112,c0=229

`c0` 轨道为 `[2,1,1,2,1,2]`，长度 `L=6`。

取完整化的 `q0=229`、`W=9`、`j=22`：

```text
r_j=1066364348000229,
σ=520685716796987=k+125·m0.
```

逐项判定：

- `q0∈[128,512)`：成立；
- `r_j∈[5^22/4,5^22)`：成立；
- `σ` 尺寸与跨块上界：成立；
- `σ` 为奇数：成立；
- `σ mod 125=112`：成立；
- 重量预算：`n2=3`，但 `W-j=9-22=-13`，**失败**；
- `L=6<j=22`：同时失败。

另外 `E=8` 不是 `2s+3` 的奇数形式，已经不在真正的 `h=0` 参数族内。

## 4. 冲突定位

- σ 尺寸和 5-adic 剩余类不构成冲突：它们在完整化后自动通过。
- σ 奇偶需要额外选择 `m0` 的奇偶，不是 `c0` 族自动满足的；
  但可以选出通过该条件的样本。
- 重量预算排除了 `E=8` 样本，但无法排除大 `E` 样本。
- 所有完整化样本共同的失败点是 `L(r_j)<j`：贪心剥离在
  `j` 步之前停止，这正是开放子引理 7.3。

因此，`c0` 轨道长度随 `E` 增大只否决“`m_n=0` 分支长度有常数界”
这条路线，并不构成 `h=0` 完整候选的反例。剩余证明仍必须给出
`L(r_j)<j` 的 `j` 依赖上界，而不是 `c0` 轨道的常数界。
