# Lean 装配防出错表

写任何 `ResetHeadEq` 或 `ResetWindowReachability` 引理前，先对照本表。

| 符号 | 正确含义 | 唯一来源 | 禁止 |
|---|---|---|---|
| `b` | 循环词全局索引 | rise/C3 分解 | 禁止当局部深度 `j` |
| `j` | 块局部重置深度 | 局部块词长度与终端结构推出 | 禁止手动设 `j=1` |
| `t` | 进入块首的单步权重 | `w.getI b`，且 `t∈{1,2}` | 禁止当整块总权重 |
| `rj` | 真实块首 | `wordOrbit (w.take (b+1)) m` | 禁止任意数值候选 |
| `r_prev` | 上一真实偶数终端 | `(5·wordOrbit (w.take (b-1)) m + 1)/2` | 禁止用 `q−1` |
| `s` | 上一终端的 5-adic 奇部 | `fiveOddPart (r_prev+1)` | 禁止用 `q` 冒充 `s` |
| `k0` | `r_prev+1` 的 5-adic 指数 | `fiveValuation (r_prev+1)` | 禁止自由选择 |
| `q` | 块局部商 | 局部块词方程 | 禁止当成状态或终端 |
| `A_j` | 局部块词分子 | `wordA` 或局部 PMI 展开 | 禁止与全局 `A` 混用 |
| `Wp` | 重置步前前缀权重 | 局部前缀权重 | 禁止用整块总权重 |
| `Wj` | `Wp+t` | 局部重置步后权重 | 禁止 `Wj=Wp+整块权重` |
| `δ` | 重置参数 | 由 `A_j,q,B` 解出 | 禁止直接固定 `δ=1/3` |
| `B` | `5^(k0+1)·s−4` | 真实上一终端 | 禁止重新定义 |
| `hident` | `A_j+5^j q=2^Wp(B+δ5^j)` | 上述对象全部确定后推出 | 禁止当独立输入 |
| `hreset` | `ResetHeadEq` | 由 `hident` 调用反向桥得到 | 禁止直接手写 |
| `hreach` | 窗口真实可达性 | 同一个 `s,k0,r_prev,rj` | 禁止另找 `r=q−1` |

## 出错时的固定顺序

```text
1. 先怀疑自己的变量来源；
2. 再检查定理前提是否完整；
3. 最后才考虑目标命题是否有反例。
```

## 三条硬规则

- 不精确或不确界的推进方式（例如放缩、松估计）会导致证明路线彻底卡死；任何路线必须先给出精确对象、真实深度坐标和精确互补阈值。
- 一个数值等式失败，只说明当前实例化错误，不自动说明目标为假。
- `q`、`s`、`r_prev`、`b`、`j` 是五类完全不同的对象，禁止互相代入。
- 只要 `hreset/hreach` 还没用同一个 `RealTerminal` 构造出来，就不得宣布 `failureWindowExistence` 卡死。
- 仓库没有现成引理 ≠ 证不了：缺失的引理就是本任务要新增的内容；
  禁止用“库中没有下界来源 / 没有现成定理”当作开放量、停止理由或
  不可证判定；未先写出并编译该引理就宣布“现有库推不出”按未动手处理。

- `CycleQb8Input` 的 `hstart`/`hcycle` 绑定真实 7 轨道；13 不是 7 轨道

  没有 `w=2` 的 hfail 前缀，rise 段长度只有 2，不满足

- 因此 `t2RunRankSumGtBoundSum_of_cycleQb8Input` 等内部断言不需要在

- 禁止把“13 模型满足全部结构字段 / 13 反例”用作不可证理由或形式
  反例；13 影子只作为“是否实际使用 7 轨道可达性”的检验器。

## 可达性层次

| 谓词 | 真实含义 | 允许使用的位置 |
|---|---|---|
| `OrbitFrom7 x` | 存在一个 `{1,2}` 合法词从 7 到达 `x` | 仅用于纯块定理；不能作为最终真实轨道可达性 |

## 真实轨道绑定硬规则（2026-08-16 补）

本项目所有证明都在真实轨道上做，不是通用结构命题。`CycleQb8Input`
的 `hstart`（m 是 7 轨道的具体第 n0 步）与 `hcycle`（w = cycleWord c p、
m = fiveXPlusOneOrbit 7 c）不是摆设字段：

- 每个 `CycleQb8Input` 命题的证明必须至少显式展开并使用一次
  `hstart` 或 `hcycle` 的具体内容（n0、c、p、m 与 7 的关系）；
- 只用 `hvalid`、`hclosed`、`hglobal_min`、`hm_pos` 等通用结构字段
  的证明，按未接入真实轨道处理，不进主线。

**13 影子测试。** 13 循环（13, 33, 83），加速词 (1, 1, 5)，
P = 3、S = 7、m = 13，满足 `CycleQb8Input` 除 `hstart`/`hcycle`
外的全部结构字段，且无坏前缀（`2^1 < 5`、`2^2 < 25`）。因此：

- 任何只用结构字段的证明会自动适用于 13 影子，等于没有使用
  7 轨道可达性；
- `cycleQb8Input_bad_prefix_exists` 不可作为独立引理：三个工具
  （`cycleWord_pmi_b_count`、`cycleQb8Input_weak_comparison`、
  `cycleQb8Input_last_step_c3`）在影子上相容且无矛盾；要区分
  13 与 7 只能靠 `hstart`/`hcycle`，而它们等价于假设
  `OrbitCycle 7`，独立证明必然循环；
- 该命题从开放目标撤下，仅在 `OrbitCycle 7` 假设下可作为主定理
  内部事实，不得再作为 hfail 的前置引理。

13 循环是 5x+1 的已知 3-循环，不是本目标要排除的对象，也不是
“伪反例”；它充当真实轨道可达性的检验器。

## PMI 使用边界

| 对象 | 正确用途 | 禁止用途 |
|---|---|---|
| 整循环 PMI 恒等式 | 闭合周期词的总预算 | 不能单独推出某个坏前缀的高估值 |
| PMI-B 坏前缀计数 | 给出坏前缀数量上界 | 不能把任意坏前缀直接当失败块 |
| `rise_block_balance` | 单块 `2H2 ≤ u+F` | 不能单独给出 `F` 的全局上界 |
| 块层 PMI 求和 | 由所有块避开窗口导致总预算矛盾，得到某个 `hfail` | 不能跳过逐块求和 |
| `qVWindowRemaining` | 旧一般局部引理的历史开放对象 | 不能重新挂到最终装配 |

`hfail` 的来源必须是：

```text
真实上升块分解
+ rise_block_balance
+ 整循环 PMI/PMI-B 预算
⇒ 至少一个块违反窗口
```

它不是从单个坏前缀直接推出的。

**全局比较 (6)（2026-08-16 判死）。**
`2ΣH2 > Σ(2(j-t)+12+F)` 不能由整循环 `2^S > 5^P` 推出；
该严格总比较从未用精确确界闭合，回绕项使其方向恒反。
此路线彻底失败，禁止复活，也不能作为 `hfail` 的来源。

## 循环 rise 块索引审计

> **2026-08-15 修正（优先于本节旧文）。** 非回绕块的
> `cycleRiseBlockSuffixEndpointRank d r` 恒等于下一块块首的 rank，
> 且该 rank 精确为 `2`（`cycleRiseBlockSuffixEndpointRank_eq_two`）。
> 因此旧文把失败条件写成
> `2 * (headDepth (r+1) - resetWeight (r+1)) + 13 ≤ suffixEndpointRank`
> 永远不可能成立，shifted next-head 失败对象作废。
> C3-tail 状态虽然可以有任意大的 rank，但 C3-tail 路线整体判定失败：
> `ResetWindowReachabilityC3` 的 `j` 只是尺寸参数，未绑定真实词深度；
> 其全局比较 (6) 从未用精确确界闭合，只做了估值/telescoping。
> 当前失败侧唯一有效推进是精确容量
> `u_j + F ≤ 2 (j - t) + 12`（`realOrbitChargeBound`）
> 与整循环 `2^S > 5^P` 的精确合并，失败阈值是
> `u_j ≥ 2 (j - t) + 13`。
> corrected 窗口界已精确等价归约为
> `rjRankT1Bound ∧ rjRankT2Bound`。
> 本节其余旧文本保留为历史记录。

当前 `CycleRiseBlockDecomposition` 的块方向固定为：

```text
headDepth r
→ c3Word r
→ c3TailState r
→ suffixWord r
→ headDepth (r+1)
```

对进入 C3 链的状态，精确估值恒等式是：

```text
c = v2(5r+1) ≥ 3
⇒
v2(r+1) = 2
```

因此 `headDepth r` 这个状态的 rank 固定为 `2`，它不能作为失败窗口
要越过的真实 reset 块首 rank。

正确对象是：

```text
cycleRiseBlockSuffixEndpointRank d r
```

它对应 `suffixWord r` 的终点，即下一个块首：

```text
wordOrbit (w.take (headDepth (r+1))) m
```

失败阈值也必须使用下一块的深度和重置步：

```text
2 * (headDepth (r+1) - resetWeight (r+1)) + 13
≤ cycleRiseBlockSuffixEndpointRank d r
```

最后一块按周期回绕：

```text
headDepth (blockCount) := headDepth 0 + P
resetWeight (blockCount) := resetWeight 0
```

禁止：

- 把 `cycleRiseBlockHeadRank d r` 当作失败 rank；
- 把当前 `headDepth r - resetWeight r` 与下一块 endpoint rank 混用；
- 用 `c3TailState r` 的 rank 配当前块阈值；
- 因为 `headRank r = 2` 就宣布结构不可满足。

这条审计规则同时修正 `cycleRiseBlockAvoidBudgetSum` 和旧定理
`cycleRiseBlockFailure_of_global_comparison_INVALID`：它们必须使用
shifted 下一块深度/重置步，而不是当前 `r`；该旧定理依赖被否定的
全局比较 (6)，只保留作审计，禁止下游使用。

## 极大循环 rise 终点的新增硬规则

- 在合法 `t∈{1,2}`、`δ` 分支下：

  ```text
  IsLocalResetTerminal t L rj δ rt
  ↔ ResetHeadEq rt.s L rt.k t δ rj
  ```

  所以 `hterm` 的真实剩余内容就是同一 `rt.s,rt.k` 的 reset 方程；
  禁止再把它当作与 `hreset` 无关的独立假设。
- 极大循环 rise run 的终点下一边为 C3，故该真实终点
  `v2(rj+1)=2`。在此点，原 `t=1/t=2` 窗口上界已经由精确恒等式
  直接闭合。
- C3→rise 边界的一次除二终端与 rise 起点满足精确式
  `rt.r = 2^(c-1)·q`（`c=w[b-1]≥3`），不是可自由选取的上一
  终端。若它还满足局部 reset 方程，则真实前驱对齐已排除
  `L=1,2`；任何候选至少要有 `L≥3`。
- 同一个终点不能同时作为 `hfail_t1/hfail_t2` 的来源；把局部
  reset 包与失败下界绑在该点，得到的就是矛盾本身，而不是可先行
  证明的中间引理。
- 这只排除“极大终点 + 同点失败”装配以及已判死的严格 PMI 总
  比较；不得推广成 valuation、前驱秩、换点失败或其他真实轨道
  降阶路线均已耗尽。

## 失败窗口布局硬规则（2026-08-15 补）

- 真实失败窗口位于循环 rise 块的 rise 端点（后接 C3）：出边 C3 的
  rank-two 恒等式直接给出矛盾（`cycleRiseBlockWindowFalse`），不需要
  decisive window bound，也不需要大深度 rank 估计。
- 禁止把失败窗口改放到 rise 段内部，并因此把大深度 rank 界重新拉回
  关键路径；该“修正”已被否决并改回。
- 已由精确结构定理闭合的方向，禁止仅凭“布局不适用”就翻案；必须
  给出满足全部前提的真实反例或精确引理，才能改判。
