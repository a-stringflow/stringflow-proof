# Lean 装配防出错表

写任何 `ResetHeadEq` 或 `ResetWindowReachability` 引理前，先对照本表。

| 符号 | 正确含义 | 唯一来源 | 禁止 |
|---|---|---|---|
| `b` | 循环词全局索引 | rise/C3 分解 | 禁止当局部深度 `j` |
| `j` | 块局部重置深度 | 局部块词长度与终端结构推出 | 禁止手动设 `j=1` |
| `t` | 进入块首的单步权重 | `w.getI b`，且 `t∈{1,2}` | 禁止当整块总权重 |
| `rj` | 真实块首 | `wordOrbit (w.take (b+1)) m` | 禁止任意数值候选 |
| `r_prev` | 上一真实偶数终端 | `(5·wordOrbit (w.take (b-1)) m + 1)/2` | 禁止用 `q−1` |
| `s` | 上一终端的 5-adic 奇部 | `fiveOddPart (r_prev+1)` | 禁止用 `q` 冒充 `s` |
| `k0` | `r_prev+1` 的 5-adic 指数 | `fiveValuation (r_prev+1)` | 禁止自由选择 |
| `q` | 块局部商 | 局部块词方程 | 禁止当成状态或终端 |
| `A_j` | 局部块词分子 | `wordA` 或局部 PMI 展开 | 禁止与全局 `A` 混用 |
| `Wp` | 重置步前前缀权重 | 局部前缀权重 | 禁止用整块总权重 |
| `Wj` | `Wp+t` | 局部重置步后权重 | 禁止 `Wj=Wp+整块权重` |
| `δ` | 重置参数 | 由 `A_j,q,B` 解出 | 禁止直接固定 `δ=1/3` |
| `B` | `5^(k0+1)·s−4` | 真实上一终端 | 禁止重新定义 |
| `hident` | `A_j+5^j q=2^Wp(B+δ5^j)` | 上述对象全部确定后推出 | 禁止当独立输入 |
| `hreset` | `ResetHeadEq` | 由 `hident` 调用反向桥得到 | 禁止直接手写 |
| `hreach` | 窗口真实可达性 | 同一个 `s,k0,r_prev,rj` | 禁止另找 `r=q−1` |

## 出错时的固定顺序

```text
1. 先怀疑自己的变量来源；
2. 再检查定理前提是否完整；
3. 最后才考虑目标命题是否有反例。
```

## 三条硬规则

- 一个数值等式失败，只说明当前实例化错误，不自动说明目标为假。
- `q`、`s`、`r_prev`、`b`、`j` 是五类完全不同的对象，禁止互相代入。
- 只要 `hreset/hreach` 还没用同一个 `RealTerminal` 构造出来，就不得宣布 `failureWindowExistence` 卡死。

## 可达性层次

| 谓词 | 真实含义 | 允许使用的位置 |
|---|---|---|
| `OrbitFrom7 x` | 存在一个 `{1,2}` 合法词从 7 到达 `x` | 仅用于纯块定理；不能作为最终真实轨道可达性 |
| `GeneralOrbitFrom7 x` | 存在任意除数词从 7 到达 `x` | 仅用于上一偶数终端 `r_prev`；不能替代块首可达性 |
| `FullOrbitFrom7 x` | 存在精确完整加速轨道深度 `n` 使 `fullOrbitIter n = x` | 块首 `rj`、循环起点 `m`、真实轨道状态 |

最终 `ResetWindowReachability` 的固定模式必须是：

```text
GeneralOrbitFrom7 r_prev
FullOrbitFrom7 rj
s * 5^k0 = r_prev + 1
```

禁止把 `OrbitFrom7`、`GeneralOrbitFrom7`、`FullOrbitFrom7` 三者互换。

## PMI 使用边界

| 对象 | 正确用途 | 禁止用途 |
|---|---|---|
| 整循环 PMI 恒等式 | 闭合周期词的总预算 | 不能单独推出某个坏前缀的高估值 |
| PMI-B 坏前缀计数 | 给出坏前缀数量上界 | 不能把任意坏前缀直接当失败块 |
| `rise_block_balance` | 单块 `2H2 ≤ u+F` | 不能单独给出 `F` 的全局上界 |
| 块层 PMI 求和 | 由所有块避开窗口导致总预算矛盾，得到某个 `hfail` | 不能跳过逐块求和 |
| `qVWindowRemaining` | 旧一般局部引理的历史开放对象 | 不能重新挂到最终装配 |

`hfail` 的来源必须是：

```text
真实上升块分解
+ rise_block_balance
+ 整循环 PMI/PMI-B 预算
⇒ 至少一个块违反窗口
```

它不是从单个坏前缀直接推出的。

## 循环 rise 块索引审计

当前 `CycleRiseBlockDecomposition` 的块方向固定为：

```text
headDepth r
→ c3Word r
→ c3TailState r
→ suffixWord r
→ headDepth (r+1)
```

对进入 C3 链的状态，精确估值恒等式是：

```text
c = v2(5r+1) ≥ 3
⇒
v2(r+1) = 2
```

因此 `headDepth r` 这个状态的 rank 固定为 `2`，它不能作为失败窗口
要越过的真实 reset 块首 rank。

正确对象是：

```text
cycleRiseBlockSuffixEndpointRank d r
```

它对应 `suffixWord r` 的终点，即下一个块首：

```text
wordOrbit (w.take (headDepth (r+1))) m
```

失败阈值也必须使用下一块的深度和重置步：

```text
2 * (headDepth (r+1) - resetWeight (r+1)) + 13
≤ cycleRiseBlockSuffixEndpointRank d r
```

最后一块按周期回绕：

```text
headDepth (blockCount) := headDepth 0 + P
resetWeight (blockCount) := resetWeight 0
```

禁止：

- 把 `cycleRiseBlockHeadRank d r` 当作失败 rank；
- 把当前 `headDepth r - resetWeight r` 与下一块 endpoint rank 混用；
- 用 `c3TailState r` 的 rank 配当前块阈值；
- 因为 `headRank r = 2` 就宣布结构不可满足。

这条审计规则同时修正 `cycleRiseBlockAvoidBudgetSum` 和
`cycleRiseBlockFailure_of_global_comparison`：它们必须使用 shifted
下一块深度/重置步，而不是当前 `r`。

## 已出现的伪反例

| 伪反例 | 表面上否定什么 | 真实错误 |
|---|---|---|
| `b=0`，`w[0]=2`，`m=7`，`r=18`，`s=19`，`rj=9` | 目标 ResetHeadEq | `j=1` 没有上一终端深度，必须排除 `b=0` |
| `b=16`，`r_prev=136708`，`s=136709`，`rj=85443`，`j=17` | 真实块首 ResetHeadEq | 全局 `b` 被当成局部 `j`；`136708` 是有限词出口叶，不是正确重置终端 |
| `q=34177`，`rj=85443`，`s=136709`，`j=1`，`δ=1` | 局部 hident | `q,j,δ` 都是手填，不是由 `A_j,q,B` 解出 |
| `r=q−1` 不在 `GeneralOrbitFrom7` | hreach | `q` 是商，不是终端；真实终端应为 `r_prev` |
| `fullOrbitIter 16 = 34177 ≡ 1 (mod 16)` | `r % 16 = 5` | `r%16=5` 只在尾部失败上下文成立，不是一般块首性质 |
| `BLOCK_LEMMA(n=1)` 的 `V+b=15>13` | 当前局部引理或 `hcharge` | 它只否证旧的更强充分条件，不是当前路线 |

判断规则：

```text
任何数值反例必须先满足目标定理的全部前提。
只要有一个前提未验证，它就是翻译反例，不是数学反例。
```

## 极大循环 rise 终点的新增硬规则

- 在合法 `t∈{1,2}`、`δ` 分支下：

  ```text
  IsLocalResetTerminal t L rj δ rt
  ↔ ResetHeadEq rt.s L rt.k t δ rj
  ```

  所以 `hterm` 的真实剩余内容就是同一 `rt.s,rt.k` 的 reset 方程；
  禁止再把它当作与 `hreset` 无关的独立假设。
- 极大循环 rise run 的终点下一边为 C3，故该真实终点
  `v2(rj+1)=2`。在此点，原 `t=1/t=2` 窗口上界已经由精确恒等式
  直接闭合。
- C3→rise 边界的一次除二终端与 rise 起点满足精确式
  `rt.r = 2^(c-1)·q`（`c=w[b-1]≥3`），不是可自由选取的上一
  终端。若它还满足局部 reset 方程，则真实前驱对齐已排除
  `L=1,2`；任何候选至少要有 `L≥3`。
- 同一个终点不能同时作为 `hfail_t1/hfail_t2` 的来源；把局部
  reset 包与失败下界绑在该点，得到的就是矛盾本身，而不是可先行
  证明的中间引理。
- 这只排除“极大终点 + 同点失败”装配以及已判死的严格 PMI 总
  比较；不得推广成 valuation、前驱秩、换点失败或其他真实轨道
  降阶路线均已耗尽。
