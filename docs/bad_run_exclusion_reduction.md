# 坏 X=2 游程的 K 同余归约（2026-08-09 续）

状态：**未闭合**。本文完成用户目标的前两步：把坏 `o_0` 写成
`(A,W,q,k,n,H)` 的显式函数，并把坏出口同余翻译成唯一 `K` 剩余类；
第三步（证明对应 `q` 不在区间或 `A` 不是 `{1,2}` 词前缀）仍是
开放子引理。本文所有语句标明必要/充分层次，不声称局部引理已闭合。

## 1. 记号

固定 `δ=0` 块，块首 `j`，`Wp=W_{j-1}`，`Wj=W_j`，
`tj=Wj-Wp∈{1,2}`，块内 `q∈[2^{Wp},2^{Wj})`。

设 `X=2` 游程从深度 `k` 开始：

- `r=r_k`，`W=W_k`，`H=H_k=2k+13-2(W-Wp)`；
- 游程长度 `n≥1`，即
  `3r+1=2^{n+2}T'`，`T'` 为奇数；
- 出口深度 `i=k+n`；
- `C=(5r_{i-1}+3)/4` 为最后一段 `X=2` 状态的正奇部；
- `K=(5r_i+3)/2^{H+1}`。

## 2. 坏出口的精确等价（充要）

**引理 2.1（充要）。** 在上述设定下，出口 `i` 处局部引理失败
（`X_i≥H+1`）当且仅当下列任一成立：

1. `2^H | 5C-1`；
2. `3·2^{H-1} | 5^{n+1}T'+1`；
3. `K∈Z_{≥1}`，并且
   ```text
   K = (5C-1)/2^H = (5r_i+3)/2^{H+1} = (5^{n+1}T'+1)/(3·2^{H-1}).
   ```

证明：游程闭式
`5r_i+3 = 4(5^{n+1}T'+1)/3` 与
`5C-1 = (5r_i+3)/2` 都是恒等式；`X_i=v_2(5r_i+3)≥H+1`
等价于 `v_2(5^{n+1}T'+1)≥H-1`，即第三条的整除性。∎

**推论 2.2（新的 5-adic 必要条件，必要）。** 若坏出口存在，则

```text
K ≡ (3·2^{H-1})^{-1}  (mod 5^{n+1}).
```

证明：由 `5^{n+1}T'+1=3K·2^{H-1}` 取模 `5^{n+1}` 即得。∎

记 `K0` 为该剩余类在 `[1,5^{n+1})` 中的最小正代表。它只依赖
`H mod (4·5^n)`（`2` 在模 `5^{n+1}` 中的阶为 `4·5^n`），
不依赖 `A,q,W`。

**推论 2.3（小 K 排除，必要）。** 对 `n≥1`：

- `K=1` 不可能，因为 `5∤3·2^{H-1}-1`（`H` 恒为奇数）；
- `K=2` 只可能在 `H≡1 (mod 4)` 时出现；
- `K=3` 只可能在 `H≡3 (mod 4)` 时出现。

证明：代入 `5 | 3K·2^{H-1}-1`，用 `2^{H-1} mod 5` 的周期
`1,2,4,3` 直接检查。∎

## 3. `K` 的显式方程与唯一 `q` 候选（充要）

用 `r=(A+5^k q)/2^W` 代入 `T'`，得到精确整数方程

```text
5^{n+1}(3A+3·5^k q+2^W) + 2^{W+n+2}
  = 3K·2^{W+n+H+1}.        (E)
```

**引理 3.1（充要）。** 坏游程存在当且仅当存在整数 `K≥1`、
`q∈[2^{Wp},2^{Wj})` 与可达前缀 `A`（`A<5^k`，
`A+5^k q=2^W r`，`r<5^k`）满足 `(E)` 且
`K≡K0 (mod 5^{n+1})`。

证明：`(E)` 是推论 2.2 的分子展开；反过来由 `(E)` 可解出
`T'` 并回到引理 2.1。∎

**引理 3.2（`q` 的区间翻译，充要）。** 对固定
`(A,W,k,n,H,K)`，`q` 由 `(E)` 唯一确定；`q∈[2^{Wp},2^{Wj})`
等价于 `K` 落在显式区间

```text
K_low =
  (5^{n+1}(3A+2^W) + 2^{W+n+2} + 3·5^{n+k+1}·2^{Wp})
  / (3·2^{W+n+H+1}),

K_high =
  (5^{n+1}(3A+2^W) + 2^{W+n+2} + 3·5^{n+k+1}·2^{Wj})
  / (3·2^{W+n+H+1}),
```

其中 `K_low ≤ K < K_high`。在归纳范围 `j≥17` 上，
`K_high/K_low ≤ 2^{tj}·(1+o(1))`，即 `K` 的相对窗口宽度至多约
`2`（`tj=1`）或 `4`（`tj=2`）。

再代入 `K=K0+m·5^{n+1}`（`m≥0`），`(E)` 化为

```text
3·5^k q = C0 + 3m·2^{W+n+H+1},
C0 = (3K0·2^{W+n+H+1} - 5^{n+1}(3A+2^W) - 2^{W+n+2}) / 5^{n+1}.
```

因此对每个 `m` 至多一个 `q`；`q` 的区间约束把 `m` 限制在至多
`O(2^{Wj}·5^{n+k+1}/2^{W+n+H+1})` 个值内。

更强的观察：若把 `m` 换成 `m+5^{n+k+1}`，`q` 增加
`2^{W+n+H+1}`，所以整数 `q` 沿步长 `2^{W+n+H+1}` 的等差数列
取值。由于 `n≥1`、`H≥3`，该步长大于 `2^{Wj}`，从而大于区间
`[2^{Wp},2^{Wj})` 的长度；因此对每个固定前缀 `A`，坏游程在区间内
**至多只有一个候选 `q`**。这个唯一候选就是满足可达性低位的
`q0(A)=(-A·5^{-k} mod 2^{Wj})`，问题收缩为验证 `q0(A)` 是否还满足
完整方程 `(E)`。

## 4. 开放子引理（第三步）

**开放子引理（必要且充分的闭合目标）。** 对每个 `δ=0` 可达词前缀
`(A,W,k)` 与每个满足 `H=2k+13-2(W-Wp)≥3` 的坏参数
`(n,K0)`，不存在整数 `m≥0` 使

```text
q(m) = (C0 + 3m·2^{W+n+H+1}) / (3·5^{n+k+1})
```

满足 `2^{Wp} ≤ q(m) < 2^{Wj}`，其中 `C0` 如第 3 节。

若该子引理成立，则坏 `X=2` 游程不可达，局部引理的两个剩余类避让
语句（A）闭合；`X=1` 链（B）可按同一 `K` 框架对称处理。

## 5. 当前已知的强度边界

- 小 `k`、小 `d` 时 `5^{n+1}` 与 `q` 的跳跃量大于区间长度，候选
  `m` 唯一或为空，推论 2.3 的模 5 检查可直接排除若干小 `K`；
- 紧路径（`k=34`、`d=37`、`tj=2`、`n=1`）下，仅由
  `K≡K0 mod 5^{n+1}` 与 `K` 窄窗口得到的候选 `K` 数约为
  `2^{37}`；但再要求 `q` 为整数且落入短区间后，每个前缀至多剩一个
  候选 `q`，所以剩余必须使用 `A` 的词结构来验证该唯一候选不满足
  `(E)`；
- 因此本文不替代证书，也不声称闭合；它把缺口压缩成第 4 节
  关于 `A` 的单一 Diophantine 子引理。

## 6. 唯一被强制的块首分子 `A_j`（2026-08-09 续）

本节把第 3 节的候选进一步压到块首分子。设 `i=k+n`、
`L=i-j`、`W_i=W_k+n`，并记块尾完整分子

```text
S = Σ_{s=j}^{i-1} 5^{i-1-s} 2^{W_s}.
```

用 `A_i=5^L A_j+S` 代入坏出口方程，得到精确整数方程

```text
2^{W_i+H+1}K = 5^{L+1}A_j + 5S + 3·2^{W_i} + 5^{i+1}q.   (F)
```

**引理 6.1（充要）。** 对固定块尾词 `(S,W_i)` 与坏参数
`(n,H,K0)`，方程 `(F)` 有解且 `K≡K0 (mod 5^{n+1})` 当且仅当

```text
K5 ≡ K0  (mod 5^{n+1}),
K5 := (5S+3·2^{W_i})·2^{-(W_i+H+1)} mod 5^{L+1},
```

且此时 `K=K5+5^{L+1}m`（`m≥0`），`A_j` 被唯一写成

```text
A_j = A0 + 2^{W_i+H+1} m - 5^j q,
A0 := (2^{W_i+H+1}K5 - 5S - 3·2^{W_i}) / 5^{L+1}.
```

证明：`(F)` 模 `5^{L+1}` 时 `5^{L+1}A_j≡0`、`5^{i+1}q≡0`，故
`K5` 由块尾词唯一决定；再由 `K≡K0 mod 5^{n+1}` 且
`L+1≥n+1` 得到 `m` 的参数化，代回 `(F)` 即得 `A_j` 公式。∎

**引理 6.2（逐 q 唯一，充要）。** 在归纳范围 `j≥17` 上，
`2^{W_i+H+1} ≥ 2^{3j+11} > 5^j`。因此对每个
`q∈[2^{Wp},2^{Wj})`，至多一个 `m≥0` 使
`A_j=A0+2^{W_i+H+1}m-5^j q` 落在 `[0,5^j)`；换言之，坏游程的
候选按 `q` 参数化，每个 `q` 至多对应一个块首分子
`A_j`。

证明：`A_j` 作为 `m` 的函数步长为 `2^{W_i+H+1}`，而
`W_i+H+1 ≥ n+3j+14-2tj ≥ 3j+11`；`5^j<2^{3j+11}`，故
`A_j∈[0,5^j)` 的 `m` 区间长度小于 `1`。∎

**推论 6.3（第三步的精确形式）。** 坏 `X=2` 游程不可达当且仅当
对每个 `δ=0` 可达块尾词与每个 `q∈[2^{Wp},2^{Wj})`，引理 6.1 的
`K5≡K0 mod 5^{n+1}` 不成立，或引理 6.2 的对应 `A_j` 不是长度
`j`、权重 `W_j` 的 `{1,2}` 词前缀分子（例如不满足
`A_j≤5^j-4^j`，或基 5 数字不是幂次 `2^{W_s}`）。

这说明目标第三步完全落在 `A_j` 的词结构上；`q` 已通过
`q=(2^{W_j}r_j-A_j)/5^j` 与 `0≤A_j<5^j` 参数化，剩余是对每个
`q` 验证唯一 `A_j` 不可实现。

## 7. `{1,2}` 词前缀分子的递归判定（第三步的形式目标）

`wordA` 的定义递推为

```text
A_0=0,  W_0=0,
A_{s+1}=5A_s+2^{W_s},  W_{s+1}=W_s+t_{s+1},  t_{s+1}∈{1,2}.
```

因此对长度 `j`、总权重 `W_j`，整数 `A_j` 是某个 `{1,2}` 词前缀
分子当且仅当存在 `t∈{1,2}` 使

```text
A_j ≡ 2^{W_j-t}  (mod 5),
A_{j-1} := (A_j-2^{W_j-t})/5
```

是非负整数，且 `A_{j-1}` 是长度 `j-1`、权重 `W_j-t` 的 `{1,2}`
词前缀分子；基例 `j=0` 时 `A_0=0`、`W_0=0`。

证明：按 `A_j=5A_{j-1}+2^{W_{j-1}}` 与 `W_j-W_{j-1}=t∈{1,2}`
直接拆最后一步；反向由递推拼回。∎

**推论 7.2（唯一贪心剥离，充要）。** 在递归判定的每一步，至多
一个 `t∈{1,2}` 能满足同余 `A_s≡2^{W_s-t} (mod 5)`；因此若
`A_j` 是词前缀分子，其词形由贪心剥离唯一决定：

```text
t_s 是唯一的 t∈{1,2} 使 A_s ≡ 2^{W_s-t} (mod 5),
A_{s-1}=(A_s-2^{W_s-t})/5,  W_{s-1}=W_s-t.
```

若某步不存在这样的 `t`、或 `A_{s-1}<0`、或在 `j` 步后
`A_0≠0`，则 `A_j` 不是 `{1,2}` 词前缀分子。

证明：`2^{W-1}≡2·2^{W-2} (mod 5)` 且 `2≢1 (mod 5)`，故两个候选
末步模 5 余类不同；唯一性由第 7 节递归判定直接给出。∎

**开放子引理 7.1（词结构，第三步的精确目标）。** 对第 6 节中由
块尾词与坏参数得到的每个 `A_j`，递归判定在第 `j` 步之前必然失败，
即不存在合法的末步步长 `t`，或剥离后得到的 `A_{j-1}` 越界
（`A_{j-1}≥5^{j-1}`），或递归进入无解分支。

这是“对应 `A_j` 不是 `{1,2}` 词的可达前缀分子”的严格等价形式；
它只使用 `ReachableWindow` 的词递推，不引入 PMI 或整循环恒等式。

## 8. 候选计数界（必要，新）

对固定块尾词，坏游程的候选按 `q` 参数化；对每个 `m≥0`，
`A_j∈[0,5^j)` 把 `q` 限制在长度 `1` 的区间内，因此候选数至多为
区间 `[5^j·2^{W_p}, 5^j(2^{W_j}+1))` 内 `step=2^{W_i+H+1}` 的倍数
数。若

```text
5^j(2^{W_j}+1) < 2^{W_i+H+1},
```

则该区间长度小于 `step`，候选数至多 `1`。代入
`W_i+H+1 = W_j + 2j + 2L0 + n + 14 - d - 2tj` 且 `d≤2L0`，
条件化为

```text
0.321928j + log2(1+2^{-W_j}) + 2tj - n - 14 < 0.
```

因此当 `0.321928j + 2tj - n - 14 < 0` 时（在 `n≥1`、`tj≤2` 下即
`j≤34`），每个块尾词至多有一个候选 `q`（含边界时也至多一个）。
这是必要条件的计数层；它把 `j≤34` 的情形压缩成“单候选是否存在”
的判定，但单候选仍需第 7 节的词结构检验，未自动排除。

对 `j≥35`，该计数界允许多个候选，剩余必须使用 `A_j` 的词结构
（第 7 节）而非单纯计数。

## 9. 全块尾词的候选总量（死路记录，必要）

把第 8 节的单词候选数对全部可达块尾词求和。块尾词由长度 `L0`、
权重 `d=L0+h0` 的 `{1,2}` 词再接 `n` 步 `t=1` 组成；容量条件在首次
失败前成立，给出 `h0≤j-t_j+5`。对固定 `(L0,h0)` 有
`C(L0,h0)` 个词，且

```text
Σ_{L0≥h0} C(L0,h0)·2^{-L0} = 2,
```

于是全部候选总量上界为

```text
2^{0.321928j+2tj-n-14} · Σ_{h0=0}^{j-tj+5} 2^{h0}·2
  ≈ 2^{1.321928j+tj-n-7}.
```

该量随 `j` 指数增长（`j=17` 时约 `2^{16}`），因此**单纯计数不能
排除全部候选**。这是死路记录：闭合必须依赖第 7 节的贪心词结构
检验与 `A_j` 的具体同余，而不是对候选总数做界。

## 10. 阻塞审计（2026-08-09 续）

当前唯一开放子引理（第 7.1 节）在连续多轮中反复收敛到同一阻塞点：

```text
对每个 δ=0 可达块尾词与每个 q∈[2^{Wp},2^{Wj})，
第 6 节公式给出的唯一 A_j 不通过第 7 节的贪心词结构检验。
```

已确认无法由以下工具单独闭合：

- 候选计数（第 8、9 节）：总量随 `j` 指数增长，不排除；
- 模 5 / 模 `5^{n+1}` 同余：由游程结构自动满足，不产生新约束；
- 唯一贪心剥离（推论 7.2）：只是把词结构检验变成确定性算法，
  没有给出 `A_j` 必然失败的原因；
- 尺寸界 `A_j<5^j`、`A_j≤5^j-4^j`：与候选 `A_j` 的构造不矛盾。

继续推进需要新的结构输入，例如：

1. 用 `A_j=A0+2^{W_i+H+1}m-5^j q` 与贪心剥离逐位展开，证明第
   `s` 步的剥离商必然越界；
2. 或证明候选等差数列与 `{1,2}` 词分子集合之间存在模
   `5^j` 的显式空隙；
3. 或给出 `ReachableWindow` 中 `A_j` 的更强词结构不变量。
