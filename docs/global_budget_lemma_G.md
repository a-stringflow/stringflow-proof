# 全局预算分裂引理 G：解析笔记

状态：第 1--6 节为严格推导（第 5 节含 2026-08-09 的 `R_n`
递推修正）；第 7 节是剩余开放子引理，未声明闭合。

## 1. 记号

固定 `δ=0` 块：块首 `j`，`Wp=W_{j-1}`，`Wj=W_j`，`tj=Wj-Wp∈{1,2}`。
块内 `u=1` 状态链记为 `p_0<p_1<...`。对链上状态 `p_k`：

- `a_k = v2(5r_k+3)/2`
- `C_k = (5r_k+3)/2^(2a_k)`
- `m_k = H_k - 2a_k`
- `B_k = m_k + 2`
- `D_k = W_k - Wp`

## 2. 宏步链严格递推（恒等式，充分必要）

由宏步闭式：

```text
5^(a_k)*C_k - 1 = 2^(2a_{k+1}-1)*C_{k+1}
m_{k+1} = m_k + 2 - 2a_{k+1}
p_{k+1} = p_k + a_k
D_{k+1} = D_k + 2a_k - 1
```

这些是恒等式；其中第一条要求下一步非终止且 `v2(5^(a_k)C_k-1)=2a_{k+1}-1`。
由第二条：

```text
m_{k+1} >= 0  ⇔  2a_{k+1} <= B_k
```

因此局部引理在 `p_{k+1}` 成立等价于 `2a_{k+1} <= B_k`；首次失败等价于
`m_{k+1}<0`，即 `2a_{k+1} >= B_k+1`。

## 3. 首次失败整数方程

设首次失败发生在宏步 `k`，则：

```text
5^(a_k)*C_k - 1 = 2^(m_k+2)*T,   T∈N
```

若恰好 `v2(5^(a_k)C_k-1)=m_k+2` 且下一步非终止，则 `T=C_{k+1}`。

## 4. 唯一 q 残差类（必要且充分）

由

```text
2^(W_k)*(5r_k+3) = 5A_k + 3*2^(W_k) + 5^(p_k+1)*q
```

得

```text
C_k = (5A_k + 3*2^(W_k) + 5^(p_k+1)*q) / 2^(W_k+2a_k)
```

失败同余等价于

```text
q ≡ q*_k  (mod 2^(W_k+H_k+2))
```

其中

```text
q*_k =
  (2^(W_k+2a_k) - 5^(a_k)*(5A_k+3*2^(W_k)))
  * 5^(-(p_k+a_k+1))
  mod 2^(W_k+H_k+2)
```

因 `q<2^(W_k)`，失败还要求 `q*_k<2^(W_k)` 且 `q=q*_k`。

## 5. 递归到链头（严格恒等式）

设从链头 `p_0` 起共 `n` 个宏步后首次失败于 `p_n`。反向消去
`C_{n-1},...,C_1`，得链头精确恒等式：

```text
5^(S_n)*C_0 - R_n = C_n * 2^(m_0+n-m_n)
```

其中

```text
S_n = a_0 + ... + a_{n-1}
R_1 = 1
R_n = 5^(a_{n-1})*R_{n-1}
      + 2^(2(a_1+...+a_{n-1})-(n-1))         (n>=2)
```

**修正（2026-08-09）。** 旧版写 `R_n = 5^(a_{n-1})R_{n-1}
+ 2^(2a_{n-1}-1)`，该式对 `n=2` 成立，但对 `n>=3` 不成立。
反解三步可验证正确末项指数是 `2(a_1+...+a_{n-1})-(n-1)`；
旧式会少掉 `2^(2(a_1+...+a_{n-2})-(n-2))` 量级的项，使第 6 节
的 `q*` 显式式在长链上失真。修正后该恒等式逐项精确。

证明：对 `n` 归纳，反向一步用
`C_{j+1}=(5^(a_j)C_j-1)/2^(2a_{j+1}-1)`；乘回去时，第 `k`
个分母 `2^(2a_k-1)` 之后每乘一个 `5^(a_j)` 会产生一个仿射项，
累加得到上述递推。

## 6. 链头到块首的 q* 显式形式（严格）

若块首经 `n0` 个 `t=2` 步到达链头，则 `u_j=2n0+1`，且

```text
C_0 =
  ( 5^(n0+1)*(A_j+5^j*q+2^(W_j))
    - 2^(W_j+2n0+1) )
  / 2^(W_j+2n0+2a_0)
```

代入第 5 节恒等式，得唯一候选

```text
q* ≡ 5^(-(S_n+n0+1+j)) * (
  5^(S_n)*2^(W_j+2n0+1)
  + 2^(W_j+2n0+2a_0)*R_n
  - 5^(S_n+n0+1)*(A_j+2^(W_j))
)  (mod 2^(M_n))
```

其中

```text
M_n = W_j + 2n0 + 2a_0 + m_0 + n + 1
    = Wp + 2j + 14 - tj + n
```

因 `q<2^(W_j)` 且 `M_n-W_j = 2j+14-2tj+n>0`，首次失败等价于
`q=q*` 且 `q*<2^(W_j)`。低 `W_j` 位自动满足
`q* ≡ -A_j*5^(-j) (mod 2^(W_j))`，这正是块首可达性
`A_j+5^j*q=2^(W_j)*r_j` 的同余；排除必须看 `W_j` 以上的位。

一致性检查：把 `q* - q` 用块首纯 `t=2` 游程
`r_j+1=2^(2n0+1)*s` 与 `C_0=(5^(n0+1)s-1)/2^(2a_0-1)` 展开后，
`q*=q` 等价于链头同余 `5^(S_n)*C_0≡R_n (mod 2^(m_0+n+1))`。
因此第 6 节的 `q*` 与第 5 节递归自洽，排除子引理正是原进位缺口的等价形式。

## 7. 排除子引理（开放）

剩余要证：

```text
q* ∉ [2^(Wp), 2^(W_j))
```

对任意可达词、宏步链与首次失败长度 `n` 成立。

### 7.1 提升量 `L` 的精确恒等式（2026-08-09 新增，充要）

写 `q*` 的最小非负代表为 `q*_0`，并设

```text
q*_0 = q + 2^(W_j) * L,        L ∈ {0,1,...,2^(M_n-W_j)-1}
```

把第 5 节恒等式代入 `q*` 定义并消去 `A_j`（用
`A_j+5^j q=2^(W_j) r_j`），得到精确同余

```text
5^(S_n+n0+1+j) * L
≡ -2^(2n0+2a_0) * (5^(S_n)C_0 - R_n)
  (mod 2^(M_n-W_j))
```

再由第 5 节的精确恒等式 `5^(S_n)C_0 - R_n
= 2^(m_0+n-m_n) C_n`，其中 `m_n` 是失败候选状态 `p_n` 的余量
（`m_n = H_n - 2a_n`，恒为奇数），得核心闭式：

```text
L ≡ -5^(-(S_n+n0+1+j)) * 2^(2j+13-2tj+n-m_n) * C_n
    (mod 2^(2j+14-2tj+n))
```

等价地，令 `M_extra = M_n - W_j = 2j+14-2tj+n`，则

```text
v_2(L) = M_extra - 1 - m_n      （当 m_n >= 0）
L = 0                           （当 m_n <= -1）
```

只要 `v_2(L) < M_extra`（即 `m_n >= 0`），就有 `L ≠ 0`，从而
`q*_0 ≥ q + 2^(W_j) ≥ 2^(W_j)`，失败被排除；而 `m_n <= -1`
时 `L ≡ 0 (mod 2^(M_extra))` 且 `0 <= L < 2^(M_extra)`，迫使
`L=0`，即 `q*_0 = q`。因此：

```text
局部引理在 p_n 成立（m_n >= 1）
  ⇔  v_2(q*_0 - q) < W_j + M_extra
  ⇔  L ≠ 0
```

这是“坏残差不在 `q` 区间”的严格同构形式，仍未闭合；闭合任务
等价于证明对每个可达链，`v_2(q*_0 - q)` 小于
`W_j + M_extra`。`C_n` 为奇数，故上式还给出：失败与否完全由
`m_n` 与 `q*_0 - q` 的 2-adic 赋值一致决定，不存在中间态。

### 7.2 最小反例的预算结构（2026-08-09 新增，必要）

设首次失败在宏步 `n-1 -> n`，则对所有更早端点均成功。记
`T_n = a_0 + ... + a_n`，则余量

```text
m_n = 13 - 2E_0 - 2T_n + 2n
```

其中 `E_0 = n0 + tj - j`。于是（均为整数等价，必要且充分）：

- 成功 `m_j >= 1`  ⇔  `T_j <= j + 6 - E_0`；
- 失败 `m_n <= -1`  ⇔  `T_n >= n + 7 - E_0`；
- 首次失败因此推出 `a_n = T_n - T_{n-1} >= 2`。

`m_k = H_k - 2a_k` 恒为奇数，所以不存在 `m=0` 的临界态；余量
从成功跳到失败时至少跨过 2。这给出失败宏步参数的窄下界：

```text
2a_n - 1 >= m_{n-1} + 2,     a_n >= 2
```

配上最小代表元给出的上界

```text
2a_n - 1 < (p_n+1)λ - 2a_{n-1},      λ = log_2 5
```

得到失败步的窄区间。`q*` 的 5-adic 唯一性进一步说明：固定块尾
词与 `a_n` 后，`C_n` 由
`2^(W_n+2a_n) C_n ≡ 5A_n+3·2^(W_n) (mod 5^(p_n+1))`
唯一决定（`C_n < 5^(p_n+1)`），从而 `q` 也被唯一决定；因此整个
排除问题是单个 `q*` 的窗口判定，不是区间扫描。

### 7.3 重置回代：前一块终端的精确方程（2026-08-09 新增，必要）

设当前块首为 `j`，上一块的偶数终端为 `e=j-1`。上一块终端结构
（`local_lemma_s6_reduction.md` 第 9 节）为

```text
r_{j-1} + 1 = 5^(k0) * s'',      s'' 为奇数，k0 >= 0
```

重置步满足

```text
2^(t_j) * r_j = 5 * r_{j-1} + 1 + δ*5^j,     1 <= δ < 2^(t_j)
```

链头处 `r_j + 1 = 2^(2n0+1) * s`，`s` 为奇数。消去 `r_j` 得精确
方程（必要且充分）：

```text
N := 2^(t_j+2n0+1) * s - 2^(t_j) + 4 - δ*5^j
   = 5 * (r_{j-1} + 1)
   = 5^(k0+1) * s''
```

第 5 节恒等式还给出 `s` 的精确表达式：

```text
5^(S_n+n0+1) * s
= 5^(S_n) + 2^(2a_0-1) * R_n
  + C_n * 2^(m_0+n-m_n+2a_0-1)
```

因此对首次失败候选（`m_n <= -1`、`a_n >= 2`），上式唯一确定
`k0 = v5(N)` 与 `s'' = N / 5^(k0+1)`。候选必须同时满足：

1. `N > 0` 且 `N ≡ 5 (mod 10)`（等价于 `s''` 为奇数）；
2. `s'' < 5^(j-1-k0)`（等价于 `r_{j-1} < 5^(j-1)`）；
3. `s''` 必须是上一块可达偶数终端的奇部；若上一块含 `u=1`
   状态，其局部引理成立的必要条件是 `H_{j-1} >= 1`
   （`k0>0` 即 `t=2` 终止时等价于 `H_{j-1} >= 1`），且 `k0`
   与上一块的终端 `t=2` 链长、`h_{j-1}`、`H_{j-1}` 有确定关系；
4. `q` 区间 `[2^(Wp),2^(W_j))` 给出
   `s ∈ [5^j * 2^(-(tj+2n0+1)), 5^j / 2^(2n0+1))`，与 `δ`
   区间合并后把 `s` 限制在短区间内。

最小反例方向：若上述方程在某 `δ` 与链参数下成立且产生合法
`(k0,s'')`，则沿上一块递归得到更小深度的失败候选（或矛盾）；
若对每个 `δ` 都失败，则当前块失败被排除。这一步把 `q*` 窗口
冲突显式化为“前一块终端奇部 `s''` 的 5-adic 结构冲突”，是当前
剩余开放语句的最精确形式。该段全部为必要条件，未声明闭合。

### 7.4 m_n 无关的估值控制（2026-08-09 新增，充要）

把第 5 节恒等式代入第 7.1 节的提升量闭式后，`m_n` 与 `C_n`
同时消去，得到第一个不依赖失败余量的估值控制。

**引理 7.4.1（m_n 无关提升量，充要）。** 令

```text
Num0 = 5^(S_n)*C_0 - R_n
```

则

```text
L ≡ -5^(-(S_n+n0+1+j)) * 2^(2n0+2a0) * Num0  (mod 2^(M_extra))
```

由此得到三个等价语句（均为充要）：

1. `L = 0` ⇔ `2^(m0+n+1) | Num0`；
2. 局部引理在 `p_n` 成立 ⇔ `2^(m0+n) ∤ Num0`；
3. 估值控制 `v_2(Num0) <= m0+n-1` 不出现 `m_n`。

证明：由第 5 节恒等式
`Num0 = C_n * 2^(m0+n-m_n)` 得

```text
2^(M_extra-1-m_n)*C_n
= 2^(2n0+2a0) * 2^(m0+n-m_n) * C_n
= 2^(2n0+2a0) * Num0
```

代入第 7.1 节同余即得。`m_n` 恒为奇数，故 `v_2(Num0)=m0+n-m_n`
不可能等于 `m0+n`，于是第 2 条等价于 `m_n >= 1`。∎

这是原进位缺口的第一个 m_n 无关形式：目标已变为纯 2-adic 估值
`v_2(5^(S_n)C_0 - R_n) <= m0+n-1`，不再出现失败余量 `m_n`。

**引理 7.4.2（前块奇部残差，充要）。** 记 `E=S_n+n0+1`，
`M_s = 2j - t_j + 13 + n`。则 `p_n` 失败当且仅当

```text
s'' ≡ 5^(-(E+k0+1)) * (
  2^(t_j+2n0+1)*5^(S_n)
  + 2^(t_j+2n0+2a0)*R_n
  - 5^E*(2^(t_j)-4+δ*5^j)
)  (mod 2^(M_s))
```

其中同余右端的模指数 `M_s` 只依赖 `j,t_j,n`，与 `n0`、`m_n`
无关。证明：由

```text
5^E*s = 5^(S_n) + 2^(2a0-1)*R_n + 2^(2a0-1)*Num0
```

与重置方程

```text
2^(t_j+2n0+1)*s = 5^(k0+1)*s'' + 2^(t_j)-4+δ*5^j
```

相乘后代入 `Num0 = C_n*2^(m0+n-m_n)`。失败 `m_n<=-1` 等价于
`2^(H_0+n-1) | (5^E*s - 5^(S_n) - 2^(2a0-1)*R_n)`，整理即得。∎

**推论 7.4.3（必要，m_n 无关尺寸窗）。** 若 `p_n` 失败，令
`F_s` 为引理 7.4.2 右端模 `2^(M_s)` 的最小非负剩余，则

```text
0 < F_s < 5^(j-1-k0)
```

特别地，若对给定链参数 `F_s = 0` 或 `F_s >= 5^(j-1-k0)`，则
当前失败被排除。这是把估值控制翻译成前块奇部 `s''` 的尺寸条件，
全部必要条件，未声明闭合。

**引理 7.4.4（纯链参数预算形式，充要）。** 记

```text
K = j - t_j + 6 - n0 - a0 = (m0-1)/2
```

则局部引理在 `p_n` 成立等价于

```text
B_n := Σ_{i=1}^{n}(a_i-1) <= K
```

证明：由余量递推 `m_n = m0 - 2B_n` 与 `m_n` 为奇数，直接代入
`m_n >= 1` 即得。∎

这是估值条件的纯 `a_i` 形式：失败恰为累计增量 `B_n` 首次越过
`K`。它与 `h_n+a_n <= j-t_j+6` 等价，不再出现 `m_n`、`q*` 或
`C_n`。

**引理 7.4.5（宏链乘积恒等式，精确）。** 沿宏步递推有

```text
Num_n = 5^(S_n) * C_0 * Π_{i=0}^{n-1} (1 - 1/(5^(a_i)*C_i))
```

其中 `Num_n = 5^(S_n)C_0 - R_n`。证明：由
`C_{i+1} = (5^(a_i)C_i - 1)/2^(2a_{i+1}-1)` 逐项相乘并代入
第 5 节恒等式即得。每个因子都在 `(0,1)` 内，且
`C_i < 5^(p_i+1)/4^(a_i)` 给出

```text
1 - 4^(a_i)/5^(p_{i+1}+1) < 1 - 1/(5^(a_i)C_i) < 1
```

因此 `v_2(Num_n) = Σ_{i=0}^{n-1}(2a_{i+1}-1)`，与引理 7.4.4
的预算形式一致。该乘积是后续沿宏链做估值归纳的精确入口；
仍未闭合。

**引理 7.4.6（失败的必要尺寸条件，m_n 无关）。** 若 `p_n` 失败，
则 `C_n >= 3`、`C_0 < 5^(n0+1+j)/2^(2n0+2a0)` 与
`Num_n < 5^(S_n)C_0` 合并给出

```text
3 * 2^(2j-2t_j+n+14) < 5^(S_n+n0+1+j)
```

即

```text
(S_n+n0+1+j) * log(5) > (2j-2t_j+n+14) * log(2) + log(3)
```

这是失败的必要条件，不出现 `m_n`；它把失败压到
`S_n >= ~0.86j + O(n)` 的尺寸窗。再由 `q` 区间下界
`s > 5^j/2^(t_j+2n0+1)` 与 `C_0 = (5^(n0+1)s-1)/2^(2a0-1)`
得第二个必要条件（精确）

```text
5^(S_n) * (5^(n0+1+j)/2^(t_j+2n0+2a0) - 1)
  * Π_{i=0}^{n-1}(1 - 1/(5^(a_i)C_i))
  < 5^(p_n+1) * 2^(v_n-2a_n)
```

其中 `v_n=2(a_1+...+a_n)-n`。该式是宏链乘积下界与
`C_n < 5^(p_n+1)/4^(a_n)` 上界的精确比较；尺寸层尚未封口，
缺口仍需要 `C_i` 的 5-adic 残差或 `s''` 三态形式。

**死路记录（2026-08-09，避免重复）。** 曾尝试用
`C_{k+1} ≡ -2^(-(2a_{k+1}-1)) (mod 5^(a_k))` 与
`5^(a_{k+1})C_{k+1} ≡ 1 (mod 2^(2a_{k+2}-1))` 的 CRT 模
`5^(a_k)2^(2a_{k+2}-1)` 给出 `C_{k+1}` 的大小下界，从而约束
`a_{k+2}`；该路线无效：CRT 最小正解可以远小于乘积模，不能由
模长推出 `C_{k+1}` 下界。实际宏链上该“CRT 大小不等式”有违反
（示例 `a=(2,1,1,1,2)`），故不得作为闭合入口。

**衔接。** 上一块终端奇部 `s''` 恰为 `k4b_equality_gap.md` 第
5.1 节的 `C'_N` 三态形式；把三态形式代入引理 7.4.2 的同余后，
剩余缺口变成对 `(w,u,k,e,j,δ)` 的纯 2-adic/5-adic 相容性，
不再出现 `m_n`。

**已知的局部事实（修正）：** `q*_0` 的低 `W_j` 位等于
`q`，因此 `q*_0` 的奇偶性与 `q` 相同，不恒为奇数；旧版
“`q*` 必为奇数”的说法不成立，奇偶性不足以排除区间。

- `q*` 正是块首处坏残差窗口的抬升残差；本子引理与原来的
  `q_V>=2^W` 进位缺口等价。
- 若从 Q 递推写成整数
  `G_n = 2^(W_0+2a_0)*C_0*5^(S_n)

  其中 `T_k=Σ_{i=k+1}^{n-1}a_i`，则 `G_n =

  `2^(E_n)|G_n`，`E_n=W_0+H_0+n+1`。由第 5 节恒等式得精确式
  `G_n = 2^(E_n-m_n-1)*C_n`；失败时 `m_n<=-1` 恒有
  `G_n >= 2^(E_n)`，因此“短链尺寸排除 `G_n<2^(E_n)`”在该
  定义下是空条件，不能作为入口（旧版该条作废）。
