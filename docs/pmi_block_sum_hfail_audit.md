# PMI 块层求和与 hfail 审计

日期：2026-08-15

状态：**块层模板已经写出，但尚未闭合**。本文不把开放不等式伪装成
已证结果。

## 1. 记号

设闭合周期词 `w` 的长度为 `P`，总权重为 `S`。把词按 C3 步切成
`K` 个 `δ=0` 块。对第 `r` 个块：

```text
j_r   : 块首重置深度
t_r   : 块首重置步权重，t_r ∈ {1,2}
u_r   : v2(r_{j_r}+1)
L_r   : 块内 rise 步数
H2_r  : 块内 t=2 步数
F_r   : 块内所有极大 t=1 游程的正部充值之和
```

块的局部余额是：

```text
2 H2_r ≤ u_r + F_r.                       (1)
```

失败窗口条件是：

```text
u_r ≥ 2(j_r - t_r) + 13.                  (2)
```

## 2. 目标

证明：

```text
闭合周期词
⇒ 存在某个 r 使 (2) 成立。
```

等价地，假设所有块都满足：

```text
u_r ≤ 2(j_r - t_r) + 12,                  (3)
```

推导与周期 PMI 方程矛盾。

## 3. 已能写出的求和

对所有块使用 (1)：

```text
2 Σ_r H2_r ≤ Σ_r u_r + Σ_r F_r.
```

在假设 (3) 下：

```text
2 Σ_r H2_r ≤ Σ_r [2(j_r - t_r) + 12] + Σ_r F_r.   (4)
```

这是文档中已经写出的求和，没有新数学。

令：

```text
H2 = Σ_r H2_r
F  = Σ_r F_r
C1 = Σ_r (L_r - H2_r)
R  = C1 + 2 H2
C  = 所有 C3 步的总权重
S  = R + C
Q  = C3 步数
```

周期闭合给出：

```text
2^S > 5^P,
S > P log_2 5.                            (5)
```

## 4. 唯一缺失的全局比较

要从 (4) 和 (5) 推出某个 `r` 满足 (2)，目前还缺少一条显式界：

```text
2 H2 > Σ_r [2(j_r - t_r) + 12 + F_r].      (6)
```

因为 (1) 等价地重写为：

```text
u_r ≥ 2 H2_r - F_r.
```

所以若 (6) 成立，则至少存在一个块满足：

```text
u_r ≥ 2(j_r - t_r) + 13,
```

这正是 `hfail`。

因此，块层求和目前精确地停在：

```text
(1) + (3) + (4) + (5)
⇒ 还需证明 (6)
⇒ hfail
```

文档 `cycle_bridge_window_to_no_cycle.md` 第 2.3.1 节写
“剩余开放不等式”的位置，就是 (6)。

## 5. 不能把 F 无条件消掉的原因

若直接假设：

```text
F_r = 0
```

则只剩纯 `t=2` 块，这不是一般块层分解。一般块中 `t=1` 游程会产生
正的 `F_r`。要把 (6) 从 PMI 周期方程推出，必须给出：

```text
Σ_r F_r
```

与 `C1,C2,C3,P,S` 之间的一个全局上界。现有 `rise_block_balance` 只
给出局部方向：

```text
2 H2_r ≤ u_r + F_r,
```

它本身不给出 `F_r` 的上界，也不能产生反向
`F_r ≤ ...`。

## 6. 当前结论

因此按仓库现有材料：

```text
hfail 仍未由 PMI 块层求和推出。
```

准确剩余是证明全局比较 (6)，或证明一个等价的块权重预算：

```text
Σ_r F_r ≤ 2(j_r - t_r) + 12 - u_r
```

对所有避块成立。这条等价式闭合后，才能说 `hfail` 只是 Lean 接线。
