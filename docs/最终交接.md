## 容易犯的错误

1. **13 影子不是形式反模型。** 13 循环 `(13,33,83)` 的词
   `[1,1,5]` 满足除 `hstart`/`hcycle` 外的结构字段，但不是 7 轨道
   合法输入。禁止用“13 模型满足全部结构字段 / 13 反例”作为不可证
   理由或形式反例；13 的排除发生在真实 hcycle 词与 selected 块层
   （无 `w=2` 前缀、rise 段长度 2 不满足 `SelectedBlockData.hLge3`），
   不需要在定理签名里“现在排除 13”。
2. **不要用过强充分条件。** `nonTwoSumFrom w 0 < 2H2` 比
   `Σ(endpoint+6) < 2H2` 强，`[2^7,1,5]` 上失败而后者成立；正确
   义务是 endpoint 和式，不要退回位置和式。
3. **逐项比较陷阱。** `2·start + 12 ≤ 2·length` 对短游程（例如
   `(0,1)`）为假；单项假不表示总和不可证，必须做 aggregate。
4. **方向陷阱。** `t2RunRankSumGtBoundSum_imp_exists_long_run` 是
   `U < L ⇒ 存在长游程`；反向“存在长游程 ⇒ U < L”不成立，也不是
   中间式。
5. **真实轨道锚点。** 新 rank 引理签名必须显式含至少一个 hcycle
   锚点：`m = fiveXPlusOneOrbit 7 c`、`w = cycleWord c p`、
   `fiveXPlusOneOrbit 7 (c+j)` 或 `hstart` 的 `n0`。只用结构字段
   的证明会被 13 影子穿透。
6. **“仓库没有现成引理”不是停止理由。** 缺的引理就是任务本身；
   先写 concrete 引理并编译，再谈方向。未写就先宣布“推不出”按
   未动手处理。
7. **禁止“Let me reconsider / 重新对齐”停顿。** 没有新失败点就
   继续写证明；reconsider 必须一句话说明要改什么。
8. **omega / ring 不能混用。** `omega` 处理线性算术，`ring` 处理
   环归一化；Nat 减法截断要喂足 `≤` 前提。
9. **端点重排用加法形式。** `U + 2H2 = 2Σe + 12R`，避免
   `2Σe − 2H2` 的 Nat 减法问题。
10. **数值前缀不是合法实例。** 原始 7 轨道前缀不满足闭环等全部
    前提，禁止用 Python 扫描原始前缀当反例或验证依据。
