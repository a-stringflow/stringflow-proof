# L-B′ U=2：精确归约与唯一剩余不等式

日期：2026-08-11

状态：本文给出 U=2 的精确代数归约，并把目标压缩为一条关于 CRT
最小正解的指数不等式。它不是完整解析证明；唯一剩余项在最后一节。

## 1. 记号与精确方程

设上升词长度为 `L`，其中恰好两个 `t=2` 步，位置为 `j1 < j2`，
末项 `t_{L-1}=1`。令

```
m1 = j1+1,  m2 = j2+1,  d = m2-m1,
S = L+2,    e = L-m1.
```

由 `2U ≤ L+1` 得 `L ≥ 3`；由末项为 1 得 `1 ≤ m1`、`m2 ≤ L-1`、
`1 ≤ d ≤ L-2`。

令 `r = r(w)` 为最小起点，`c = 3r+1`。文档第 7 节的精确方程等价于

```
5^m2 c = 2^L Q - R,
Q = (40 + 96k) / 5^(L-m2),   k ≥ 0 整数,
R = 2^(m2+1) + 2^m1·5^d.
```

记 `B = 2^(d+1) + 5^d`，则 `R = 2^m1 B`。

## 2. 归约到 γ

由 `5^m2 c = 2^L Q - 2^m1 B = 2^m1(2^e Q - B)`，且
`gcd(5^m2, 2) = 1`，得

```
2^m1 | c,    c = 2^m1 γ,    γ = (2^e Q - B) / 5^m2 ≥ 1.
```

于是

```
r = (2^m1 γ - 1) / 3.
```

对 `γ` 取模 `2^e`：`B = 2^(d+1)+5^d`，而 `e ≥ d+1` 只能推出
`2^(d+1) ≡ 0 (mod 2^e)` 在 `e = d+1` 时成立；一般情形
`e > d+1`，不能把 `B` 换成 `5^d`。从 `5^m2 γ ≡ -B (mod 2^e)`
得正确同余

```
5^m1 γ ≡ -(1 + 2^(d+1)·5^(-d))  (mod 2^e).
```

令 `g` 为上式模 `2^e` 的最小正剩余，则
`γ = g + 2^e h`，`h ≥ 0`。

## 3. 已解析下界

**下界 I。** 因为 `γ ≥ 1`，

```
r ≥ (2^m1 - 1)/3.
```

**下界 II（修正）。** 旧版本由错误同余
`5^m1 g + 1 = 2^e h0` 写出的第三条下界不成立；正确同余是
`5^m1 g ≡ -(1+2^(d+1)·5^(-d)) (mod 2^e)`，它不再给出整数
`h0`。因此当前可用的无条件下界只有：

```
r ≥ (2^m1 - 1)/3,
```

以及 `h≥1` 时的 `r ≥ (2^L - 1)/3`。旧“其他类弱界由两条下界
闭合”的结论撤销。

## 4. 唯一剩余不等式

除弱界外，目标还要求：

- `r ≡ 3 (mod 5)`：`r^5 ≥ 2^(L+2)`；
- `r ≡ 4 (mod 5)`：`(3r)^5 ≥ 2^(L+2)`；
- 其他类：`(5r)^5 ≥ 2^(L+2)`。

由 `r = (2^m1 γ - 1)/3`，这三条分别等价于

```
2^m1 γ - 1 ≥ 3·2^((L+2)/5)     (r≡3),
2^m1 γ - 1 ≥ 2^((L+2)/5)       (r≡4),
2^m1 γ - 1 ≥ (3/5)·2^((L+2)/5) (其他).
```

`r mod 5` 由 `γ mod 5` 唯一决定：

```
r ≡ 3  ⇔  γ ≡ 0 (mod 5),
r ≡ 4  ⇔  γ ≡ 2^{-(m1+1)} (mod 5).
```

因此最终目标化为：

> **剩余不等式。** 对满足 `1 ≤ m1`、`m2 = m1+d ≤ L-1`、
> `d ≥ 1`、`e = L-m1`、`a = L-m2` 的参数，设 `γ0` 是满足
>
> ```
> γ0 ≡ -(1+2^(d+1)·5^(-d))·5^{-m1}  (mod 2^e),
> γ0 ≡ (-1)^m1                        (mod 3),
> γ0 ≡ ρ          (mod 5)
> ```
>
> 的最小正整数，其中
> `ρ = 0`（当 `r≡3`）、`ρ = 2^{-(m1+1)}`（当 `r≡4`）、
> 其余 `ρ ∈ {1,2,3}`。则需证明
>
> ```
> 2^m1 γ0 - 1 ≥ κ·2^((L+2)/5),
> ```
>
> 其中 `κ = 3`（`r≡3`）、`κ = 1`（`r≡4`）、
> `κ = 3/5`（其他类）。

`γ0` 还需携带 `Q ≡ q0 (mod 96)` 的完整条件。由
`5^(L-m2)Q = 40 + 96k` 得

```
Q ≡ 40·5^{-(L-m2)} (mod 96),
```

而 `5^8 ≡ 1 (mod 96)`，故

```
q0 = 40  若 L-m2 为偶数,
q0 = 8   若 L-m2 为奇数.
```

因此 `Q = q0 + 96t`，`t ≥ 0`。把它代入
`γ = (2^e Q - B)/5^m2`，得到 `γ` 还必须满足

```
γ ≡ (2^e q0 - B)·5^{-m2}  (mod 96).
```

所以 `γ0` 是最小正整数解：

```
γ0 ≡ -(1+2^(d+1)·5^(-d))·5^{-m1}  (mod 2^e),
γ0 ≡ (2^e q0 - B)·5^{-m2}         (mod 96),
γ0 ≡ (-1)^m1                       (mod 3),
γ0 ≡ ρ                            (mod 5).
```

模数两两互素（`2^e`、`96`、`3`、`5` 中只有 `96` 与 `3` 不互素，
但可先合并 `96` 与 `2^e` 为 `2^(max(e,5))·3`，再与 `5` 合并），
所以 `γ0` 由 `(L,m1,d,ρ)` 通过 CRT 唯一决定。

该不等式不依赖 SURV-EX 的其他条件，也不依赖有限扫描。它同时覆盖
`L ≤ 5` 的剩余弱界。

## 4bis. γ0 的二分支：h=0 是唯一剩余

令 `g` 为 `-(1+2^(d+1)·5^(-d))·5^{-m1} (mod 2^e)`
的最小正剩余，则

```
γ0 = g + 2^e h,   h ≥ 0.
```

`h` 由模 `3`、模 `5` 与模 `96` 条件联合唯一确定；不能只凭
`2^e` 与 `15` 互素就断言 `h<15`。

**若 `h ≥ 1`。** 则

```
γ0 ≥ 2^e = 2^(L-m1),
r ≥ (2^m1·2^e - 1)/3 = (2^L - 1)/3.
```

对 `L ≥ 3` 显然有 `2^L/3 > 2^((L+2)/5)`，因此这一支无条件闭合，
三个分支目标全部满足。

**若 `h = 0`。** 则 `γ0 = g`。定义
`K = (B + 5^m2·g)/2^e`；这是由参数唯一确定的整数，不是
`K = ceil(B/2^e)`。例如 `m1=1,m2=2,L=3` 时 `B=9,e=2,g=3`，
`K=21`，而 `ceil(B/4)=3`。

由 `γ = (2^e Q - B)/5^m2` 与 `γ = g + 2^e h` 得
`Q = K + 5^m2·h`，所以 `h=0` 等价于 `Q = K`。原方程
`5^a·Q = 40 + 96k`（`a = L-m2`）在 `Q=K` 时给出
`K·5^a = 40 + 96k`，即

```
K ≡ q0 (mod 96),   k = (K·5^a - 40)/96 ≥ 0,
```

其中 `q0=8`（`a` 为奇数）或 `q0=40`（`a` 为偶数）。

`h=0` 还要求对应的 `r` 是整数并落在给定类。由
`5^m2·γ = 2^e·K - B` 分别模 `3` 和模 `5`（此时 `B≡0 (mod 3)`、
`B≡2^(d+1) (mod 5)`）得到另外两条必要条件：

```
K ≡ (-1)^(L+m2) (mod 3),
K ≡ 2^(1-a)         (mod 5).
```

因此 `h=0` 的候选是唯一的：先由参数确定
`g = ⟨-(1+2^(d+1)·5^(-d))·5^{-m1}⟩_{2^e}`，再确定
`K = (B+5^m2·g)/2^e`；只有

```
K ≡ q0 (mod 96),
K ≡ (-1)^(L+m2) (mod 3),
K ≡ 2^(1-a)     (mod 5),
k = (K·5^a - 40)/96 ≥ 0
```

同时成立时 `h=0` 才可能出现。前三条模数 `96,3,5` 两两互素，
可合并成唯一剩余类 `K ≡ K0 (mod 480)`；因为 `K` 本身已被
`(L,m1,d)` 固定，所以这是单点检查，不再是 `ceil` 窗口。
若该检查失败，则 `h≥1`，`γ0 ≥ 2^e`，U=2 的三个分支目标
全部闭合。

若该检查通过，则 `γ0 = g`，对应的 `r` 类由 `g mod 5` 唯一决定，
唯一剩余不等式为

```
2^m1·g - 1 ≥ κ·2^((L+2)/5),
g = (2^e·K - B)/5^m2.
```

旧文档第 4bis 节中基于错误同余
`5^m1 g + 1 = 2^e h0` 的 `h0=1..6` 排除全部失效，不能继续引用。

## 5. 当前状态

- `U ≥ 3`：由 L-B′c 分支闭合（Lean 中 `lb_prime_c` 已证）。
- `U = 0,1`：文档解析闭合，Lean 形式化未完成。
- `U = 2`：已压缩为 `h≥1` 与 `h=0` 两分支；`h≥1` 无条件闭合，
  `h=0` 唯一剩余是单点检查
  `K≡q0 (mod 96)`、`K≡(-1)^(L+m2) (mod 3)`、
  `K≡2^(1-a) (mod 5)`、`k≥0`，其中
  `K=(B+5^m2·g)/2^e` 不是 `ceil`；检查命中时还需对 `g` 证明
  显式指数不等式。本文未宣称闭合。
