# X=2 单步排除的容量矛盾归约（2026-08-10）

状态：**部分闭合**。本文不声明单步 X=2 排除已证；它给出两条新的
严格解析语句：

1. 在容量条件 `h_i≤j-t_j+5`（所有 `u=1` 状态）成立时，**偶数出口
   的坏 X=2 单步不可能存在**；
2. 因此任何反例的出口估值必为奇数，并迫使块终端满足
   `h_e≥j-t_j+7`，即终端容量 `H_e≤-1`。

由此得到充分收口：若终端不等式 `h_e≤j-t_j+6`（等价于局部引理，
见 `local_lemma_terminal_s6_equivalence.md` 定理 2.1）成立，则单步
X=2 排除成立。本文所有语句标明必要/充分层次；不把 `j-t_j` 与
`W_{j-1}` 混用，不使用扫描证书。

## 1. 记号与目标

固定 `δ=0` 块：块首 `j`，重置步长 `t_j=W_j-W_{j-1}∈{1,2}`，
`Wp=W_{j-1}`。设 `k=j+L0`，`L0=h+1`，块内前缀词形为
`1 2^h`（`h≥0`），即

```text
X_k=v_2(5r_k+3)=2,
w=(5r_k+3)/4,
e_k=v_2(5w-1).
```

单步 X=2 排除的目标是（充要）：

```text
e_k ≤ H_k-1,    H_k=2k+13-2(W_k-Wp).
```

用户给出的归约族同余

```text
5^(h+2)u ≢ 7  (mod 2^(2j+14-2t_j-2h)),
u=(5r_j+3)/4^(h+1)
```

与 `e_k≤H_k-1` 严格等价（见 `bad_run_x2_n1_reduction.md` 第 5、
11 节），这里不再重复。

容量条件（`u=1` 状态）：

```text
(C)  对块内每个 u=1 状态 i，h_i ≤ j-t_j+5.
```

由恒等式 `D_i-i=h_i-(j-t_j)` 与 `H_i=2i+13-2D_i`，(C) 等价于
`H_i≥3`。

## 2. 偶数出口被容量条件排除（严格）

**引理 2.1（必要）。** 设 `e_k≥H_k`，出口状态 `i=k+1` 满足
`X_i=1+e_k`。若 `X_i` 为偶数，则容量条件 (C) 被违反；因此在
(C) 成立时，坏出口不可能有偶数 `X_i`。

**证明。** `H_k` 恒为奇数，因为

```text
H_k=2k+13-2(W_k-Wp) ≡ 13 ≡ 1 (mod 2).
```

故 `H_k+1` 是偶数。若 `X_i` 为偶数且 `X_i≥H_k+1`，则
`X_i≥H_k+1`。

`X_i=2a` 时，`i` 是 `u=1` 状态，其宏步为一步 `t=1` 后接
`a-1` 步 `t=2`，终点 `i'=i+a` 仍是 `u=1` 状态。从 `i` 到 `i'`
的 `t=2` 步数为

```text
a-1 = X_i/2 - 1.
```

前缀 `1 2^h` 已贡献 `h_i=h` 个 `t=2` 步，故

```text
h_{i'} = h + X_i/2 - 1
      ≥ h + (H_k+1)/2 - 1
      = h + (H_k-1)/2.
```

代入 `H_k=2k+13-2(W_k-Wp)`、`W_k-Wp=t_j+2h+1`：

```text
H_k-1 = 2j+2h+2+13-2(t_j+2h+1)-1
      = 2j+12-2t_j-2h,
```

于是

```text
h_{i'} ≥ h + (2j+12-2t_j-2h)/2
       = j-t_j+6.
```

但 (C) 要求 `h_{i'}≤j-t_j+5`，矛盾。∎

**说明。** 引理 2.1 是必要方向：它不证明出口成功，只证明在容量
条件 (C) 下偶数出口不可能失败。该论证不依赖 `w` 的具体结构，
只用 `X_i≥H_k+1` 与宏步的 `t=2` 消耗。

## 3. 奇数出口等价地压成终端容量失败（必要）

**推论 3.1（必要）。** 设 (C) 成立且 `e_k≥H_k`。则出口估值
`X_i=1+e_k` 必为奇数，且

```text
X_i ≥ H_k+2,
e_k ≥ H_k+1.
```

**证明。** 由引理 2.1，`X_i` 不能为偶数；`X_i≥H_k+1` 且
`H_k+1` 为偶数，故奇数 `X_i` 至少为 `H_k+2`。∎

**推论 3.2（必要）。** 在推论 3.1 的情形，块终端 `e` 满足

```text
h_e ≥ j-t_j+7,
H_e = 2j+13-2t_j-2h_e ≤ -1.
```

**证明。** `X_i` 为奇数时，`i` 是块内最后一个 `u=1` 状态；其后
一步 `t=1` 再把 `u` 变为偶数，随后 `k0=(X_i-1)/2` 步 `t=2`
到达偶数终端 `e=i+1+k0`。因此

```text
h_e = h + k0 = h + (X_i-1)/2
    ≥ h + (H_k+1)/2
    = h + (2j+14-2t_j-2h)/2
    = j-t_j+7.
```

再由 `H_e=2j+13-2t_j-2h_e` 得 `H_e≤-1`。∎

**推论 3.3（终端 S6 蕴含单步排除，充分）。** 若对所有含 `u=1`
状态的 `δ=0` 块都有终端不等式

```text
(S6)  h_e ≤ j-t_j+6,
```

则单步 X=2 排除成立。

**证明。** 反设 `e_k≥H_k`。由引理 2.1 与推论 3.1，出口估值必为
奇数；由推论 3.2，`h_e≥j-t_j+7`，与 (S6) 矛盾。∎

注意 (S6) 与局部引理在块内所有 `u=1` 状态成立互相等价
（`local_lemma_terminal_s6_equivalence.md` 定理 2.1），所以推论
3.3 是“用终端容量闭合单步 X=2 排除”的充分收口，不是循环论证：
它把两个开放语句显式并成一个。

## 4. 剩余奇数出口的显式结构（必要）

若反例存在，令

```text
e_k=2s,   s≥(H_k+1)/2 = j-t_j+7-h.
```

则坏同余取偶数深度：

```text
5^(h+2)u ≡ 7  (mod 2^(2s)).
```

终端参数为

```text
k0 = s,
e  = k+2+s,
r_e+1 = 5^s s'',   5∤s'',  s'' 为奇数,
0 < s'' < 5^(k+2).
```

最后一个界来自最小代表元 `r_e<5^e` 与 `e-s=k+2`。下一个重置步
`j'=e+1`、`t'∈{1,2}`、`δ∈{1}`（`t'=1`）或 `δ∈{1,3}`
（`t'=2`）满足

```text
r_{j'}+1 = (5^s·(5s''+δ5^(k+3)) - 4 + 2^(t')) / 2^(t').
```

这些是恒等式/必要条件；剩余开放点是把该式与下一块首容量尾部
方程（`block_head_tail_reduction.md` 第 2--3 节）合并，证明
`s` 与 `s''` 的尺寸/同余不可同时成立。

**补充（精确整数方程，恒等式）。** 由 `s''=(5w-1)/2^(2s)` 与
`5w-1=(5^(h+2)u-7)/2`、`u=(5r_j+3)/4^(h+1)` 逐项消去 `u,w`
得

```text
5^(h+3)r_j + 3·5^(h+2) - 7·2^(2h+2)
  = 2^(2s+2h+3)·s''.
```

这是奇数出口失败条件的精确整数形式；`s''` 为奇数、
`5∤s''`、`0<s''<5^(k+2)`。再代入 `r_j=(A_j+5^jq)/2^(W_j)`
即得到 `A_j,q` 版本。该式本身仍是必要等价，不排除候选。

## 5. 新增必要约束与尺寸界

**推论 5.1（尺寸上界，必要）。** 奇数出口反例还满足

```text
2^(2s+1) < 5^(j+h+3) / 2^(2h+2),
```

即

```text
s < ((j+h+3)·log_2 5 - 2h - 3)/2.
```

**证明。** 由精确整数方程与 `s''≥1` 得
`5^(h+3)r_j+C ≥ 2^(2s+2h+3)`；再用 `r_j<5^j` 与
`C=3·5^(h+2)-7·2^(2h+2) >0`，保留主项即得。∎

该界是必要的，但不是充分的；例如 `j=17,t_j=1,h=2` 时
`s≥21` 与 `s<22.05` 同时可满足，因此尺寸层不能单独排除。

**推论 5.2（奇偶与 5-adic 必要约束）。**

1. 块首 `q` 恒为奇数：`A_j` 为奇数、`2^(W_j)r_j` 为偶数，
   `q=(2^(W_j)r_j-A_j)/5^j` 除以奇数 `5^j` 后仍为奇数；
2. `s'' mod 5 ∈ {1,4}`，且与精确整数方程自动相容；
3. 奇数出口要求 `q` 为奇数，否则精确整数方程左端为奇数而右端
   为偶数，直接矛盾。

这些约束都不足以排除候选；它们把剩余验证进一步收窄到
`s''` 的尺寸窗口与下一块首尾部方程的联合无解性。

**推论 5.3（`s''` 的窄区间，必要）。** 由 `r_j<5^j`、
`r_j≥5^j/2^(t_j)` 与精确整数方程得

```text
(5^(j+h+3)/2^(t_j)+C)/2^(2s+2h+3)
  ≤ s'' < (5^(j+h+3)+C)/2^(2s+2h+3).
```

因此 `s''` 只可能落在长度

```text
5^(j+h+3)·(1-2^(-t_j))/2^(2s+2h+3)
```

的区间内；再结合 `s''` 为奇数、`5∤s''`，当该长度小于 `4` 时
候选至多一个。这是必要条件，不是排除。

**推论 5.4（最小 `s` 下的区间长度，必要）。** 在容量边界
`h=j-t_j+5`、最小奇数出口 `s=2` 时，区间长度约为

```text
5^(2j+8-t_j)·(1-2^(-t_j))/2^(2j+17-2t_j),
```

即随 `j` 指数增长，因此边界附近不能靠 `s''` 窄区间单独排除；
剩余仍需要词结构或下一块首尾部方程。

## 6. 结论

- 已证（在 (C) 下）：偶数出口坏 X=2 单步不存在；
- 已证：奇数出口坏 X=2 单步 ⇒ 终端 `h_e≥j-t_j+7`、`H_e≤-1`；
- 已证（充分）：终端 S6 `h_e≤j-t_j+6` ⇒ 单步 X=2 排除；
- 未证：终端 S6 本身，以及第 4 节剩余奇数出口的显式无解性。

本文不改变 `bad_run_x2_n1_reduction.md` 的单步 X=2 排除为当前
唯一开放量的结论；它把该开放量进一步分成“偶数出口（已由 (C)
排除）”与“奇数出口（等价于终端容量破坏）”两个子类。
