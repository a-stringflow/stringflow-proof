# LTE 奇部递推的预算形式（2026-08-09 续）

状态：**未闭合**。本文把 K4/LTE 路线写成纯预算形式：
每个宏步的估值完全由 `v2(a_i)`、`s_i=v2(C_i-1)` 以及
等号情形才出现的额外进位 `e_i` 决定；预算
`B_n=Σ(a_i-1)<=K` 由此变成精确的逐宏步递推。
本文不声明 L1、L2 或 K4B 已证，也不声明局部引理已闭合；
只把剩余缺口压缩到三个可分别验证的语句，并记录两条
新的必要条件。

## 1. 记号

沿用 `lte_macro_k4_reduction.md` 与 `global_budget_lemma_G.md`。
固定 `δ=0` 块内宏步链 `p_0<p_1<...`，对宏步起点 `p_i`：

- `X_i=2a_i`，`a_i>=1`；
- `C_i=(5r_i+3)/2^(2a_i)` 为正奇整数；
- `s_i=v2(C_i-1)`，`u_i=(C_i-1)/2^(s_i)` 为奇数；
- `n_i=2+v2(a_i)`，`w_i=(5^(a_i)-1)/2^(n_i)` 为奇数；
- `V_i=v2(5^(a_i)C_i-1)`；
- `m_i=H_i-2a_i`（奇数），`H_i=2p_i+13-2D_i`；
- `B_i=Σ_{k=1}^i(a_k-1)`，`m_i=m_0-2B_i`；
- `K=(m_0-1)/2`，`d_i=m_i-1=2(K-B_i)`。

局部引理在 `p_i` 成立等价于 `m_i>=1`，即 `B_i<=K`；
下一个 `u=1` 状态成功等价于 `V_i<=m_i+1`，即
`d_{i+1}=d_i+1-V_i>=0`。

## 2. LTE 三态预算递推（恒等式，充要）

LTE 分解给出：

```text
V_i = s_i              (s_i < n_i,  情形 1)
V_i = n_i              (s_i > n_i,  情形 2)
V_i = n_i + e_i        (s_i = n_i,  情形 3)
```

其中 `e_i=v2(w_i+u_i+2^(n_i)w_i u_i)>=1`。于是逐宏步：

```text
B_{i+1} = B_i + (V_i-1)/2,
d_{i+1} = d_i + 1 - V_i,
m_{i+1} = m_i + 1 - V_i.
```

各情形的宏步长度与预算成本：

1. `s<n`：`a_{i+1}=(s+1)/2`，成本 `(s-1)/2`；
   成功当且仅当 `s<=m_i`（失败当且仅当 `s>=m_i+2`）。
2. `s>n`：`a_{i+1}=(n+1)/2`，成本 `(v2(a_i)+1)/2`；
   成功当且仅当 `n<=m_i+1`。
3. `s=n`：`a_{i+1}=(n+e+1)/2`，成本 `(1+v2(a_i)+e)/2`；
   成功当且仅当 `e<=m_i+1-n`。

这些是恒等式或直接等价条件。情形 3 因为 `e_i>=1`，
成功还要求 `n_i<=m_i`，即

```text
s_i=n_i 且宏步成功  ⇒  v2(a_i)<=m_i-2.
```

这是本文新增的必要条件（不是充分条件）。

## 3. `s'` 的三态递推（恒等式，充要）

由 `C_{i+1}=(5^(a_i)C_i-1)/2^(V_i)` 直接展开：

1. `s<n`：
   ```text
   s' = v2( (u-1) + 2^(n-s) w (1+2^s u) ).
   ```
   令 `α=v2(u-1)`，则 `s'=min(α,n-s)`；
   若 `α=n-s`，则 `s'>=n-s+1`。
2. `s>n`：
   ```text
   s' = v2( (w-1) + 2^(s-n) u (1+2^n w) ).
   ```
   令 `β=v2(w-1)`，则 `s'=min(β,s-n)`；
   若 `β=s-n`，则 `s'>=s-n+1`。
3. `s=n`：
   ```text
   s' = v2( (w+u+2^n w u)/2^e - 1 ) >= 1.
   ```

前两式的 `min` 分支是精确的；唯一未闭合的额外量分别是
`α=n-s` 与 `β=s-n` 两个“单比特等号”情形，
第三式未闭合量是 `e` 本身。

## 4. 失败模式分类（新，必要）

**引理 4.1（等号是 L1 下的唯一危险点，必要）。**
对宏步 `i`：

1. 若 `s_i≠n_i` 且宏步失败，则 `v2(a_i)>=m_i`；
2. 若 `s_i=n_i` 且宏步失败，则 `e_i>=m_i+2-n_i`。

证明：情形 1 失败 `s>=m+2` 且 `s<n=2+v2(a)` 给出
`v2(a)>=s-1>=m+1`；情形 2 失败 `n>=m+2` 即
`v2(a)>=m`；情形 3 失败即 `n+e>=m+2`。∎

因此：

- L1（`v2(a_i)<=m_i-1`，充分）自动排除情形 1、2 的全部失败；
- 在 L1 成立时，唯一可能的失败是情形 3，且失败当且仅当
  K4B 失败 `e_i>=m_i+2-n_i`；
- 若 L1 失败（`v2(a_i)>=m_i`），情形 1、2、3 仍可能成功
  （例如情形 1 的 `s_i` 很小）；一旦失败，失败宏步满足
  `V_i>=m_i+2`，成本 `(V_i-1)/2>=(m_i+1)/2`，预算一步耗尽。

这正好把“危险点”精确化为：**在预算未耗尽且 L1 成立时，
`B_n<=K` 的维持只可能被等号情形 `s_i=n_i` 破坏。**

## 5. 剩余语句与势能记录

### 5.0 预算耗尽态的结构（新，必要）

**推论 4.2。** 若 `m_i=1`（即 `d_i=0`，预算恰好耗尽）且
宏步成功，则：

- 下一状态仍是宏步起点时，`V_i=1` 且 `a_{i+1}=1`；
- 下一状态是终端（`X` 为奇数）时，`V_i=2`。

证明：成功要求 `V_i<=m_i+1=2`；非终端时 `V_i=2a_{i+1}-1`
为奇数，故 `V_i=1`、`a_{i+1}=1`；终端时 `V_i=X_{i+1}-1`
且 `X_{i+1}` 为奇数，故 `V_i` 为偶数，只能取 `2`。∎

因此在预算耗尽态，继续走下去的宏步成本为 `0`，余量保持
`m_{i+1}=1`（非终端）或进入终端；失败等价于 `V_i>=3`，
等号情形 `s_i=n_i` 只是其中一种可能来源。

### 5.1 三个剩余语句

1. **L1（必要/充分分层）**：对每个宏步起点，
   `v2(a_i)<=m_i-1`。它是排除情形 1、2 失败的充分条件；
   目前没有任何 δ=0 递推证明。
2. **L2（辅助归纳候选）**：`s_i<=m_i+2`，且等号时
   `s_i>n_i`。它用来在宏步递推中传播 L1/K4B；
   目前未从递推推出。
3. **K4B（等号分支，充要）**：`s_i=n_i` 蕴含
   `e_i<=m_i+1-n_i`。在 L1 下这是情形 3 成功的充要条件。

### 5.2 势能 `Q_i=m_i+1-s_i`

沿宏步有精确递推：

```text
情形 1:  Q' = Q + 1 - s'  <= Q            (s'>=1)
情形 2:  Q' = Q + (s+1-n) - s'
情形 3:  Q' = Q + 1 - e - s' <= Q - 1      (e,s'>=1)
```

因此等号情形每步严格消耗至少 1 单位 `Q`，情形 1 永不增加
`Q`；`Q>=-1` 等价于 L2。剩余难点是情形 2 可能通过
`s+1-n` 的增益提高 `Q`，而 `s'` 的等号进位
`β=s-n` 又可能抵消该增益。该势能只把 L2 翻译成逐宏步递推，
不闭合 L2。

### 5.3 新增的必要条件汇总

- 情形 3 成功 ⇒ `v2(a_i)<=m_i-2`；
- 情形 1 失败 ⇒ `v2(a_i)>=m_i+1`；情形 2 失败 ⇒
  `v2(a_i)>=m_i`；
- L1 成立时，`B_n<=K` 的失败只可能来自 K4B 失败。

这些语句全部标明必要/充分层次，未声称闭合。

## 6. 完整 2-adic 商的免进位递推（新整理，严格恒等式）

把第 3 节的 `s'` 递推换成完整商

```text
y_k = (q_{V,k} - q_k) / 2^(W_k) ∈ Z_2,
y_k = -2^(X_k) * C_k * 5^(-(k+1)).
```

块内 `δ=0` 时 `y_k` 满足精确线性递推（无进位位）：

```text
t=1:  y_{k+1} = y_k/2 + 2*5^(-(k+2)),
t=2:  y_{k+1} = y_k/4 - (1/2)*5^(-(k+2)).
```

记 `u_k=5^(-(k+2))`（2-adic 单位），则逐估值：

- `t=1` 且 `X_k>=3`：`X_{k+1}=1`（自动安全，余量增加）；
- `t=1` 且 `X_k=2`：写 `y_k=4*o`（`o` 为奇数），则
  `X_{k+1}=2+e`，其中
  `e = v2(o+u_k)-1 >= 0`；这是 X=2 游程的“危险点”；
- `t=1` 且 `X_k=1`：`X_{k+1}=0`（偶数态）；
- `t=2` 且 `X_k=1`：写 `y_k=2*o`（`o` 为奇数），则
  `X_{k+1}=v2(o-u_k)-1 >= 0`；宏步端点要求
  `X_{k+1}=2`，即 `v2(o-u_k)=3`。

这些是恒等式；`e` 就是第 2、3 节在 `a=1` 宏步（`n=2`）时
`s=1` 或 `s=2` 分支的额外进位。沿一个 X=2 游程，
每个 `t=1` 步的余量变化为 `m'=m-e`，因此

```text
B_n<=K  ⇔  游程中累计 e 不超过剩余预算 2(K-B)+1.
```

该形式把 `c_i` 进位位替换成单个 2-adic 商 `o` 对固定单位
`u_k` 的模 `4`/`8` 余类条件，仍未闭合；剩余问题等价于证明
对可达 `(q,A,W)`，`o+u_k` 的 2-adic 赋值被预算控制。

## 7. X=2 游程的闭式：长度与出口进位（新，严格恒等式）

设 X=2 游程从深度 `k0` 开始，`y_{k0}=4o_0`（`o_0` 为奇数），
`u_k=5^(-(k+2))`。令

```text
z_k = o_k * 5^(k+2),      w_k = z_k + 5/3.
```

只要游程继续（`X=2`），就有

```text
o_{k+1} = (o_k+u_k)/2,
z_{k+1} = 5(z_k+1)/2,
w_{k+1} = (5/2) w_k,
```

故 `w_k=(5/2)^k w_0`，且

```text
o_k 为奇数  ⇔  w_k 为偶数  ⇔  v2(w_0) >= k+1.
```

因此 X=2 游程长度精确为

```text
n = v2(w_0) = v2(3*5^(k0+2)*o_0 + 5).
```

写 `3*5^(k0+2)*o_0+5 = 2^n*c`（`c` 为奇数），则出口步
`n-1 -> n` 的进位为

```text
e = v2(o_{n-1}+u_{n-1}) - 1
  = v2(5^(n-1)*c - 1).
```

证明：`w_{n-1}=2*5^(n-1)*c`，代入
`e=v2(w_{n-1}-2/3)-1` 即得。∎

于是“游程累计 `e` 不超过 `2(K-B)+1`”变成对单个整数

```text
3*5^(k0+2)*(B_{k0}/4) + 5
```

的两个显式 2-adic 赋值控制：`n=v2(...)`、
`e=v2(5^(n-1)*oddPart(...)-1)`。`B_{k0}` 由
`(q,A,W)` 经完整商递推唯一决定；该形式把 X=2 游程的
危险点完全消去成固定仿射函数 `3*5^(k0+2)x+5` 的
2-adic 赋值，仍未闭合。

## 8. 局部引理 ⇔ 两个单剩余类避让（新，充要归约）

本节把整条局部引理压成两个“`C` 避开一个模 `2^H` 剩余类”
的语句。这是第 6、7 节递推的直接推论，不再涉及完整
`q_V` 窗口。

对块内奇数状态 `i`，若 `X_i=2`，令
`C_i=(5r_i+3)/4`；若 `X_i=1`，令 `C_i=(5r_i+3)/2`。
两者都是奇数。

**引理 8.1（单步失败判据，充要）。**

```text
t=1 步 i -> i+1 在 i+1 失败
  ⇔  X_i=2 且 C_i ≡ 5^(-1) (mod 2^(H_i));
t=2 步 i -> i+1 在 i+1 失败
  ⇔  X_i=1 且 C_i ≡ -5^(-1) (mod 2^(H_i)).
```

证明：用完整商 `y_i=-2^(X_i)C_i*5^(-(i+1))`。
`t=1` 时 `H_{i+1}=H_i`，失败
`y_{i+1}≡0 (mod 2^(H_i+1))` 等价于
`y_i≡-4*5^(-(i+2)) (mod 2^(H_i+2))`；左端赋值
`X_i`，右端赋值 `2`，故必须有 `X_i=2`，代入
`y_i=-4C_i5^(-(i+1))` 得 `C_i≡5^(-1) (mod 2^(H_i))`。
`t=2` 同理：`H_{i+1}=H_i-2`，失败等价于
`y_i≡2*5^(-(i+2)) (mod 2^(H_i+1))`，必须有 `X_i=1`，
代入得 `C_i≡-5^(-1) (mod 2^(H_i))`。∎

**推论 8.2（局部引理的剩余类形式，充要）。** 设块首
`u_j` 为奇数且 `n0>=1`（首个 `u=1` 状态由 `t=2` 从
`X=1` 状态产生），则块内所有 `u=1` 状态的局部引理等价于：

```text
(A) 每个可达 X=2 状态满足 C_i ≢ 5^(-1)  (mod 2^(H_i));
(B) 每个可达 X=1 状态满足 C_i ≢ -5^(-1) (mod 2^(H_i)).
```

`n0=0`（块首即 `u=1`）时还需单独验证块首估值
`X_j<=H_j`。证明：块内 `u>=3` 的状态恒有 `X=1`，
`u=1` 状态要么由 `t=2` 从 `u=3` 产生，要么由 `t=1`
从 `X=2` 的 `u=1` 状态产生；引理 8.1 保证每条边的
失败都等价于 (A) 或 (B)，其余边自动成功。∎

因此整个局部引理缺口就是两个显式剩余类
`5^(-1) mod 2^H` 与 `-5^(-1) mod 2^H` 的避让；
它等价于第 7 节对 `e` 的预算控制，仍未闭合。

**推论 8.3（同一游程内至多一个坏点，新，必要）。**
设 `i,i+1` 是同一 X=2 游程中连续两个 X=2 状态
（`t=1` 相连，`W_{i+1}=W_i+1`）。令 `q_A(i)` 为使
`C_i≡5^(-1) (mod 2^(H_i))` 成立的唯一 q 剩余，则

```text
q_A(i+1) - q_A(i)
  ≡ 5^(-(i+2)) * (8*5^(-1)-15) * 2^(W_i)
    (mod 2^(W_i+H_i+2)),
```

右端系数 `8*5^(-1)-15` 为奇数，故差是 `2^(W_i)` 的奇数倍。
若两个值都落在 `[0,2^(W_j))` 内，其差绝对值 `<2^(W_j)<=2^(W_i)`，
与“`2^(W_i)` 的奇数倍”矛盾。因此同一 X=2 游程内至多一个
状态的坏残差能落在 q 区间。

对 `t=2` 连接的 X=1 链（`W_{i+1}=W_i+2`），同理令
`q_B(i)` 为使 `C_i≡-5^(-1) (mod 2^(H_i))` 的 q 剩余，则

```text
q_B(i+1) - q_B(i)
  ≡ 5^(-(i+2)) * 2*(5^(-1)-1) * 2^(W_i)
    (mod 2^(W_i+H_i+1)),
```

右端 `v2 = W_i+3`，故同一 X=1 链内也至多一个坏点。
证明只需把 `A_{i+1}=5A_i+c_i2^(W_i)`（`c_i=4` 或 `1`）
代入两个坏残差同余并相减。∎

该推论把 (A)/(B) 的验证压缩到每个游程/链的最后一个危险
状态；结合第 7 节的闭式，剩余语句是单个游程出口的
`e<=2(K-B)+1`，仍未闭合。

## 9. 死路记录：坏出口不能由纯算术排除（新）

对任意 `k0,H,n`，若要求坏出口 `e>=H-1` 且
`n=v2(3*5^(k0+2)*o_0+5)`，则 `o_0<2^(H-1)` 被唯一确定：

```text
o_0 ≡ 3^(-1)*5^(-(n+k0+1))*(2^n-5^n)  (mod 2^(n+H-1)).
```

取该同余在 `[0,2^(H-1))` 的代表后，`n=v2(...)` 自动成立，
`e>=H-1` 也自动成立。因此坏出口在纯 2-adic 同余层面对
每个 `n` 都存在，不能靠 `o_0` 的尺寸、奇偶或同余自洽排除。

例如 `(k0,H,n,o_0,e)=(1,3,1,3,2)` 就是算术上自洽的坏出口，
但该 `o_0` 是否可由某个 `(q,A,W)` 经块内递推到达，正是
尚未闭合的部分。结论：剩余预算不等式
`e<=2(K-B)+1` 的证明必须使用 q 区间
`[2^(W_(j-1)),2^(W_j))` 与前缀分子 `A` 的可达性结构，
单靠本节和第 7 节的同余闭式不能闭合。

## 10. K 同余归约（2026-08-09 续）

新增 `bad_run_exclusion_reduction.md`，把坏 X=2 游程压成单一整数
方程：

```text
5^(n+1)(3A+3·5^k q+2^W) + 2^(W+n+2)
  = 3K·2^(W+n+H+1),
```

其中 `K=(5r_i+3)/2^(H+1)∈Z_{≥1}`。由此得到新的必要同余

```text
K ≡ (3·2^(H-1))^(-1)  (mod 5^(n+1)).
```

该归约完成“坏 `o_0` → 唯一 `K` 剩余类 → `q` 候选”的前两步；
第三步“对可达 `A` 证明 `q(m)∉[2^(Wp),2^(Wj))`”仍开放，详见新文件。
