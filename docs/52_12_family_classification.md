# 52.12 族分类：定义输入而非可推导引理

本文说明阶段二剩余输入 `hlast` / `hU1` 为什么是 52.12 的族分类
定义，不能从模条件或结构上界独立推出。

## 1. 族定义

QB-8 循环中 A/B 族按“上升段末步”与“C3 链头权重”约定：

- A 族：`b=1`，`t_last=1`，链头权重 `t_1=3`，故 `U<=L-1`。
- B 族：`b=2`，`t_last=2`，链头权重 `t_1=5`，故 `1<=U`。

52.12 把这两种组合记为“两种幸存组合”；`hlast`（词层）与
`hU1`（解析层）是同一约定的两个等价表述：

```lean
U_bounds_of_hlast : wordLast w = b -> (A 族 U<=L-1 或 B 族 1<=U)
```

## 2. 为什么模条件不能推出末步

52.6 的端点模 80 判别只给出“末步确定模类”的方向：

- 头权重 `t_1=3`（A 族）：`wordLast=1 -> M0=43 mod 80`，
  `wordLast=2 -> M0=59 mod 80`。
- 头权重 `t_1>=5`（B 族）：`wordLast=1 -> M0=3 mod 80`，
  `wordLast=2 -> M0=19 mod 80`。

但反向不成立：A 族的 `43` 与 `59` 都满足 `5M0+1` 不被 `16`
整除；B 族的 `3` 与 `19` 中，`M0=83`（`83=3 mod 80`）有
`5*83+1=416`、`v2=5`，满足头权重 `5` 且对应 `wordLast=1`。
因此给定链头权重与端点模类，末步仍有两种可能。

## 3. Lean 接口处理

阶段二结构层把族分类作为输入：

- `Qb8OrbitStructuralInput.hlast`：`wordLast w = b`（词层）。
- `Qb8OrbitStructuralU1Input.hU1`：52.12 的 `U` 界（解析层）。

两者等价，且在 `Axioms` 审计中只依赖
`propext`、`Classical.choice`、`Quot.sound`。这不是隐藏缺口，
而是 QB-8 循环的 A/B 族定义约定。

## 4. 结论

阶段二 Lean 侧已收口：结构层输入只剩真实结构字段与族分类
`hlast`/`hU1`，其余（`hT`、`hP205`、`hcyc`、`hD`、`hfeas`、
`hU`、`h201`）全部自动推导。52.12 族分类不作为 Lean 证明目标。
