# 坏 X=2 游程的 n=1 归约与单步子引理（2026-08-10）

状态：**部分闭合**。本文闭合目标的三步框架中的第 1、2 步与第 3 步的
`N0<2^(Δ+H+1)` 区制，并用 F 不变量把坏 X=2 游程严格归约为“单步
X=2 排除”。单步子引理本身仍是唯一开放量；若它成立，则坏游程不可达，
并按现成链闭合局部引理到 7 发散。本文不新增 Lean 定理，不使用扫描证书。

## 1. 充要式 (1)：坏出口等价于 N0 的 2-adic 窗口

**记号。** 固定 `δ=0` 块：块首 `j`，`L=i-j`，`Δ=W_i-W_j`，
`Wp=W_{j-1}`。令

```text
S   = Σ_{s=j}^{i-1} 5^(i-1-s) 2^(W_s),
s0  = S / 2^(W_j),
N0  = 5^(L+1) r_j + 5 s0 + 3·2^Δ.
```

块内闭式（充要）：

```text
2^(W_i) r_i = 5^L 2^(W_j) r_j + S,
5r_i+3 = N0 / 2^Δ.
```

证明：由 `A_i=5^L A_j+S`、`A_j=2^(W_j)r_j-5^j q`、
`A_i=2^(W_i)r_i-5^i q` 消去 `q,A_j,A_i` 得第一式；再乘 5 加 3 得第二式。
∎

**引理 1.1（充要）。** 坏出口 `X_i=v_2(5r_i+3)≥H_i+1` 当且仅当

```text
v_2(N0) ≥ Δ+H_i+1,
```

即 `2^(Δ+H_i+1) ∤ N0` 的否定是坏出口。

证明：`v_2(5r_i+3)=v_2(N0)-Δ` 是恒等式。∎

## 2. 尾包络与一步剥皮（恒等式，充要）

令 `w_ℓ=W_{j+ℓ}-W_j`（`ℓ=0..L`），则 `w_0=0`，`w_ℓ` 严格递增，
`w_ℓ-w_{ℓ-1}∈{1,2}`。

**引理 2.1（尾包络，充分）。**

```text
s0 = Σ_{ℓ=0}^{L-1} 5^(L-1-ℓ) 2^(w_ℓ) ≤ 5^L - 4^L < 5^L.
```

证明：`w_ℓ≤2ℓ`，故 `2^(w_ℓ)≤4^ℓ`，代入等比求和即得。∎

**推论 2.2（N0 的尺寸上界，充分）。**

```text
N0 < 5^(L+1)(r_j+1) ≤ 5^(i+1).
```

证明：由引理 2.1 与 `2^Δ≤4^L` 得

```text
N0 ≤ 5^(L+1)r_j + 5(5^L-4^L) + 3·4^L
   = 5^(L+1)(r_j+1) - 2·4^L.
```

再由 `r_j<5^j` 且 `r_j` 为整数得 `r_j+1≤5^j`。∎

**引理 2.3（一步剥皮，充要）。** 设 `t_i=W_i-W_{i-1}`，则

```text
s0 = 5 s1 + 2^(Δ-t_i),
N0 = 5^(L+1) r_j + 25 s1 + c_i·2^(Δ-t_i),
c_i = 5 + 3·2^(t_i) ∈ {11,17}.
```

证明：`s0` 的末项是 `2^(w_{L-1})=2^(Δ-t_i)`，其余项含因子 5；
`N0=5^(L+1)r_j+5s0+3·2^Δ` 代入即得。∎

## 3. 不等式系统与 `N0<2^(Δ+H_i+1)` 区制

令 `M=Δ+H_i+1`，`H0=2(j-t_j)+13`，`l` 为块尾 `t_{j+1}..t_i` 中
`t=1` 的步数。由 `H_i=2i+13-2(W_i-Wp)` 与 `Δ=W_i-W_j` 得恒等式

```text
M = H0+l+1,          Δ+H_i = H0+l.
```

**引理 3.1（尺寸区制，充分）。** 若 `N0<2^M`，则
`v_2(N0)≤Δ+H_i`，估值条件成立。

证明：正整数 `N0` 满足 `v_2(N0)≤log_2 N0<M`，故
`v_2(N0)≤M-1=Δ+H_i`。∎

因此唯一剩余区制是

```text
N0 ≥ 2^(H0+l+1).
```

结合推论 2.2，该区制必须满足必要尺寸条件

```text
2^(H0+l+1) < 5^(i+1),
```

即

```text
H0+l+1 < (i+1) log_2 5.
```

这是必要而非充分条件；它只淘汰 `L` 很小时的一部分区制，不能单独闭合。

## 4. F 不变量归约：坏游程长度必为 1

沿用 `p_adic_window_route.md` 第 8--9 节：

```text
E_k = -(5r_k+3),   E_{k+1} = (5E_k+4)/2  (t=1),
                   E_{k+1} = (5E_k-2)/4  (t=2).
```

对非空块尾词有（充要）`E_L=5^L E_0+M_L`，且
`v_2(M_L)≤Δ+1`；等号 `v_2(M_L)=Δ+1` 当且仅当词形为
`1 2^(L-1)`（见 p_adic route 引理 9.4、9.5）。

设坏 X=2 游程从深度 `k` 开始，长度为 `n≥1`，出口 `i=k+n`；
块内前缀 `j..k` 长度 `L0=k-j`，权重增益 `Δ0=W_k-W_j`；
全尾长度 `L=L0+n`，权重增益 `Δ=Δ0+n`。游程起点有
`X_k=2`，故

```text
v_2(E_prefix) = Δ0 + 2,
v_2(E_full)   ≥ Δ + H_i + 1.
```

记 `a=v_2(E_0)=X_j`。对前缀，由三角不等式：

```text
v_2(E_prefix)=v_2(5^L0 E_0 + M_prefix),
v_2(M_prefix)≤Δ0+1,
```

要得到 `v_2(E_prefix)=Δ0+2`，必须
`a=v_2(M_prefix)∈{Δ0,Δ0+1}`。这是必要条件，不是充分条件。

对全尾同理，要得到 `v_2(E_full)≥Δ+H_i+1>Δ+1`，必须

```text
a=v_2(M_full)∈{Δ,Δ+1}.
```

**定理 4.1（必要归约）。** 若坏 X=2 游程存在，则下列必要条件成立：

1. 游程长度 `n=1`；
2. `a=X_j=Δ0+1`；
3. 当 `L0≥1` 时，前缀词形必为 `1 2^(L0-1)`；
4. 全尾 `v_2(M_full)=Δ`（即 `δ'=0`）。

证明：`a∈{Δ0,Δ0+1}` 与 `a∈{Δ0+n,Δ0+n+1}` 的交集在 `n≥1` 时只能是
`a=Δ0+1`、`n=1`。于是 `v_2(M_prefix)=a=Δ0+1`，由 p_adic route
推论 9.5 得词形 `1 2^(L0-1)`；全尾 `v_2(M_full)=a=Δ`。这些都是
坏出口的必要条件；是否真正失败还取决于剥皮后的高位奇偶条件。∎

`L0=0`（游程从块首直接开始）没有前缀，单独属于单步子引理范围：
`X_j=2`、`n=1`、全尾词 `1`。此时前缀集合不适用，但全尾条件
`a=2∈{n,n+1}` 仍给出 `n=1`。

## 5. 归约后的显式闭式

设 `L0≥1`，前缀词 `1 2^(L0-1)` 后接游程步 `t=1`。令

```text
y_k=5r_k+3=4^(L0)u,   u 为奇数,   u≡3 (mod 4).
```

**引理 5.1（充要闭式）。**

```text
y_i = 5^(L0+1)u - 7,
H_i = H_k = 2j - 2t_j + 15 - 2L0,
```

且坏出口当且仅当

```text
v_2(5^(L0+1)u - 7) ≥ H_i + 1.
```

证明：对词 `1 2^(L0-1) 1` 逐段代入 `y` 递推
（`t=1: y'=(5y-4)/2`，`t=2: y'=(5y+2)/4`），
前缀终点 `y_k=2(5^L0 u-1)`，游程步后得 `y_i=5^(L0+1)u-7`。
`H_i` 直接代入定义。∎

**推论 5.2（等价形式，充要）。** 记
`w=(5r_k+3)/4=(5^L0 u-1)/2`，则 `X_k=2`，且坏出口当且仅当

```text
v_2(5w-1) ≥ H_k.
```

因此 `L0≥1` 的情形完全落入“X=2 状态经一步 t=1 后坏出口”的同一单步问题。

## 6. 最小开放子引理：单步 X=2 排除

**单步子引理（开放，充分闭合目标）。** 对任意 `δ=0` 可达状态
`(A_k,W_k,q)`，若

```text
X_k=v_2(5r_k+3)=2,   w=(5r_k+3)/4,
```

则

```text
v_2(5w-1) ≤ H_k - 1,   H_k=2k+13-2(W_k-Wp).
```

该子引理等价于局部引理在“X=2 后接一步 t=1”处的估值条件；由定理 4.1
和推论 5.2，闭合它即闭合坏 X=2 游程排除。

**引理 6.1（单步充要）。**

```text
v_2(5w-1) ≥ H_k
  ⇔  2^(W_k+H_k+2) | 25A_k + 11·2^(W_k) + 5^(k+2)q.
```

证明：`5w-1=(25r_k+11)/4`，`25r_k+11` 的分子用 `A_k` 展开后
两边乘以 `2^(W_k)` 即得。∎

**引理 6.2（向后剥皮恒等式，充要）。**

```text
v_2(25r_k+11) = v_2(5^(k+2)q + Q0) - W_k,
Q0 = 25A_k + 11·2^(W_k).
```

证明：`25A_k+11·2^(W_k)+5^(k+2)q = 2^(W_k)(25r_k+11)`。∎

**推论 6.3（候选唯一，充要）。** 若坏出口成立，则

```text
q ≡ -Q0·5^(-(k+2))  (mod 2^(W_k+H_k+2)).
```

由于 `q<2^(W_k)<2^(W_k+H_k+2)`，坏出口至多对应一个 `q`；
这个候选就是可达的 `q` 本身。因此单步子引理等价于证明

```text
2^(W_k+H_k+2) ∤ 25A_k + 11·2^(W_k) + 5^(k+2)q.
```

这是当前唯一未闭合的解析语句；它不再包含“游程长度”或“块尾词结构”，
只包含单个 X=2 状态与其一步后继的估值。

## 8. 下一步最小可证子引理

若单步 X=2 排除整体仍卡住，下一步最小目标是：

```text
对固定 δ=0 块，证明
v_2(25A_k + 11·2^(W_k) + 5^(k+2)q)
  ≤ W_k + 2k + 14 - 2(W_k-Wp),
```

其中 `Wp=W_{j-1}` 是块首前一步权重。该语句只涉及一个状态、一个块首
`q` 与 `A_k` 的词前缀结构，不再依赖坏游程参数 `(n,K0)`。

**引理 8.1（块首单步的尺寸排除，充分）。** 若 `k=j`（游程从块首直接
开始）且

```text
t_j=2, k≤19     或     t_j=1, k≤25,
```

则单步子引理自动成立。

证明：此时 `W_k-Wp=t_j`，`H_k=2k+13-2t_j`，且
`25r_k+11<25·5^k+11`。直接检查
`25·5^k+11<2^(2k+15-2t_j)` 在所列范围内成立，故
`v_2(25r_k+11)<H_k+2`，即 `v_2(5w-1)≤H_k-1`。∎

对 `k>j`（即 `L0≥1`），`Δ0=W_k-W_j≥1`，尺寸上界不足以排除，

## 9. 预算等价与归约族的候选计数（必要）

沿用 `local_lemma_analytic_advance.md` 第 7 节的预算记号：

```text
Z_k=2^(W_k-W_j)U_k,   U_k=-5^(-(k+1))(5r_k+3),
a_k=v_2(Z_k)=W_k-W_j+X_k,
s_k=H_j+l_k-a_k=H_k-X_k.
```

**引理 9.1（预算等价，充要）。** 对 `t=1`、`X_k=2` 的同位相消步，

```text
e_k=v_2(5w-1),   s_k=H_k-2,
```

且单步子引理 `v_2(5w-1)≤H_k-1` 等价于预算不等式

```text
e_k≤s_k+1.
```

证明：`U_k=-5^(-(k+1))·4w`，`p_k=5^(-(k+2))`，故
`e_k=v_2(U_k/4+p_k)=v_2(5w-1)`；其余直接代入。∎

因此本归约没有引入新开放量：它把坏 X=2 游程排除精确压成
`local_lemma_analytic_advance.md` 推论 7.2 的唯一开放语句，并给出
该语句在 `L0≥1` 族上的显式形式。

**引理 9.2（归约族候选计数，必要）。** 在 `L0≥1` 族中，若坏出口
成立，则 `u=(5r_j+3)/4^(L0)` 满足

```text
u≡7·5^(-(L0+1))  (mod 2^(H_i+1)),
u≡3·4^(-L0)      (mod 5),
0<u<5^(j+1)/4^(L0).
```

因此 `u` 至多有

```text
2^(αj+2t_j-16)+1,   α=log_2 5-2≈0.321928,
```

个候选。唯一候选的充分条件是 `αj+2t_j<16`，即
`j≤43`（`t_j=1`）或 `j≤37`（`t_j=2`）；更大的 `j` 可能多于一个。

证明：前两条分别是坏出口同余与 `r_j=(4^(L0)u-3)/5` 的整性；
第三条来自 `r_j<5^j`。CRT 把 `u` 唯一压到模
`5·2^(H_i+1)` 的剩余类，候选数不超过区间长度
`5^(j+1)/4^(L0)` 除以该模，再代入
`H_i+1=2j-2t_j+16-2L0` 即得。∎

引理 9.2 是必要条件；超过唯一候选范围的 `j`（如 `j≥44`）仍可能有
多个候选，需用 `A_j` 的词结构排除，不能由计数闭合。

## 10. e 转移恒等式与反向链（用户新入口，2026-08-10 续）

本节把“大 `e` 不能自由出现”写成精确的单步转移。设 `u` 为 2-adic
整数，满足 `e(u)=v_2(5u-1)≥2`，令

```text
u'=(5u+3)/4,   m=(5u-1)/2^(e(u)) 为奇数.
```

**引理 10.1（e 转移，充要）。**

```text
e(u)=2  ⇒  e(u')=0,
e(u)=3  ⇒  e(u')=1+v_2(5m+2),
e(u)=4  ⇒  e(u')=2+v_2(5m+1),
e(u)≥5  ⇒  e(u')=2.
```

证明：`5u-1=2^e m`，故

```text
25u+11 = 5(5u-1)+16 = 5·2^e m+16.
```

逐项检查：

- `e=2`：`5·2^2 m+16=4(5m+4)`，且 `5m+4` 为奇数；
- `e=3`：`5·2^3 m+16=8(5m+2)`；
- `e=4`：`5·2^4 m+16=16(5m+1)`；
- `e≥5`：`5·2^e m+16=16(5·2^(e-4)m+1)`，括号为奇数。

再由 `e(u')=v_2(5u'-1)=v_2(25u+11)-2` 即得。∎

**推论 10.2（复位，必要）。** 若 `e(u)≥5`，则 `e(u')=2`；因此
前向序列中不可能出现两个连续值 `≥5`。大 `e` 只能在 `e=3` 且
`v_2(5m+2)` 很大、或 `e=4` 且 `v_2(5m+1)` 很大时产生。

**推论 10.3（反向同余，必要）。** 若 `e(u')=E≥5`，则前驱必须满足

```text
e(u)=4,   m ≡ -5^(-1)  (mod 2^(E-2)).
```

证明：由引理 10.1，`e=2` 给 `0`、`e≥5` 给 `2`，均不可能；
`e=3` 分支若给 `E≥5`，则 `v_2(5m+2)=E-1≥4`，代入
`5u-1=8m` 迫使 `v_2(5u-1)=4`，与 `e(u)=3` 矛盾。故只剩
`e=4` 分支。∎

**推论 10.4（深同余局部化，必要）。** 若序列末项 `e(u_N)≥5`，
则反推一步即把“深同余”压到前驱的 `m`；再往前，前驱的 `e` 只能是
3 或 4，而它们各自要求的 `m` 同余深度至多为 2。因此大 `e` 的
深层同余不在链的中间，而在最后一步的 `m` 上。

证明：对 `e=4` 的前驱，若要产生 `e'=4`，需要
`v_2(5m+1)=2`；要产生 `e'=3`，需要 `v_2(5m+1)=1`。对 `e=3`
的前驱同理，深度至多 2。∎

**字典（充要）。** 对 `δ=0` 可达状态取

```text
u=r_k,   u'=(5u+3)/4=w_k=(5r_k+3)/4.
```

此时 `e(u')=v_2(5w_k-1)=e_k` 正是单步子引理中的进位，而
`e(u)=v_2(5r_k-1)`。转移恒等式因此直接作用于可达状态本身，不是
抽象模型。

**推论 10.5（失败的必要同余，充要）。** 若 `e_k≥5`，则

```text
v_2(5r_k-1)=4,
5r_k-1 ≡ -16·5^(-1)  (mod 2^(e_k)),
```

等价地

```text
r_k ≡ 13  (mod 16),
w_k ≡ 1-4·5^(-1)  (mod 2^(e_k-2)).
```

证明：把字典代入推论 10.3 的 `e=4` 分支；`e=3` 分支在 `E≥5`
时与 `v_2(5r_k-1)=3` 自相矛盾（`5r_k-1=8m` 与
`m≡-2·5^(-1) mod 2^(E-1)` 迫使 `v_2(5r_k-1)=4`）。∎

**过渡说明。** 推论 10.5 看起来把“坏出口”压成两条同余，但下文
“重要修正”会证明第二条同余是恒真式；因此它不构成可用的最小子引理。

**推论 10.6（归约族上的显式形式，必要）。** 在 `L0≥1` 族中，
`r_k=2·5^(L0-1)u-1`，故

```text
v_2(5r_k-1)=1+v_2(5^(L0)u-3),
w_k=(5^(L0)u-1)/2.
```

因此失败的必要同余化为

```text
5^(L0)u ≡ 11        (mod 16),
5^(L0)u ≡ 3-8·5^(-1) (mod 2^(e_k-1)).
```

前一条只固定 `u mod 16`（按 `L0 mod 4` 分别给
`11,15,3,7`），与 `u≡3 (mod 4)` 相容；后一条才是深同余。
并且后一条取模 `16` 自动给出 `5^(L0)u≡11 (mod 16)`，所以
前一条被后一条蕴含，不是独立条件（下文“重要修正”进一步说明
后一条本身也只是恒真式）。

**重要修正（自动同余）。** 推论 10.5 的后一条实际上不产生新约束：
`5^(L0)u ≡ 3-8·5^(-1) (mod 2^(e_k-1))` 两边乘 5 得

```text
5^(L0+1)u ≡ 15-40·5^(-1) ≡ 7  (mod 2^(e_k-1)),
```

而 `5^(L0+1)u-7` 按定义有 `v_2 = e_k+1 ≥ e_k-1`，故该同余是
恒真式。因此转移给出的唯一非平凡必要条件是

```text
v_2(5r_k-1)=4,   即 r_k ≡ 13 (mod 16).
```

这条本身很弱，可达的近失败状态（例如 `r=41650749`）也满足它。
所以 e 转移恒等式虽然把“大 e 只能由 e=4 前驱制造”变成精确形式，
但没有把单步子引理压成更小的新同余；真正的困难仍在使用 `A_k` 的
词结构控制 `e_k` 本身。

因此本节不产生新的最小子引理：它确认反向链方向不会单独闭合，唯一
非平凡必要条件是 `r_k≡13 (mod 16)`，而这条与 `u` 的候选计数、
`A_j` 词结构都不冲突。下一步仍回到第 8 节的单步子引理，或寻找
能把 `e_k` 与 `h_k`（块内 `t=2` 数）直接绑定的词结构不变量。

## 11. 归约族的显式闭式分子（2026-08-10 续）

设 `L≥1`、`h=L-1`，前缀词形 `1 2^h`，即 `W_k=W_j+2h+1`，
且 `X_j=2h+2`，写 `5r_j+3=4^(h+1)u`（`u` 为奇数）。
闭式尾包络给出

```text
s0 = 3·5^h - 2·4^h.
```

**引理 11.1（闭式分子，充要）。**

```text
N := 25·5^(h+1)r_j + 25·(3·5^h - 2·4^h) + 11·2^(2h+1)
   = 5^(h+1)(25r_j+15) - 50·4^h + 11·2^(2h+1)
   = 2^(2h+2)(5^(h+2)u - 7).
```

且

```text
e_k = v_2(5^(h+2)u - 7) - 1 = v_2(N) - (2h+3).
```

坏出口当且仅当

```text
v_2(N) ≥ 2j+16-2t_j,
```

目标 `e_k≤H_k-1` 等价于

```text
v_2(N) ≤ 2j+15-2t_j
      = (2h+3) + (H_k-1).
```

证明：逐项代入 `s0` 与 `25r_j+15=5·4^(h+1)u`，合并
`-50·4^h+11·2^(2h+1)=-14·2^(2h+1)=-7·2^(2h+2)`。∎

**引理 11.2（三项估值拆分，恒等式）。** 写

```text
N = A + B + C,
A = 5^(h+1)(25r_j+15),   v_2(A)=2h+2,
B = -50·4^h,              v_2(B)=2h+1,
C = 11·2^(2h+1),          v_2(C)=2h+1.
```

则 `B+C=-14·2^(2h+1)`，`v_2(B+C)=2h+2`，且

```text
v_2(N)=2h+2+v_2(5^(h+2)u-7).
```

证明：直接合并即可。∎

**推论 11.3（尾词 `1 2^h` 的 2-adic 透明性，充要）。** 设 `h≥1`，
`o_0` 是 `X=1` 状态（`y=2o_0`）的奇部。若连续 `h` 步 `t=2`
中前 `h-1` 步保持 `X=1`、第 `h` 步得到 `X=2`，则

```text
o_0 ≡ 3·4^h - 1  (mod 2^(2h+2)).
```

该同余对这样的链是充要的。在归约族中，初始 `t=1` 步后的奇部为

```text
o_0 = 5·2^(2h)u - 1,
```

代入后等价于

```text
u ≡ 3 (mod 4),
```

而这正是归约族已知的前缀条件。因此尾词 `1 2^h` 对 `u` 的
2-adic 类不产生额外约束：它对 `e_k` 的控制是“透明的”，困难全部
留在块首前缀 `A_j` 通过 `u=(5r_j+3)/4^(h+1)` 对 `e_k` 的影响。

证明：`X=2` 的单步条件为 `5o+1≡8 (mod 16)`，即
`o≡11 (mod 16)`；保持 `X=1` 的条件为 `o≡7 (mod 8)`，且
`o'=(5o+1)/4`。归纳得

```text
o_0 ≡ a_h (mod 2^(2h+2)),   a_1=11,   a_{h+1}=4a_h+3,
```

故 `a_h=3·4^h-1`。代入 `o_0=5·2^(2h)u-1` 并除以 `2^(2h)`
即得 `5u≡3 (mod 4)`。∎

**评注（不闭合）。** 引理 11.1 是正确闭式，但三项拆分没有把问题
变小：它精确回到 `v_2(5^(h+2)u-7)`，而该量正是第 5 节的
`v_2(5^(L+1)u-7)`。用 `u<5^(j+1)/4^(h+1)` 的尺寸上界只能得到

```text
e_k < (j+h+3)log_2 5 - 2h - 3,
```

与目标 `e_k≤2j+12-2t_j-2h` 比较，需要
`αj+λh≤8.04-2t_j`；在 `j≥17`、`h≥1` 时不成立。因此该闭式
仍把缺口压在同一条语句上：

```text
5^(h+2)u ≡ 7  (mod 2^(2j+14-2t_j-2h))
```

在 `u=(5r_j+3)/4^(h+1)`、`r_j=(A_j+5^j q)/2^(W_j)` 的
可达范围内无解。这等价于第 8 节的单步子引理，不是新的可证子引理。

## 12. 2026-08-10 续：容量矛盾把单步排除分成偶数/奇数出口

新增 `x2_single_step_capacity_reduction.md`：

- 若容量条件 `h_i≤j-t_j+5`（所有 `u=1` 状态）成立，坏单步的出口
  估值 `X_{k+1}=1+e_k` 不能为偶数；偶数出口会迫使下一个 `u=1`
  状态满足 `h_{i'}≥j-t_j+6`，与容量条件矛盾。这是严格解析语句，
  不使用证书。
- 因此反例只能有奇数出口，且此时 `e_k` 为偶数、
  `e_k≥H_k+1`，块终端满足 `h_e≥j-t_j+7`、`H_e≤-1`。
- 充分收口：若终端不等式 `h_e≤j-t_j+6`（局部引理等价形式）成立，
  则单步 X=2 排除成立。

该归约不声称闭合；它把开放量分成“偶数出口（已由容量条件排除）”
与“奇数出口（等价于终端容量破坏）”两个子类。
