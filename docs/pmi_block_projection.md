## 1. 块层记号

设 `δ=0` 块之前的重置步为 `j≥1`，`t_j∈{1,2}`，
`δ_j∈{1,...,2^(t_j)-1}`。上一块的偶数终端为 `r_(j-1)`，满足

```text
0 ≤ r_(j-1) < 5^(j-1),
r_(j-1)+1 = 5^(k0)·s'',
```

其中 `k0≥0`，`s''` 为奇数，因此

```text
s'' ≤ 5^(j-1-k0).
```

重置方程为

```text
2^(t_j)·r_j = 5·r_(j-1)+1+δ_j·5^j.
```

令

```text
N = 2^(t_j)·(r_j+1)
  = 5^(k0+1)·s'' + δ_j·5^j + 2^(t_j)-4,
u_j = v2(r_j+1) = v2(N)-t_j.
```

对纯 `t=2` 块，S6 阶段 1 的目标是

```text
u_j ≤ 2(j-t_j)+12.
```

## 2. 局部余额恒等式（已证）

设块内 `t=2` 步数为 `H2`，块首估值 `u_j`，所有极大 `t=1`
游程终点（最后一个终点为偶数终端时计 `v2=0`）的充值量之和为
`F`。逐状态跟踪 `v2(r_i+1)` 得

```text
2·H2 ≤ u_j + F.
```

因此若块层预算

```text
u_j+F ≤ 2(j-t_j)+12
```

成立，则终端容量

```text
H2 ≤ j-t_j+6
```

成立。这条余额式是 C4′ 与 S6 终端的公共局部入口；它不是等价
改写，而是逐点估值的精确恒等式。

## 3. 块层 PMI 投影：重置头估值窗口

**投影（必要，精确）。** 若纯 `t=2` 块的块首估值失败，即

```text
u_j ≥ 2(j-t_j)+13,
```

则

```text
v2(N) ≥ 2j-t_j+13.
```

由 `N = 5^(k0+1)·s''+δ_j·5^j+2^(t_j)-4`，两边消去奇数因子
`5^(k0+1)`，得到唯一窗口：

```text
s'' ≡ -5^(-(k0+1))·(δ_j·5^j+2^(t_j)-4)
        (mod 2^(2j-t_j+13)),
```

且必须同时满足

```text
1 ≤ s'' ≤ 5^(j-1-k0).
```

**证明。** 失败假设给 `N` 的高 2 幂整除；`5^(k0+1)` 为奇数，
可逆，故 `s''` 的模类唯一。`s''` 的尺寸来自上一偶数终端
`r_(j-1)<5^(j-1)`。∎

该窗口使用的新全局量是上一块的 `5` 进指数 `k0` 与奇部 `s''`，
它们没有出现在旧阻塞语句 `V+b≤j+2-t_j`、`D_i≤i` 或
`H2≤j+5` 中。

## 4. 小深度大小闭合（已证）

先排除平凡奇偶情形：若 `δ_j` 为偶数，则 `N` 为奇数，不可能有
奇数块首 `r_j`，因此非平凡情形必有 `δ_j∈{1,3}`。

**情形 `t_j=1`。** 此时 `δ_j=1`，

```text
N = 5^(k0+1)·s''+5^j-2 ≤ 2·5^j.
```

失败给 `N ≥ 2^(2j+12)`。若

```text
2^(2j+12) > 2·5^j,
```

即 `(5/4)^j < 2^11`，也就是 `j≤34`，则大小矛盾。故 `t_j=1`
时 `j≤34` 的失败由纯不等式排除。

**情形 `t_j=2`。** 此时

```text
N = 5^(k0+1)·s''+δ_j·5^j ≤ 4·5^j.
```

失败给 `N ≥ 2^(2j+11)`。若

```text
2^(2j+11) > 4·5^j,
```

即 `(5/4)^j < 2^9`，也就是 `j≤27`，则大小矛盾。故 `t_j=2`
时 `j≤27` 的失败由纯不等式排除。

这两条是解析大小界，不是扫描证书；它们只覆盖小深度，不能替代
大深度窗口排除。

## 5. 失败时的全局参数约束（已证）

设 `t_j=2`、`δ_j∈{1,3}`，并记 `a=j-k0-1`。若块首失败
`v2(N)≥2j+11`，则

```text
s''+δ_j·5^a ≤ 4·5^a,
v2(s''+δ_j·5^a) ≥ 2j+11 = 2a+2k0+13.
```

由 `2^(2a+2k0+13) ≤ s''+δ_j·5^a ≤ 4·5^a` 得

```text
2^(2k0+11) ≤ (5/4)^a.
```

等价地，

```text
2k0+11 ≤ a·log_2(5/4).
```

这是失败的必要条件：失败块的上一终端 `5` 进指数 `k0` 被当前
重置深度与上一终端深度之差 `a` 线性压制。它把大深度窗口进一步
限制为 `k0` 远小于 `a` 的子族，但仍未排除该子族。

## 6. 唯一剩余不等式

剩余情形：

```text

```

在这些情形中，块首失败当且仅当第 3 节的唯一窗口

```text

        (mod 2^(2j-t_j+13)),
```

被真实上一终端奇部实现。**块层 PMI 投影的决定性语句是：**

> 对每个全局可达的 `δ=0` 块，上述窗口为空。

等价地，证明估值不等式

```text
v2(5^(k0+1)·s''+δ_j·5^j+2^(t_j)-4) ≤ 2j-t_j+12.
```

这是当前唯一剩余；它需要上一块的递推（`k0,s''` 由更早的块决定）


其中 `w` 的第 `i` 步前权重为 `W_i`（`W_0=0`），

```text
rj+1 = 5^(k+1)·t0·2^(U-2),   t0 < 5^N/4.
```

```text
7·5^L + A_w + 2^W = 2^W·5^(k+1)·2^(U-2)·t0.
```

## 10. 失败窗口代入完整轨道词方程后的精确剩余

把第 9 节的完整轨道词方程分别代入 `t_j=2` 与 `t_j=1` 的失败窗口，
得到两个显式 Diophantine 方程。它们不是新的等价归约，而是把
“唯一窗口为空”直接展开成轨道词参数 `(L,W,A_w)` 的语句。

**情形 `t_j=2`（S6 阶段 1，`M=1`）。** 失败时
`rj+1=5^(k0+1)·t0·2^(U-2)`，其中 `t0` 为奇数且 `5∤t0`。代入
轨道词方程得精确等式

```text
7·5^L + A_w + 2^W = 2^(W+U-2)·5^(k0+1)·t0.
```

这里 `U` 是失败同余里的总 `2` 进估值：
`U = v2(N) = v2(5^(k0+1)·(s''+δ·5^a))`，而
`u_j = v2(rj+1) = U-2`。因此 `U-2 = u_j`，常数换算没有额外
的 `±2` 偏差。

因此左侧的 `2` 进估值被完全固定：

```text
v2(7·5^L + A_w + 2^W) = W+U-2.
```

原失败条件是 `U-2 ≥ 2j+9`，所以闭合 `t_j=2` 等价于证明：对所有
满足上述精确等式与重置约束的完整轨道词，

```text
v2(7·5^L + A_w + 2^W) ≤ W+2j+8.
```

该式使用 `rj` 的完整轨道词方程；`k0` 约束只压缩 `a=j-k0-1` 的范围，
不单独给出这条估值上界。

再取模 `5^(k0+1)`：因为 `rj≡-1 (mod 5^(k0+1))`，得到

```text
7·5^L + Σ_{r=0}^{min(k0,L-1)} 2^(W_(L-1-r))·5^r ≡ -2^W (mod 5^(k0+1)),
```

其中 `r≥k0+1` 的项已被模 `5^(k0+1)` 消去。

最低位给出必要条件：末步权重
`t_(L-1)=W-W_(L-1) ≡ 2 (mod 4)`。这是轨道词必须满足的局部
`5` 进条件，但仍不能单独排除全部候选。

**情形 `t_j=1`。** 记 `a=j-k0-1`，失败必要条件
`v2(s''+5^a)=1` 给 `s''+5^a=2M`，`M` 为奇数。由
`N=2(rj+1)=5^(k0+1)(s''+5^a)-2` 与轨道词方程得精确等式

```text
7·5^L + A_w + 2^W = 2^W·(5^(k0+1)·M - 1),
```

等价地

```text
v2(5^(k0+1)·M - 1) = v2(rj+1).
```

原失败条件是 `v2(rj+1) ≥ 2j+11`。因此 `t_j=1` 闭合等价于证明：
对所有满足该等式与 `1≤M≤5^a` 的完整轨道词，

```text
v2(5^(k0+1)·M - 1) ≤ 2j+10.
```

这条剩余使用轨道词方程（通过 `rj+1` 的左侧表达式）、上一块的
递推（`k0,M` 来自 `r_(j-1)+1=5^k0·s''`），以及 `k0` 与 `a` 的
尺寸关系；`M≤5^a` 本身不足以排除
`5^(k0+1)·M ≡ 1 (mod 2^(2j+11))` 的大深度候选。

**方向 A：`k0` 因子 4 收紧不可由当前输入推出。**

若想用“模长大于区间长”把 t_j=1 的候选唯一化，需要

```text

```

（利用 `M>(5^a+1)/2` 后至多只需



所以方向 B 不是新的约束，而是同一方程的按词尾/词前缀重排；它

## 13. t_j=1 的剩余类位置形式（2026-08-12）

记

```text
Q = 2^(2j+11) = 2^(2a+2k0+13),
R = ⟨5^(-(k0+1))⟩_Q
```

为模 `Q` 的最小正剩余。失败等价于存在 `n≥0` 使

```text
5^a/2 < R + n·Q < 5^a/2 + 5^a/(2·4^(k0+1)).
```

把 `R=(h·Q+1)/5^(k0+1)` 代入，其中

```text
h ≡ -2^(-(2j+11))  (mod 5^(k0+1)),
```

并令 `H=h+n·5^(k0+1)`，则失败等价于存在整数 `H` 满足

```text
(5^j-2)/2^(2j+12) < H
  < (5^j-2+5^j/4^(k0+1))/2^(2j+12),
H ≡ h  (mod 5^(k0+1)).
```

这是 t_j=1 分支现在唯一剩余的不等式。它没有被闭合：区间长度是

```text
5^j/(2^(2j+12)·4^(k0+1))
  = (5/4)^a·(5/4)^(k0+1)/(2^12·4^(k0+1)),
```

它可以大于 `5^(k0+1)`，所以不能用“区间短于剩余类周期”直接排除。
剩余来自 `h` 的 `5` 进类：`h=-2^(-(2j+11)) mod 5^(k0+1)`；
不是来自 `R` 的低位 `2` 进位。

**附加筛选（`5∤s''` 的提升类）。** 由
`D=H·2^(2j+12)-5^j+2=5^(k0+1)·s''` 可知 `5∤s''` 等价于
`v5(D)=k0+1`，即 `H` 必须避开模 `5^(k0+2)` 的唯一提升类

```text
H ≠ -2^(-(2j+11))  (mod 5^(k0+2)).
```

这条把候选再筛掉一个 5 进提升，但仍未排除整个区间中的
`H≡h (mod 5^(k0+1))` 类；它不是闭合，而是剩余类位置的
必要条件。

## 14. t_j=1 的 r 归约（符号核对与精确形式，2026-08-12）

记

```text
P=5^(k0+1),  M0=2j+12,
L0=(5^j-2)/2^M0,
U0=(5^j-2+5^j/4^(k0+1))/2^M0.
```

设

```text
c=(h·2^M0+2)/P。
```

则

```text
h=(c·P-2)/2^M0,
L0-h = P·(5^a-c)/2^M0,
U0-h = P·(5^a-c+5^a/4^(k0+1))/2^M0。
```

因此 `H=h+t·P` 落在 `(L0,U0)` 等价于

```text
(5^a-c)/2^M0 < t < (5^a-c)/2^M0 + η,
η=5^a/(2^M0·4^(k0+1))。
```

由 `c·P≡2 (mod 2^M0)` 得

```text
c ≡ +2·P^(-1)  (mod 2^M0)。
```

令

```text
r = ⟨P^(-1)·(5^j-2)⟩_{2^M0},
```

则

```text
P·r ≡ 5^j-2 ≡ P·(5^a-c)  (mod 2^M0),
```

所以 `r/2^M0` 正是 `(5^a-c)/2^M0` 的小数部分。不存在整数
`t` 的充要条件是

```text
1 - r/2^M0 ≥ η。
```

符号核对：目标草稿中的 `r=⟨P^(-1)(5^j+2)⟩` 与
`c≡-2P^(-1)` 不成立；正确式是上面的 `5^j-2` 与 `+2P^(-1)`。

该归约是精确的，但不闭合：`r` 是模 `2^M0` 的一个显式剩余，
单独看没有下界保证 `1-r/2^M0≥η`。当 `η<1` 时仍需证明该剩余
类位置不等式；当 `η≥1` 时区间长度超过周期 `P`，必须使用完整
轨道词方程或 S6 前缀估值把候选压到 `P` 以下或钉到坏提升类
`h'`。

**`η≤5/7` 子分支未闭合（2026-08-12 修正）。** 提交
`d7cd2cd` 的“闭合”声明无效：它把候选变量 `s''` 和剩余变量 `r`
的方向用反了。正确判据不是 `r≥D`。

设 `D=η·2^M0=5^a/4^(k0+1)`。当 `η<1` 时 `D<2^M0`，候选 `t`
存在等价于 `s''<D`。由 `s''≡2^M0-r (mod 2^M0)` 与
`0<s''<D<2^M0` 得 `s''=2^M0-r`，因此候选存在等价于

```text

```

而“无候选”等价于

```text
1 - r/2^M0 ≥ η  ⇔  r ≤ 2^M0 - D。
```

b=1 宏链界给出

```text
s'' < (2/5)·D  ⇔  r > 2^M0 - (2/5)·D。
```

当 `η≤5/7` 时 `2^M0-(2/5)·D ≥ D`，但这只是 `r` 的一个下界；
无候选需要的是 `r≤2^M0-D`，方向相反，因此该子分支不能由这条
宏链界闭合。例如 `η=0.4` 时无候选要求 `r≤0.6·2^M0`，而
`r=0.5·2^M0` 虽满足 `r≥D` 却不产生候选；宏链界给出的
`r>0.84·2^M0` 恰好强制候选存在。

剩余窗口保持第 14 节开头的形式：对 `η<1` 需证
`1-r/2^M0≥η`，即 `r≤2^M0-D`；`η≥1` 仍需完整轨道词/S6 前缀的
新全局约束。这里的障碍来自 `r` 的 2-adic 距离，不来自 `k0`
约束或 `H` 的 5 进提升。

## 15. b=1 最大终止链进入 t_j=1 窗口（2026-08-12）

设上一块最后 `u=1` 状态为 `p`，终止段为一步 `t=1` 后接 `k0`
步 `t=2`，且 `p+1+k0=j-1`。这是局部引理归约中的最大 `t=2`
终止链情形；此时

```text

```

由 `r_{p+1}+1=(5r_p+3)/2` 与 `t=2` 链恒等式
`4^{k0}(r_{j-1}+1)=5^{k0}(r_{p+1}+1)`，代入
`r_{j-1}+1=5^{k0}·s''`，得到精确恒等式

```text
s'' = (5r_p+3)/2^(2k0+1)。
```

这是恒等式，不是新假设。上一块 S6 在该分支等价于终端容量
`h_{j-1}≤j0-t0+6`，其中 `h_{j-1}=h_p+k0`；等价地
`D_{j-1}≤j+5`。这条只约束重量预算，不约束 `r_p`，因此它不与
`X_p=2k0+1` 矛盾。

t_j=1 无候选的一个充分条件是 `s''≥D`，其中

```text

```

候选存在只可能发生在 `s''<D`，所以 `s''≥D` 确实排除候选。
代入上述恒等式得到精确整数不等式


即 `r_p ≥ (5^a-6)/10`。这就是该分支真正剩余的下界：它是
`r_p` 的 5-adic 上/下半区间判定，等价于 `q_p` 的
Cycle Embedding / `q*` 上半区间问题；S6 的重量上界不蕴含它。
该分支仍未闭合。

### 15.1 `q*` 上半区间路径的适用边界（2026-08-12）

### 15.3 `p=j0,t_p=2` 的 `δ` 分支（解析闭合，2026-08-12）

## 16. t=2 分支：`A_w` 的固定系数+指数变量归约（2026-08-12）

**引理 16.1（`A_w` 闭式，充要）。** 设完整轨道词长度为 `L`，
恰有 `b` 个 `t=2` 步，位置

```text
0 ≤ p_1 < ... < p_b < L，
```

总权重 `W=L+b`，则

```text
A_w = (5^L - 2^W + S)/3,
S = Σ_{j=1}^{b} 2^(p_j+j)·5^(L-p_j-1)。
```

**证明。** 由命题 24.1，

```text
A_w = A_all1(L)+Σ_{j=1}^{b}2^(j-1)·Δ_(p_j)
    = (5^L-2^L)/3
      + Σ_{j=1}^{b}2^(j-1)·(2^(p_j+1)·5^(L-p_j-1)-2^L)/3。
```

合并 `2^L` 项时系数为
`1+Σ_{j=1}^{b}2^(j-1)=2^b`，而 `2^(L+b)=2^W`，即得闭式。∎

因此

```text
7·5^L + A_w + 2^W
= (22·5^L + 2^(W+1) + S)/3，
```

所以

```text
v2(7·5^L + A_w + 2^W)
= v2(22·5^L + 2^(W+1) + S)。
```

又 `22·5^L` 的 `v2=1`，且 `S` 的每一项都有因子 `2`，于是

```text
v2(7·5^L + A_w + 2^W)
= 1 + v2(11·5^L + 2^W + S/2)。
```

这是目标不等式 `v2(...)≤W+2j+8` 的标准指数线性型入口：所有
变量只出现在指数 `L,W,p_j` 中。当前 `S` 的项数 `b` 未被控制，
因此还不能直接引用定理 12.1；下一步是把 `b` 或 `S` 的项数压缩
到固定常数，或证明这些项可以合并为固定项数的指数线性型。

## 17. 反向精度直接证明（2026-08-12）

本节不把窗口改写进 A1/C1 或 p-adic 线性型，而是直接对失败估值
做反向传播。对 `t=2` 与 `t=1` 统一记

```text
E = 2j+9   (t=2),
E = 2j+11  (t=1)。
```

两条失败条件都等价于 `rj≡-1 (mod 2^E)`。

**引理 17.1（反向精度增益，充要）。** 设
`r_i=(5r_(i-1)+1)/2^(t_i)` 且 `r_i≡-1 (mod 2^(E_i))`，则

```text
r_(i-1) ≡ -5^(-1)·(2^(t_i)+1)  (mod 2^(E_i+t_i))。
```

**证明。** 由 `5r_(i-1)+1=2^(t_i)r_i` 与 `r_i≡-1` 得
`5r_(i-1)+1≡-2^(t_i) (mod 2^(E_i+t_i))`；`5` 在模 `2` 幂下可逆，
整理即得。∎

**推论 17.2（初始状态残差，充要）。** 若完整轨道词 `w` 从 7
走到 `rj` 且 `rj≡-1 (mod 2^E)`，则

```text
7·5^L + A_w + 2^W ≡ 0  (mod 2^(E+W))。
```

等价地，

```text
7 ≡ -5^(-L)·(2^W + A_w)  (mod 2^(E+W))。
```

**证明。** 沿 `w` 从末状态反向迭代引理 17.1，累计精度为
`E+Σ t_i=E+W`；初始状态为 7。∎

**推论 17.3（逐位条件，充要）。** 推论 17.2 等价于
`2^W(rj+1)` 的 2-adic 展开低 `E+W` 位全为零。因子 `2^W` 已贡献
`W` 位，剩余 `E` 位正是 `rj+1` 的失败估值。基 5 数字系统
（第 30.2 节）把 `A_w` 的 `L` 个数字与这个大同余逐位绑定。

**当前状态。** 推论 17.2 是两条窗口不等式的同一反向传播形式，
但尚未闭合：

- `t=2`：证明不存在合法词 `w` 使
  `7·5^L+A_w+2^W≡0 (mod 2^(W+2j+9))`；
- `t=1`：同上，但模指数为 `W+2j+11`。

引理 17.1 与推论 17.2 是严格充要的反向精度时钟，不依赖定理
12.1。

**推论 17.4（已撤销，无效）。** 旧文本声称 `rj` 是深度 `j` 的
状态，因此 7 到 `rj` 的完整词长 `L=j`，并由此得到
`A_w<5^j`、`2^(W_j)≤4^j` 与 `N<9·5^j` 的尺寸矛盾。该前提
不成立：`j` 是块内深度，不是完整轨道词长；真实块首反例

```text

7 到 229 的唯一合法词 [2,1,2,1,1,2],  L=6, W=9
```

给出 `A_w=7873>5^4`、`2^9=512>4^4`，因此 `N<9·5^j` 不成立。
推论 17.4 无效；两条窗口不等式仍开放。

## 18. 块级进位自动机（2026-08-12）

本节不声称闭合窗口估值；它把 t=2 分支写成精确的逐数字进位自动机，
并给出块转移矩阵与谱半径命题的准确陈述。自动机的状态与转移是可
证明的恒等式，已同步到 `lean/BlockAutomaton.lean`；谱半径命题本身
仍是开放语句。

### 18.1 t=2 分支的输入

固定合法 δ=0 块，`t_j=2`，记 `a=j-k0-1≥0`，`δ∈{1,3}`，
`s''` 为上一偶数终端的奇部：`s''` 为奇数、`5∤s''`，且在归纳假设
“所有更早块满足 S6”下有 `0<s''<5^a/4`。窗口估值是

```text
v2(5^(k0+1)·s''+δ·5^j) = v2(s''+δ·5^a),
```

目标为

```text
v2(s''+δ·5^a) ≤ 2a+2k0+12。
```

右边 `5^(k0+1)` 是奇数，因此消去它是恒等（必要且充分）。

### 18.2 精确状态与转移（已证恒等式）

把 `s''+δ·5^a` 写成基 5 数字串：最高位是 `δ`，随后是 `s''` 的
从高位到低位的数字 `d_{a-1},...,d_0`。自动机从高位向低位读数字，
用递推

```text
n ← 5n+d。
```

**状态。** `(e,u)`，其中 `n=2^e·u` 且 `u` 为奇数；`e` 是当前
`2` 进估值，`u` 是当前奇部。

**转移。** 对数字 `d∈{0,...,4}`，

```text
n' = 5n+d,
e' = v2(n'),
u' = n'/2^(e')。
```

即 `T_d(e,u)=(v2(5·2^e·u+d), oddPart(5·2^e·u+d))`。这是精确
恒等式，不是近似。`lean/BlockAutomaton.lean` 中
`valuationStep_correct` 证明 `n'=2^(e')·u'` 且 `u'` 为奇数。

转移表（精确恒等式，逐项由 `valuationStep_correct` 可直接验证）：

```text
d=0:  e'=e,  u'=5u;
e=0, d=1:       e'=v2(5u+1);
e=0, d=3:       e'=v2(5u+3);
e=0, d=2 或 4:  e'=0;
e=1, d=2:       e'=1+v2(5u+1);
e=1, d=4:       e'=1;
e=1, d=1 或 3:  e'=0;
e=2, d=4:       e'=2+v2(5u+1);
e=2, d=2:       e'=1;
e=2, d=1 或 3:  e'=0;
e≥3, d=1 或 3:  e'=0;
e≥3, d=2:       e'=1;
e≥3, d=4:       e'=2。
```

因此高估值只能由低状态 `e≤2` 配合特定数字产生：

```text
(e=0,d=1): e'=v2(5u+1),
(e=0,d=3): e'=v2(5u+3),
(e=1,d=2): e'=1+v2(5u+1),
(e=2,d=4): e'=2+v2(5u+1)。
```

一旦 `e≥3`，任何非零数字都把估值重置到 `{0,1,2}`，数字 0 保持
`e'=e`。这正是块级加权自动机的谱结构：高估值只能由上述四类单步
提升产生，并且提升量由 `v2(5u+1)` 或 `v2(5u+3)` 控制。

### 18.3 块转移与块矩阵（谱半径命题，开放）

对固定 `(a,δ,s'')`，块转移是转移函数的合成：

```text
B = T_{d_0} ∘ T_{d_1} ∘ ... ∘ T_{d_{a-1}} ∘ T_δ，
```

先读最高位 `δ`，进入状态 `(v2(δ), δ/2^(v2(δ)))`，再依次读
`d_{a-1},...,d_0`；最终状态的 `e` 等于 `v2(s''+δ·5^a)`。

对固定数字串长度 `a`，把每个数字 `d` 对应的转移写成加权矩阵
`M_d`：若只统计“能由同一块链前提实现的数字串”，则块矩阵

```text
M_a = M_{d_0}·M_{d_1}·...·M_{d_{a-1}}·M_δ
```

的联合谱半径命题是：

**命题 18.1（块级谱界，开放）。** 对全体可达 δ=0 块，存在常数
`C` 使块转移的摊销增长满足


### 19.1 末位归约引理（已证，必要且充分）


**证明。** 自动机按高位到低位读数字，`n_0` 是去掉末位后的前缀值，

因为 `s''` 为奇数且 `5∤s''`，末位 `d≠0`，所以最终高估值不可能

步恰为四类提升之一。直接代入 `5n_0+d` 即得四条等式。∎


3. 剩下只需排除 `e≥3` 的 t=2 链在 `e` 为偶数且 `≥4` 的阶段
   命中窗口。链上 `M=M_0/4^s`、`e=e_0-2s`、`k=s`，目标化为：
   对真实链初态 `(e_0,k=0,M_0)`，不存在 `s` 使
   `2^(e_0-2s)·m_0 ∈ (δ5^a,(δ+1/4)5^a)` 且 `e_0-2s≥4`。

该框架把 G 收窄到 K 与 t=2 链窗口回避；两者仍未闭合。

**e=2 步进入 5∣r'+1 的精确判据（已证恒等式）。** 设
`r=4m-1`、`v=v_2(5m-1)`、`q=(5m-1)/2^v`。则
`k'=v_5(q+1)≥1` 当且仅当

```text
v ≡ 0 (mod 4)。
```

**证明。** `q≡-2^(-v) (mod 5)`，故
`q+1≡1-2^(-v) (mod 5)`；`2^(-v)≡1 (mod 5)` 当且仅当
`v≡0 (mod 4)`。∎

因此子引理 K 恰好等价于：完整轨道上每个 `e=2` 步都产生
`5∤r'+1`。这是任务 2 在 `e=2` 分支的精确形式。

**t=2 链窗口缩放的精确形式（已证恒等式）。** 固定目标深度
`j`，链初态 `(e_0,k_0,M_0)` 的窗口指数 `a_0=j-1-k_0`。经过
`s` 步 `e≥3` 转移后，

```text
M_s=M_0/4^s,  k_s=k_0+s,  a_s=j-1-k_s=a_0-s,
```

故

```text
M_s∈(δ5^(a_s),(δ+1/4)5^(a_s))
  ⇔  M_0∈(δ(4/5)^s 5^(a_0),(δ+1/4)(4/5)^s 5^(a_0))。
```

这是任务 1 的严格形式：窗口随 `M→M/4`、`a→a-1` 同步缩放，
窗外性沿单条 t=2 链保持；链间重置（`e=1,e=2`）由上面的
`k'=0` 与 K 判据控制。

**δ=1 时链窗口的铺砌恒等式（已证）。** 固定 `a_0`，令
`L_s=(4/5)^s·5^(a_0)`。因为 `(5/4)^1=5/4`，所以

```text
∪_{s≥0}(L_s, (5/4)L_s) = (0, (5/4)·5^(a_0)]，
```

即 `δ=1` 的窗口族把区间 `(0,1.25·5^(a_0)]` 无缝铺满。于是对
`M_0`（非边界值）存在唯一 `s` 使 `M_0∈(L_s,1.25L_s)`，并且

```text
s = ⌊log_{5/4}(5^(a_0)/M_0)⌋+1,
```

链命中 `δ=1` 窗口当且仅当该唯一 `s` 满足
`e_0-2s` 为偶数且 `≥4`。这把链窗口回避压成单条整数不等式；
边界值 `M_0=L_s` 落在窗口族的开区间之外，不影响坏窗口判定；
对 `δ=3` 窗口族有间隙，不能铺砌，需单独处理。

### 19.10 K 与链窗口回避的 t=1 游程闭式（2026-08-12）

本节把 K 与链窗口回避第一次写成不依赖词表、只依赖“最大 `e=1`
游程起点”的显式闭式。它仍不闭合 G，但把两条剩余语句压缩成
两个单变量/双参数 2-adic 估值不等式，并暴露一条此前缺失的
精确前提：链初态必须是完整轨道上真实游程的产物，仅靠
`e=1` 出生关系不够。

**引理 19.10.1（最大 `e=1` 游程闭式，充要）。** 设完整轨道上
`r+1=2a`、`e=1`，且 `r` 是连续 `e=1` 段的第一项（前一状态
的 `e≠1`）。令

```text
λ=v_2(3a-1),  c=(3a-1)/2^λ 为奇数。
```

则该 `e=1` 段恰好含 `λ` 个状态，段末下一状态的

```text
B_0=5a_{λ-1}-1=2(c5^λ+1)/3,
e_0=v_2(B_0)=1+v_2(c5^λ+1),
m_0=B_0/2^{e_0}=(c5^λ+1)/(3·2^{e_0-1})。
```

**证明（恒等式）。** `e=1` 段内 `a_{i+1}=(5a_i-1)/2`，闭式

```text
a_i=(5^i a-(5^i-2^i)/3)/2^i,
```

于是

```text
5a_i-1=[5^{i+1}(3a-1)+2^{i+1}]/(3·2^i)
       =2(5^{i+1}2^{λ-i-1}c+1)/3。
```

当 `i+1<λ` 时括号内为 `1+偶数`，是奇数，故
`v_2(5a_i-1)=1`，游程继续；当 `i+1=λ` 时括号内为
`5^λ c+1`，是偶数，游程结束并得到上式。∎

**推论 19.10.2（链窗口两项不等式，充要）。** 设链初态
`(e_0,k_0=0,m_0)` 由引理 19.10.1 的游程产生，令
`X=c5^λ+1`。则第 `s` 步 `e≥3` 链命中坏窗口，当且仅当存在
`N≥0`、`δ∈{1,3}` 使

```text
e_s=e_0-2s=1+v_2(X)-2s≥4 为偶数，
δ·3·2^(2s-1)·5^N < X < (δ+1/4)·3·2^(2s-1)·5^N。
```

等价地，`M_s=2^(1-2s)X/3∈(δ5^N,(δ+1/4)5^N)`。由于 `X` 与
`δ·3·2^(2s-1)·5^N` 均为整数，左端严格不等式可写为
`δ·3·2^(2s-1)·5^N+1 ≤ X`。∎

**注意（必要：出生关系不是充分前提）。** 纯算术版链回避已被
目标中的 `m_0=201` 否证。在引理 19.10.1 参数下该例为

```text
a=2573,  λ=1,  c=3859,  X=19296,
e_0=6,  m_0=201,  s=1,  N=5,  δ=1,
3·2^(1)·5^5=18750 < 19296 < 23437.5=(5/4)·18750。
```

它满足全部局部约束：出生关系、`e_s=4≥4`、窗口命中，且
`r_s=B_s-1=5·3216-1=16079` 给出非负的
`r_{j-1}=16079-5^6=454<5^6`。该例只被一条前提排除：
`a=2573` 对应的轨道状态 `r=2a-1=5145` 不在完整轨道上
（有限回归核验，非证明）。
因此修正后的链窗口回避必须显式携带“`a` 是完整轨道上最大
`e=1` 游程起点”，不能只写出生关系。

**引理 19.10.3（K 的游程参数形式，充要）。** 在引理 19.10.1
记号下，若 `e_0=2s+2` 为偶数，则 `t=2` 链终点
`e=2` 处的 K 条件

```text
v_2(5^(s+1)m_0-1)≢0 (mod 4)
```

等价于

```text
v_2(c5^(λ+s+1)+5^(s+1)-3·2^(2s+1))≢2s+1 (mod 4)。
```

特别地，`s=0`（即 `e_0=2`）时化为

```text
v_2(5^(λ+1)c-1)≢1 (mod 4)。
```

**证明。** `5^(s+1)m_0-1=(5^(s+1)X-3·2^(2s+1))/(3·2^(2s+1))`，
分母 2-adic 估值恰为 `2s+1`，代入 `X=c5^λ+1` 即得。∎

**引理 19.10.4（K 的 `e=2` 出生形式，充要）。** 若链初态由
`e=2` 状态 `(m_p,v_p)` 经 `e=2` 步产生，且
`e_1=v_2(q+1)` 为偶数、`e_1≥2`：

```text
q=(5m_p-1)/2^(v_p),  e_1=v_2(q+1),  s=(e_1-2)/2,
```

则链终点 `e=2` 的 K 条件等价于

```text
v_2(5^(s+2)m_p-5^(s+1)+5^(s+1)·2^(v_p)-2^(e_1+v_p))
  ≢ v_p+e_1 (mod 4)。
```

对应链窗口命中等价于

```text
δ·2^(v_p+2s)·5^N < 5m_p-1+2^(v_p) < (δ+1/4)·2^(v_p+2s)·5^N。
```

**证明。** 由 `q+1=2^(e_1)m_1` 与
`M_s=(5m_p-1+2^(v_p))/2^(v_p+2s)` 代入窗口；K 的分子代入
`m_1=(5m_p-1+2^(v_p))/2^(v_p+e_1)` 即得。∎

**推论 19.10.5（坏窗口钉定游程起点，必要）。** 在引理 19.10.1
与推论 19.10.2 的命中前提下，`e_s≥4` 给出
`v_2(X)≥2s+3`，即

```text
c ≡ -5^(-λ)  (mod 2^(2s+3))。
```

由 `3a-1=2^λ c`，这等价于把游程起点 `a` 唯一钉在
`mod 2^(λ+2s+3)` 的一个显式剩余类。该剩余类是把链窗口回避
接到“反向精度阶梯”的入口；K 与链窗口回避仍未闭合。

**状态。**
- 引理 19.10.1、推论 19.10.2、引理 19.10.3、19.10.4、
  推论 19.10.5：已证（纯代数/估值恒等式）。
- K：全轨道版已否证（见 19.14，`n=90`）。剩余语句必须删除
  无条件 `e=2` 坏状态；只能保留“e=2 后继进入 `e≥4` 偶数且
  携带真实偶数终端关系”的转移型条件。若沿用旧 K，目标为假。
- 链窗口回避：未闭合。剩余为：完整轨道每个最大 `e=1` 游程
  起点 `a`（以及每个 `k_0=0` 的 `e=2` 出生链初态）不满足
  19.10.2/19.10.4 的两项不等式与 `e_s≥4`。
- G：未闭合。`m_0=201` 仍只是“非真实链初态”的校准反例，
  不是 G 反例；`485699` 仍只说明坏窗口必须限制 `e≥4`。

### 19.11 链窗口的近似形式与 N=0 排除（2026-08-12）

**引理 19.11.1（窗口近似形式，充要）。** 在推论 19.10.2 的
记号下，链窗口命中当且仅当存在偶数 `w≥4`、整数 `N≥1`、
`δ∈{1,3}`，使

```text
3δ·5^N < 2^w·u < (3δ+3/4)·5^N，
```

其中

```text
u=X/2^(v_2(X)) 为 X 的奇部，
w=v_2(X)-2s+1=e_s。
```

特别地，`N=0` 不可能命中。

**证明。** `M_s=2^(1-2s)X/3=2^w·u/3`。窗口
`M_s∈(δ5^N,(δ+1/4)5^N)` 两边乘以 `3` 即得第一式；由坏窗口
要求 `e_s≥4` 为偶数，`w=e_s` 为偶数且 `w≥4`。若 `N=0`，
区间为 `(3δ,3δ+3/4)`，对 `δ=1,3` 均不含整数，而 `2^w·u`
是整数，矛盾，故 `N≥1`。∎

**说明（必要，剩余不变量）。** 该形式把链窗口回避压缩成一条
纯 Diophantine 逼近语句：对完整轨道每个真实游程起点 `a`，
`u=oddPart(c5^λ+1)` 不能被某个偶数 `w≥4` 的 `2^w` 倍塞进
`(3δ5^N,(3δ+3/4)5^N)`。`u` 满足的额外结构是
`u≡2^(-v_2(X)) (mod 5)` 且 `3|u`；这两条加上 `a` 的完整轨道
可达性，仍未给出解析排除，是本节的唯一剩余。

**注意（必要：出生关系 + 窗口仍不是 G 的充要表述）。** 即使链
初态是完整轨道的真实游程产物，窗口条件本身仍可能被满足。真实
链初态 `(e_0=12,m_0=579)`（来自 `a=75891`、`λ=3`）在
`s=0`、`a_0=9`、`δ=1` 下满足

```text
M_0=2^(12)·579=2371584 ∈ (5^9, (5/4)·5^9),
e_0-2s=12≥4。
```

但该窗口给出的偶数终端
`r_{j-1}=2371583-5^9=418458` 不是 7 的完整轨道偶数终端
（有限回归核验，非证明）。因此“真实链初态 + 出生关系 + 窗口”
仍不是 G 的充分条件；链窗口回避必须把 `a_0` 与完整轨道偶数终端
`r_{j-1}=r_s-δ5^(a_0)` 的可达性绑定。这正是 G 自身的可达性部分，
不能靠游程闭式消去。修正后的剩余语句是：对每个真实链初态与每个
真实偶数终端关系，`s≥0` 的窗口命中不成立。

### 19.12 K 的链不变量压缩与链窗口回避的不可拆分性（2026-08-12）

**引理 19.12.1（K ⇔ 偶链常数，充要）。** 对偶数状态
`e=2r` 定义

```text
D_r:  v_2(5^r·m-1)≢0 (mod 4)。
```

沿 `t=2` 链 `(2r,m)→(2r-2,5m)` 有

```text
v_2(5^(r-1)·5m-1)=v_2(5^r·m-1)，
```

故 `D_r` 在整条偶链上不变。K 成立当且仅当每个偶数状态
`(2r,m)` 都满足 `D_r`。因此只需检查偶链出生状态。

**引理 19.12.2（奇链出生的 D 传递，充要）。** 设 `e=1` 状态
`(1,m)` 满足 `H=v_2(5m-1)=2r`，其 `t=1` 后继为
`(2r,m')`，`m'=(5m-1)/2^(2r)`。则 `D_r` 在该后继成立当且仅当

```text
v_2(5^(r+1)·m-5^r-4^r) ≢ 2r (mod 4)。
```

**证明。**
`5^r·m'-1=(5^(r+1)·m-5^r-4^r)/4^r`，分母 2-adic 估值
`2r`，代入 `D_r` 即得。∎

**引理 19.12.3（偶链出生的 D 传递，充要）。** 设 `e=2` 状态
`(2,m)` 满足 `F=v_2(5m-1)=v`，且

```text
q=(5m-1)/2^v,  e'=v_2(q+1)=2r,  m'=(q+1)/2^(2r)。
```

则 `D_r` 在 `(2r,m')` 成立当且仅当

```text
v_2(5^(r+1)·m-5^r+5^r·2^v-2^(v+2r)) ≢ v+2r (mod 4)。
```

**证明。** `5^r·m'-1` 通分得
`(5^(r+1)m-5^r+5^r·2^v-2^(v+2r))/(2^(v+2r))`，
分母 2-adic 估值为 `v+2r`。∎

因此 K 的剩余是两条出生传递不等式的统一证明：对每个奇链出生
与偶链出生，相应估值不得等于指定模 4 类。该形式把 K 从“完整
轨道任意 `e=2` 状态”压缩为“偶链常数 `F` 永不为 0 mod 4”，
但仍未闭合。

**注意（必要：链窗口回避不可拆分为独立引理）。** 链窗口回避若
不引用 G 的完整可达性，会同时被两个方向的缺失击穿：

1. 真实链初态 `(12,579)` 在 `s=0,a0=9,δ=1` 命中窗口，但
   `r_{j-1}=418458` 不是偶数终端；
2. 完整轨道上的中间偶值 `146=2·73`（由 `29→73` 的 `5x+1` 分解
   产生）满足 `147<5^4/4`（`a0=4`），但对应的
   `r_s=146+5^4=771` 不在完整轨道。

因此“出生关系 + 窗口”既缺 `r_{j-1}` 的偶数终端性，又缺 `r_s`
的轨道性；两条正是 G 自身的两个可达性分量。链窗口回避不能作为
不引用 G 可达性的独立引理成立，正确形态就是把 G 原样保留。

### 19.13 修正后的链窗口回避（G 等价形式，2026-08-12 续）

目标已修正：允许引用 G 的两个可达性分量。链窗口回避不再作为
独立引理，而是等价重述为 G 的精确条件。

**引理 19.13.1（窗口命中 ⇔ `s''` 小，充要）。** 固定真实块首
`r_j`、上一偶数终端 `r_{j-1}+1=5^(k_0)s''`、链初态
`(e_0,k_0,M_0)`，第 `s` 步链状态 `r_s` 满足 `e_s≥4`。则

```text
M_s∈(δ5^(a_0-s),(δ+1/4)5^(a_0-s))
  ⇔  s''<5^(a_0)/4。
```

**证明。** `r_s+1=5^(k_0)s''+δ5^(j-1)=5^(k_0)(s''+δ5^(a_0))`
且 `k_s=k_0+s`，故

```text
M_s=(s''+δ5^(a_0))/5^s。
```

窗口两边乘以 `5^s` 得
`δ5^(a_0)<s''+δ5^(a_0)<(δ+1/4)5^(a_0)`，即
`0<s''<5^(a_0)/4`。∎

**引理 19.13.2（修正后链窗口回避，G 等价，开放）。** 若

```text
r_{j-1}+1=5^(k_0)s'',  0<s''<5^(a_0),
r_s=r_{j-1}+δ5^(j-1) 在完整轨道上,
e_s=v_2(r_s+1)≥4 为偶数,
```

则 `s''≥5^(a_0)/4`。

这是 G 在 `t=2` 链分支上的精确剩余：它显式携带 `r_{j-1}` 的
偶数终端性与 `r_s` 的完整轨道性，不再尝试绕开 G。

**推论 19.13.3（词结构同余，必要）。** 设 `r_s` 在完整轨道深度
`d`，总权重 `W_d`，词分子
`A_d=Σ_{i=0}^{d-1}2^(W_i)5^(d-1-i)`。若 `d≥j`，则

```text
2^(W_d)(5^(k_0)s''-1+δ5^(j-1))
  ≡ Σ_{p=0}^{j-1}2^(W_(d-1-p))·5^p  (mod 5^j)。
```

**证明。** 轨道词方程 `2^(W_d)r_s=7·5^d+A_d`，代入
`r_s=5^(k_0)s''-1+δ5^(j-1)`；`d≥j` 时 `7·5^d≡0 (mod 5^j)`，
而 `A_d mod 5^j` 的后 `j` 位系数正是 `2^(W_(d-1-p))`。∎

该同余把修正后的链窗口回避变成“`s''` 的小性与词尾部
`2^(W_(d-1-p))` 的基 5 进位结构不相容”的单一解析语句；K 与
该语句均仍未闭合。

**引理 19.13.4（真实块窗口只能发生在 `s=0`，已证）。** 设

```text
r_{j-1}+1=5^(k_0)s'',  5∤s'',  0<s''<5^(a_0),
r_s=r_{j-1}+δ5^(j-1),  r_s 在完整轨道上,  e_s≥4。
```

则 `s=0`。

**证明。** 链式给出 `v_5(r_s+1)=k_0+s`，而
`r_s+1=5^(k_0)(s''+δ5^(a_0))`，故
`v_5(s''+δ5^(a_0))=s`。若 `a_0≥1`，则
`s''+δ5^(a_0)≡s''≢0 (mod 5)`，所以 `s=0`；若 `a_0=0`，则
`s''<5^0=1` 无正整数解。∎

**推论 19.13.5（链窗口回避只剩 `s=0`，充要）。** 修正后的链窗口
回避等价于：对真实块首的奇数前驱 `r`，若

```text
e=v_2(r+1)≥4 为偶数,  r=r_{j-1}+δ5^(j-1),
r_{j-1}+1=5^(k_0)s'',  5∤s'',
```

则 `s''≥5^(a_0)/4`。目标中的 `m_0=201,s=1` 反例被引理
19.13.4 直接排除，不需要轨道回归：真实块中 `s≥1` 与
`5∤s''` 不相容。

因此链窗口回避不再是“沿整条链排除”，而是单状态 G 语句：
真实前驱 `r` 的 5-adic 前缀不能同时满足“偶数高估值”和
“`s''<5^(a_0)/4`”。K 与该单状态语句仍未闭合。

**引理 19.13.6（偶数终端后继的窗口等价形式，充要）。** 设
上一偶数终端 `r_{j-1}=2y`，其中 `y` 是完整轨道上的奇数状态。
则窗口命中当且仅当

```text
2y+1 < 5^j/4。
```

**证明。** `r_{j-1}+1=2y+1=5^(k_0)s''`，故
`s''=(2y+1)/5^(k_0)`。窗口 `s''<5^(a_0)/4` 等价于
`2y+1<5^(k_0+a_0)·5/4=5^(j-1)·5/4=5^j/4`。∎

**引理 19.13.7（块首窄区间形式，充要）。** 设 `r_j=(5r+1)/4`
是真实 `t_j=2` 块首。窗口命中当且仅当

```text
r_j+1 ∈ (δ·5^j/4, δ·5^j/4+5^j/16)，
```

且 `v_5(r_j+1)=k_0+1`、`4·5^(k_0+1) | r_j+1`。

**证明。** `r_j+1=5(r+1)/4=5^(k_0+1)(s''+δ5^(a_0))/4`。
由窗口 `0<s''<5^(a_0)/4` 得
`δ5^j/4<r_j+1<(δ+1/4)5^j/4`，即上式；又
`5∤(s''+δ5^(a_0))` 且 `s''+δ5^(a_0)≡0 (mod 4)`，
故 `v_5(r_j+1)=k_0+1` 且 `4·5^(k_0+1)|r_j+1`。反向代入即得。∎

**注意（必要：窄区间形式仍不充分）。** 真实轨道状态
`r_j=2964479` 满足 19.13.7 的窄区间：取 `δ=1,j=10` 时

```text
r_j+1=2964480 ∈ (2441406.25, 3051757.8125)，
```

且 `v_5(r_j+1)=1`、`4·5|r_j+1`。但它对应的
`r_{j-1}=(4r_j-1)/5-δ5^(j-1)=418458` 不是完整轨道偶数终端
（有限回归核验，非证明）。因此 19.13.6/19.13.7 必须保留
`y` 在完整轨道上（即 `r_{j-1}` 的偶数终端可达性）这一前提；
这正是 G 的不可删分量。修正后的单状态剩余为：

```text
y 在完整轨道上且 2y+1<5^j/4 不可能与
r=2y-1+δ5^(j-1) 在完整轨道上、e(r)≥4 同时成立。
```

**引理 19.13.8（词尾商形式，充要）。** 在窗口前提下令

```text
z=(r_j+1)/(4·5^(k_0+1))。
```

则

```text
z 为整数,  5∤z,  v_2(z) 为偶数,
z ∈ (δ·5^(a_0)/16, δ·5^(a_0)/16+5^(a_0)/64)。
```

若 `r_j` 在完整轨道深度 `d+1` 且 `d+1≥j`，则

```text
4·2^(W_(d+1))·z
  ≡ (2^(W_(d+1))+Σ_(p=0)^(j-1)2^(W_(d-p))·5^p)/5^(k_0+1)
  (mod 5^(a_0))，
```

且上式右端分子的 `v_5` 恰为 `k_0+1`。

**证明。** 由 19.13.7 的区间除以 `4·5^(k_0+1)` 得 `z` 的区间；
`5∤z` 来自 `v_5(r_j+1)=k_0+1`，`v_2(z)` 为偶数来自
`e(r)=4+v_2(z)`。词方程
`2^(W_(d+1))(r_j+1)=7·5^(d+1)+A_(d+1)+2^(W_(d+1))`
在 `d+1≥j` 时模 `5^j` 消去 `7·5^(d+1)`，再除以 `5^(k_0+1)`
即得同余。∎

因此单状态 G 的剩余被压成一条词尾 Diophantine 逼近：完整轨道
词的最后 `j` 个权重 `W_(d-p)` 所确定的模 `5^(a_0)` 剩余类，
其最小非负代表必须同时落在
`(δ·5^(a_0)/16,δ·5^(a_0)/16+5^(a_0)/64)`、满足 `5∤z` 与
`v_2(z)` 为偶数。该语句与 K 均仍未闭合。

**引理 19.13.10（累计尾权 5-adic 级数形式，充要）。** 设
`r_j` 前 `j` 步的尾权为

```text
s_1=t_d=2,  s_2=t_(d-1),  ...,  s_j=t_(d-j+1),
W^(m)=s_1+...+s_m。
```

定义 5-adic 级数

```text
F_j = 1 + Σ_(p=0)^(j-1) 2^(-W^(p+1)) · 5^p。
```

则

```text
v_5(F_j)=k_0+1,
z ≡ F_j / (4·5^(k_0+1))  (mod 5^(a_0))。
```

**证明。** 词分子分解为
`2^(W_(d+1))+Σ_(p=0)^(j-1)2^(W_(d-p))5^p
 =2^(W_(d+1))·F_j`，其中
`W_(d+1)-W_(d-p)=W^(p+1)`。再由 19.13.8 的同余代入即得。∎

因此 G 的剩余等价于：对完整轨道每个真实块，累计尾权
`W^(1),...,W^(j)` 的 5-adic 零游程长度 `k_0+1` 与商
`F_j/(4·5^(k_0+1))` 的最小非负代表不能同时满足
`z∈(δ·5^(a_0)/16,δ·5^(a_0)/16+5^(a_0)/64)`、`5∤z`、
`v_2(z)` 为偶数。该级数形式把 G 压到“尾权进位阶梯”上，
仍未闭合。

**核验（单项回归，非证明）。** 对真实轨道
`r_j=2964479`、`j=10`、`δ=1`、`k_0=0`、`z=148224`，实际尾权
`s=[2,1,1,1,4,2,2,7,1,1]` 给出

```text
W=[2,3,4,5,9,11,13,20,21,22],
F_j mod 5^10 = 2964480 = 4·5·z，
```

与引理 19.13.10 完全一致。这确认级数公式在真实轨道上自洽，
但它不证明窗口不可能；该实例的偶数终端可达性仍失败。

**推论 19.13.11（窗口钉定尾权前缀，必要）。** 窗口命中给出

```text
F_j ≡ 4·5^(k_0+1)·z  (mod 5^(a_0+k_0+1))。
```

对满足 `W^(m)<4·5^(a_0+k_0+1-m)` 的 `m`，`W^(m)` 由该同余
唯一钉定；真实块中这覆盖 `m≲a_0+k_0+1-O(log(a_0+k_0+1))`。
因此窗口命中会把最后一段尾权的绝大部分唯一化，仅剩尾部少数
几步的有限歧义。该钉定是反向排除的下一步入口，仍未闭合。

**引理 19.13.12（真实块首迫使 `v_2(z)≥2`，已证）。** 设
`r_j` 是真实 `t_j=2` 块首，`r=(4r_j-1)/5` 是坏前驱，窗口命中。
则

```text
v_2(z)≥2 且为偶数。
```

**证明。** `r_j=(5r+1)/4` 且 `r_j+1=5(r+1)/4`，故
`e_j=v_2(r_j+1)=e(r)-2`。`t_j=2` 要求 `e_j≥3`；又
`e(r)` 为偶数，故 `e_j` 为偶数，所以 `e_j≥4`、`e(r)≥6`。
由 `r+1=16·5^(k_0)z` 得
`e(r)=4+v_2(z)≥6`，故 `v_2(z)≥2`。∎

因此窗口候选必须满足

```text
z≡0 (mod 4),
z∈(δ·5^(a_0)/16,δ·5^(a_0)/16+5^(a_0)/64),
5∤z。
```

这仍不足以用计数闭合：区间长度约为 `5^(a_0)/64`，其中
`4|z` 的候选约 `5^(a_0)/256` 个。该压缩只排除 `v_2(z)=0`
的候选，核心尾权阶梯仍未闭合。

### 19.14 单变量轨迹避让：全轨道 K 反例与修正后坏状态（2026-08-12）

**结论（必要）。** 当前目标中“在 `e=2` 阶段
`v_2(5m-1)≡0 (mod 4)` 即坏状态”的陈述在完整 7 轨道上是
假的。完整轨道确实进入该状态，因此单变量轨迹避让定理不能
把 K 写成无条件坏集；必须把坏状态限定为带真实偶数终端关系
的 G 型状态，并把 `e=2` 阶段作为转移前提而不是独立坏状态。

**反例（n=90，完整轨道单项核验）。** 轨道从 `r_0=7` 按
`r_{n+1}=(5r_n+1)/2^(v_2(5r_n+1))` 递推。第 90 项为

```text
r_90 = 32454075652083,
r_90+1 = 32454075652084 = 4·8113518913021,
e = 2,  m = 8113518913021（奇数），
5m-1 = 40567594565104 = 16·2535474660319,
v_2(5m-1) = 4 ≡ 0 (mod 4)。
```

因此全轨道 K 被单个显式状态否证。该反例的传播是：

```text
n=89: e=1, m=6490815130417（前驱，非 K 违反）；
n=90: e=2, v_2(5m-1)=4（K 违反）；
n=91: r'=2535474660319, r'+1=2^5·5·15846716627,
      e'=5, k'=1（不是 e≥4 偶数）；
n=92: e=3, k=2;
n=93: e=1, k=3;
n=94: k 回落为 0。
```

所以该 K 反例不会直接产生 G 坏状态：后继链的 `e` 为
`5,3,1`，从未出现 `e≥4` 偶数与 `k≥1` 同时成立。定向核验
（非证明）还显示，`r_90` 的所有候选
`r_(j-1)=r_90-δ5^(j-1)`（`δ∈{1,3}`）中，不存在满足
`r_(j-1)=2y`、`y` 为轨道前缀状态、且
`r_(j-1)+1=5^k·s''`、`0<s''<5^a/4` 的真实偶数终端关系。

**更强的转移型现象（n=181/182，单项核验，非证明）。** 500 步
校准中唯一同时满足 `v_2(5m-1)≡0 (mod 4)` 与
`e'=v_2(q+1)≥4` 偶数的 `e=2` 状态在 `n=181`：

```text
r_181=20392971610557427,  e=2,
5m-1=16·1593200907074799,  v_2(5m-1)=4,
q+1=1593200907074800=2^4·5^2·63728036282992,
e'=4,  k'=2。
```

后继 `r_182=1593200907074799` 满足 `e=4,k=2`，是 G 的
“候选阶段”，但它没有命中窗口：对 `δ∈{1,3}` 与
`a=j-1-k≥1`，`M=63728036282992` 不在
`(δ5^a,(δ+1/4)5^a)` 内；对轨道前缀定向核验也未发现真实偶数
终端关系。因此即使最强的前驱现象也不进入 G 坏状态。

**修正后的坏状态（单变量避让目标）。** 删除无条件 `e=2`
条款后，坏状态定义为：轨道状态 `r` 满足

```text
e≥4 为偶数,  k≥1,
∃δ∈{1,3}, j≥1, a=j-1-k≥1:
  M∈(δ5^a,(δ+1/4)5^a),
  r_(j-1)=r-δ5^(j-1)=2y（y 为轨道状态），
  r_(j-1)+1=5^k·s'',  s'' 为奇数,  5∤s'',
  0<s''<5^a/4。
```

`e=2` 阶段只作为转移前提进入归纳：当
`v_2(5m-1)≡0 (mod 4)` 且 `e'=v_2(q+1)` 为偶数时，后继进入
`e≥4` 偶数的候选阶段；是否坏由上面的窗口与真实终端关系判定。
这一步不再需要独立的 K 语句，也不允许把
`v_2(5m-1)≡0 (mod 4)` 本身称为坏状态。

**状态。** 19.14 的反例与修正已写入；修正后的单变量避让定理
尚未闭合，Lean 定理必须按修正后坏集陈述。旧目标中的无条件
`e=2` 条款已证明为假，不能作为零 sorry 定理交付。

### 19.15 修正后的单变量避让：坏状态与链起点结构（2026-08-12 续）

**定理 19.15.1（G-only 轨迹避让，目标陈述）。** 从
`(e,m,k,M)=(3,1,0,8)`（即 `r=7`）出发沿 19.3 的三分递推，
不存在轨道状态 `r` 满足修正后的坏状态：

```text
e=v_2(r+1) 为偶数且 e≥4,  k=v_5(r+1)≥1,
M=(r+1)/5^k,
∃δ∈{1,3}, j≥1, a=j-1-k≥1:
  M∈(δ5^a,(δ+1/4)5^a),
  r_(j-1)=r-δ5^(j-1)=2y,  y 为轨道状态,
  r_(j-1)+1=5^k·s'',  s'' 为奇数,  5∤s'',
  0<s''<5^a/4。
```

**引理 19.15.2（坏状态的链起点形式，充要）。** 设 `r` 是坏状态。
从 `r` 沿 `e≥3` 链反推恰好 `k` 步得到链起点 `r_0`，满足

```text
r_0+1 = 4^k·(s''+δ5^a),
e_0=v_2(r_0+1)=e+2k 为偶数且 ≥2k+4,
k_0=v_5(r_0+1)=0,
M_0=(r_0+1)/2^(e_0)=M 为奇数且 5∤M,
```

且 `r_0` 的紧前驱 `r_{-1}` 满足 `v_2(r_{-1}+1)∈{1,2}`。
反向链上的精确不变量是

```text
r_s+1=2^(e+2k-2s)·5^s·M,   0≤s≤k。
```

反向亦成立：若 `r_0+1=4^k(s''+δ5^a)` 且 `r_0` 是真实轨道状态，
则第 `k` 个链状态 `r` 满足坏状态的窗口与终端关系。

**证明。** 由 `e≥3` 步 `(e,m)→(e-2,5m)`，反推一步把
`(e,m)` 变为 `(e+2,m/5)`。坏状态 `r` 有 `m=5^k·M`、`5∤M`，
因此恰好反推 `k` 步后 `m` 不再被 5 整除，得到上式与
`k_0=0`。若 `r_0` 的紧前驱仍是 `e≥3`，则链未到头，矛盾于
“恰好 `k` 步后不能再反推”。∎

**推论 19.15.3（两类出生，必要且充分）。** 在上述记号下，
`r_{-1}` 只有两种可能：

1. `e_{-1}=1`：存在奇数 `m` 使 `r_0+1=5m-1`，即
   `5m-1=4^k(s''+δ5^a)`；等价地
   `m=(4^k(s''+δ5^a)+1)/5`，`r_{-1}=2m-1`。
2. `e_{-1}=2`：存在奇数 `m` 与 `v=v_2(5m-1)≢0 (mod 4)` 使
   `q=(5m-1)/2^v`，`q+1=4^k(s''+δ5^a)`；等价地
   `m=(2^v(4^k(s''+δ5^a)-1)+1)/5`，`r_{-1}=4m-1`。

**证明。** 由引理 19.15.2 与 19.3 的三分递推直接代入。情况 2
中 `v_5(q+1)=k_0=0`，由 19.9 的判据得 `v≢0 (mod 4)`。∎

**推论 19.15.4（出生整性，必要）。** 情况 1 要求

```text
(-1)^k·s'' ≡ -1 (mod 5)；
```

情况 2 要求

```text
2^v·(4^k(s''+δ5^a)-1) ≡ -1 (mod 5)。
```

**证明。** 分子的 5 整除性；`4^k≡(-1)^k (mod 5)`，
`s''+δ5^a≡s'' (mod 5)`。∎

**推论 19.15.5（K 违反不进入 G，必要）。** 若 `r_{-1}` 是
`e=2` 状态且 `v_2(5m-1)≡0 (mod 4)`，则其后继 `r_0` 满足
`v_5(r_0+1)≥1`，因此 `r_0` 不是链起点。任何 G 坏状态对应的
`e=2` 出生状态必满足 `v_2(5m-1)≢0 (mod 4)`。完整轨道的 K
违反（如 `n=90`）因此不可能直接成为 G 的出生。

**证明。** 19.9 的判据给出
`k'=v_5(q+1)≥1 ⇔ v_2(5m-1)≡0 (mod 4)`。若 `k'≥1`，则
`r_0+1` 被 5 整除，与链起点 `k_0=0` 矛盾。∎

**引理 19.15.6（链上差分恒等式，已证）。** 在 19.15.2 的记号下，
对 `0≤s≤k` 有

```text
r_s+1 = 4^(k-s)·5^s·(s''+δ5^a),
r_{s+1}-r_s = 4^(k-s-1)·5^s·(s''+δ5^a),
r-r_0 = (5^k-4^k)·(s''+δ5^a)。
```

**证明。** 由 19.3 的 `e≥3` 步 `r_{s+1}=(5r_s+1)/4` 与
`r_s+1=2^(e+2k-2s)·5^s·M` 直接展开；第三个等式是前两个在
`s=0..k-1` 上的累加。∎

**说明（词递推自洽，已证）。** 纯 `t=2` 段上的词递推
`A_{t+1}=5A_t+2^(W_t)` 给出

```text
Σ_{s=0}^{k-1} 2^(W_0+2s)·5^(k-1-s) = 2^(W_0)·(5^k-4^k)，
```

因此 19.15.6 的差分与轨道词方程代入后严格回到
`r_0+1=4^k(s''+δ5^a)`，没有引入新的数值条件。

**推论 19.15.7（`e=1` 出生与窗口的显式桥，已证）。** 在 19.15.3
情况 1 中，若链起点由最大 `e=1` 游程产生（19.10.1 的记号
`λ,c`），则

```text
3·4^k·(s''+δ5^a) = 2(c5^λ+1),
e+2k = 1+v_2(c5^λ+1)。
```

**证明。** 19.10.1 给出 `r_0+1=2(c5^λ+1)/3`，19.15.2 给出
`r_0+1=4^k(s''+δ5^a)`；联立即得第一式。两边取 2-adic 估值得
第二式。∎

**推论 19.15.9（`e=1` 出生的 S-unit 形式，已证）。** 19.15.7
等价于

```text
c·5^λ + 1 = 3·2^(e+2k-1)·m_1,
m_1=(s''+δ5^a)/2^e 为奇数且 5∤m_1。
```

即两项 S-unit 方程

```text
c·5^λ - 3·2^(e+2k-1)·m_1 = -1。
```

这里 `c,m_1` 均为不被 5 整除的奇数。仅靠该方程本身存在大量
算术解，因此必须继续使用“`c` 来自真实 `e=1` 游程起点、

### 19.16 `k=1` 抵消子情形的真实游程起点差分（2026-08-12）

### 19.18 出生步权重的模 5 钉定与类型 2 的 `v≡3 (mod 4)`（2026-08-12）

**引理 19.18.1（出生步权重，必要）。** 设 `t_prev` 是进入 `r0`

```text

m≡5 (mod 8),  m≡5 或 13 (mod 16) 按 v=3 或 v≥7,
s''=2^e m_1-5^a,  0<s''<5^a/4,
r_{-1}=4m-1 在 7 的轨道上,
r0=(5m-1)/2^v 在 7 的轨道上,
以及 19.15.1 的坏状态与真实终端前提。
```

**统一剩余。** 对两种类型，`r0+1=4^k(s''+5^a)=2^(e+2k)m_1`，
`r0` 与 `y=(5^k s''-1)/2` 都必须是 7 的轨道状态，且
`r=2y+5^(j-1)` 也必须是 7 的轨道状态。19.18.3/19.18.4 的反向
模系递推只钉住逐层 `m mod 5`、`t_b mod 4` 与 2-adic 低比特，
尚未与 7 的初始词产生矛盾。闭合这两个子语句中的任何一个，
其余部分仍未完成；两个都闭合后 `δ=1` 剩余才关闭。

### 19.18.6 校准（单项核验，非证明）

对 7 的前 2000 项轨道，`e=2` 且 `v_2(5m-1)≡3 (mod 4)` 的状态

### 19.18.9 唯一剩余与 X 因素（2026-08-12，未闭合）

本轮不再增加等价归约或新架构名。按 19.18.8，`δ=1` 剩余仍为
两个精确子语句：

**类型 1 的完整候选。** 存在奇数 `m`、正整数 `L` 与
`(j,k,a,s'')` 满足

```text
5m-1=4^k(s''+5^a),   0<s''<5^a/4,
s'' 为奇数,  5∤s'',  s''≡11 或 19 (mod 20) 按 k 的奇偶,
3m-1=2·5^(L-1)·c,   c 为奇数,
r_{-1}=2m-1,  r0=5m-2,
y=(5^k s''-1)/2,  r=5^k(s''+5^a)-1。
```

其中 `r_{-1},r0,y,r` 都必须属于 `FullOrbitFrom7`。非轨道算术
层已被 19.16 的 `y=34177` 类实例穿透：这些实例满足全部局部
同余与尺寸，只有预测游程起点 `r_B` 不属于完整轨道。

**类型 2 的完整候选。** 存在奇数 `m,m_1` 与正整数
`(j,k,a,e,v)` 满足

```text
v=v_2(5m-1)≡3 (mod 4),
5m=2^v(2^(e+2k)m_1-1)+1,

m≡5 (mod 8),  m≡5 或 13 (mod 16) 按 v=3 或 v≥7,

r_{-1}=4m-1,  r0=(5m-1)/2^v,
y=(5^k s''-1)/2,  r=5^k(s''+5^a)-1。
```

同样要求 `r_{-1},r0,y,r ∈ FullOrbitFrom7`。

**本轮结论（必要）。** 两个候选的局部算术层都不与
`m≡5 (mod 8)`、反向权重模系、出生步权重或 2-adic 低比特矛盾；
19.18.4 的反向模系只能把逐层 `t_b mod 4` 和 `m mod 5` 钉住，
不能控制反向树中 `t_b` 的无界幅度。因此唯一 X 因素仍然是：

> 从 `y` 到 `r0` 的实际完整轨道词步型 `A_w`（特别是 C3 步分布）
> 如何进入 `2^W·r0=5^N·y+A_w`，并排除两个候选的
> `FullOrbitFrom7` 成员性。

19.16.2 的差分估值、19.17 的词尾同余和 19.18 的出生权重均未
把该成员性闭合；在写出完整轨道词约束前，不得宣称局部引理、
