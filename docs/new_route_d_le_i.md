# 新收口路线：证明 D_i <= i（BLOCK_LEMMA 已被否决）

日期：2026-08-08

## 1. BLOCK_LEMMA(n=1) 为假

W 可实现反例见 `block_lemma_w_counterexample_cert.txt`：
深度 21，`V+b=15 > 13=j+2-t_j`，22 个链节点全部属于 W。
因此原目标中的 BLOCK_LEMMA 不能作为充分条件。

## 2. 新充分条件：D_i <= i 蕴含 G_i >= 1

记号：对前缀自动机状态，`W_i` 是前缀权重，`q_i` 是商，
`j` 是最后一次重置步，`D_i = W_i - W_{j-1}`。

若 `D_i <= i` 对所有 `i>=17` 成立，则：

```
q_i >= 2^{W_{j-1}} = 2^{W_i-D_i},
G_i = q_i*5^i / 2^{W_i+i+2}
    >= 5^i / 2^{D_i+i+2}
    >= 5^i / 2^{2i+2} = (5/4)^i / 4 > 1.
```

这是充分条件（非必要条件）；对 `i=17` 已给
`(5/4)^17/4 ~ 14.7 > 1`。

## 3. 剩余开放核心

解析证明：对所有 `i>=17`，`D_i <= i`，即当前块内
`t=2,delta=0` 步数 `b_i` 满足 `b_i + t_j <= j`。

已知证据（有限范围证书，不是证明）：

- `d<=22` 全部前缀：`D_i>i` 计数 0，`D_i=i` 且 `r_i=7 mod 8`
  计数 0；
- 随机前缀 10000 条、长度 30..1000、5,000,882 个状态：同样为 0；
- 小深度存在 `D_i>i`，但这些块在深度 17 前必然重置。

以上三条已被第 5 节的深度 31 精确反例否决：旧全前缀界只到 21，
随机搜索命中该反例前缀的概率为 `2^-31`。

## 4. 闭合链（若 D_i<=i 成立）

```
D_i<=i -> G_i>=1 -> c_k>=4(4/5)^k -> m_d>=2^{d+2} -> D0 + SURV-EX + TD0 -> 7 发散
```

`G_i>=1` 与后续链的现有推导见 `e0_margin_automaton.md` 第 19--20 节；
只需把 BLOCK_LEMMA 替换为 `D_i<=i` 作为入口。

## 5. D_i<=i 的精确反例（深度 31，否决）

**结论：** `D_i<=i` 对全部前缀状态不成立。精确反例见
`d_bound_counterexample_cert.txt` 与 `d_bound_counterexample.md`。

前缀
```
(2,2,1,1,2,1,2,1,1,2,2,1,2,
 2,2,2,2,2,1,1,1,2,1,1,1,2,2,2,2,2,2)
```
从深度 14 到 31 全部满足 `delta_i=0`；最后一次重置 `j=13`、
`t_j=2`、`W_{12}=18`。于是：
```
i=30: D_i=30, r_i≡7 mod8   （危险延续状态）
i=31: D_i=32, D_i-i=1
```

旧证书只精确枚举到深度 21，且随机搜索命中该前缀概率为 `2^-31`。
因此原证书的“零违反”不是尾部证明，也不能再作为 `D_i<=i` 的支持。

该反例处 `G_31≈153.94>1`，所以 `G_i>=1` 本身未被否决；但
`D_i<=i -> G_i>=1` 的充分条件路线已失效，需要寻找其他充分条件。

## 6. 新的更弱充分条件

`D_i<=i` 失败后，下一步目标收窄为容量引理 C：
$$
h_i\le j-t_j+\lambda i-2,\qquad
\lambda=\log_2\frac54,
$$
其中 `h_i` 是当前 `delta=0` 块内到 `i` 为止的 `t=2` 步数。
C 是 `G_i>=1` 的充分条件，且未被深度 31 反例否决。
C 又归结为引理 L：若 `r_i=3 mod 4` 则势能
`T_i=lambda*i-2-(D_i-i)>=1-lambda`。

完整推导见 `capacity_lemma_reduction.md`。L 仍是开放解析语句。
