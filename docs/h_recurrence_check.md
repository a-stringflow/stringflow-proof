# h_i 递推核查（2026-08-09）

结论：用户给出的递推

```text
h_1 = 0,
h_{i+1} = h_i + (v2(a_i)-1)/2
```

**不正确**。正确递推是

```text
h_1 = (u_j-1)/2,
h_{i+1} = h_i + a_i - 1 = h_i + (X_i-2)/2,
```

其中 `X_i=2a_i` 是第 `i` 个 `u=1` 状态的估值。只有块首
`u_j=1`（`n0=0` 情形）时才有 `h_1=0`。

## 1. 记号

- `δ=0` 块，块首深度 `j`，块首奇偶部
  `u_j=v2(r_j+1)`；
- 块内 `u=1` 状态列 `p_1<p_2<...`；
- 对第 `i` 个 `u=1` 状态，
  `X_i=v2(5r_{p_i}+3)`，宏步参数 `a_i=X_i/2`；
- `h_i` = 从块首到 `p_i` 之间（`(j,p_i]`）的 `t=2` 步数。

## 2. 块首到第一个 u=1 状态

块内 `t=2` 步要求 `u≥2`，并精确满足

```text
u' = u - 2.
```

因此从块首 `u_j`（奇数）降到 `u=1` 需要

```text
(u_j-1)/2
```

个 `t=2` 步，即

```text
h_1 = (u_j-1)/2.
```

当且仅当 `u_j=1` 时 `h_1=0`。该式与
`local_lemma_analytic_advance.md` 的恒等式
`h_m=(u_j-1)/2+(1/2)Σ_{k<m}(X_k-2)` 一致。

## 3. 相邻 u=1 状态之间的 t=2 步数

设 `p_i` 是 `u=1` 状态且 `X_i=2a_i` 为偶数。宏步结构为：

1. 一步 `t=1`，由 `t1_next_valuation`（已在
   `../lean/AutomatonInterface.lean` 编译）：

   ```text
   v2(r'+1) = X_i - 1 = 2a_i - 1.
   ```

2. 随后每个 `t=2` 步把 `u` 减少 `2`：

   ```text
   u -> u-2.
   ```

3. 回到下一个 `u=1` 状态要求

   ```text
   (2a_i-1) - 2L = 1,
   ```

   故

   ```text
   L = a_i - 1 = (X_i-2)/2.
   ```

因此

```text
h_{i+1} = h_i + a_i - 1 = h_i + (X_i-2)/2.
```

## 4. 为什么 `(v2(a_i)-1)/2` 是错的

`v2(a_i)` 出现在 LTE 的
`n_i=2+v2(a_i)` 中，控制 `5^(a_i)-1` 的 2-adic 估值，但它不决定
`t=2` 步数。反例：

- `a_i=1`：正确增量 `0`；错误式给 `(0-1)/2=-1/2`；
- `a_i=2`：正确增量 `1`；错误式给 `(1-1)/2=0`；
- `a_i=4`：正确增量 `3`；错误式给 `(2-1)/2=1/2`。

错误式甚至不恒为整数，而 `h_i` 是步数计数。

## 5. 与逐步/全局 block 递推的一致性

逐步 `δ=0` 递推直接给出

```text
h_{s+1} = h_s + 1  （t_{s+1}=2）,
h_{s+1} = h_s      （t_{s+1}=1）.
```

宏步 `p_i -> p_{i+1}` 含一步 `t=1` 和 `a_i-1` 步 `t=2`，逐项求和
即得第 3 节的增量；这说明正确递推同时与逐步递推和全局 block
递推一致。块首部分由 `t=2` 链的 `u -> u-2` 闭式给出。

## 6. 求和形式

由第 2、3 节：

```text
h_i = (u_j-1)/2 + Σ_{k<i}(X_k-2)/2
    = (u_j-1)/2 + Σ_{k<i}(a_k-1).
```

这就是 `local_lemma_analytic_advance.md` 第 2 节第 4 条已列出的
恒等式。若某处写成 `h_{i+1}=h_i+(v2(a_i)-1)/2`，应视为笔误或
符号混淆，需要改为 `h_{i+1}=h_i+a_i-1`。

## 7. 终端宏步的说明

若 `X_i=2a_i+1` 为奇数，则宏步终点是 `u=0` 终端，新增
`a_i` 个 `t=2` 步（一步 `t=1` 后接 `a_i` 步 `t=2`），而非
`a_i-1`。该情形不属于“下一个 `u=1` 状态”的 `h_i` 序列，但在
块总 `h` 计数时需要单独处理。
